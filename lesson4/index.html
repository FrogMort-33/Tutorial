Part 1: The big idea and the world 12 MIN

Our project() rule from Lesson 1 has a hidden assumption: you are standing at (0, 0, 0), looking straight along +z. Dividing by z only makes sense if z means "how far in front of me". So how can you ever walk anywhere?

The trick is that you don't. When you step 1 to the right, everything you see slides 1 to the left. If instead the cube slid 1 to the left while you stood still, you would see exactly the same picture, pixel for pixel. So the computer keeps you fixed and moves the world.

That means we now need two different ways to measure where a point is:

Four kinds of coordinates now

SHAPE: from the cube's own centre (cube_points). WORLD: from the fixed centre of the map. CAMERA: from you, +z the way you face. SCREEN: pixels from the window's top-left. In Lessons 1 to 3 you sat at the WORLD centre facing +z, so WORLD and CAMERA were the same thing and we only needed one word.

The world gets addresses

Before anything moves, the cube gets a fixed address in the WORLD, and you get one too. Three new variables hold your position.

cube_position = (0, 0, 5)     # the cube's centre, in WORLD coordinates
cube_x, cube_y, cube_z = cube_position

cam_x = 0                     # where YOU stand, in WORLD coordinates
cam_y = 0
cam_z = 0

A corner's WORLD position is its SHAPE position plus cube_position: ((x + cube_x), (y + cube_y), (z + cube_z)). With cube_position = (0, 0, 5) that is the same "add 5 to z" as before.

# ---- The three turns (from Lesson 2B, unchanged) -----------------------
def rotate_x(point_3d, angle_degrees):
    """TIP one point around the x axis (+y swings toward +z)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = x
    new_y = (y * cos_a) - (z * sin_a)
    new_z = (y * sin_a) + (z * cos_a)
    return (new_x, new_y, new_z)


def rotate_y(point_3d, angle_degrees):
    """TURN one point around the y axis (+x swings toward +z)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = (x * cos_a) - (z * sin_a)
    new_y = y
    new_z = (x * sin_a) + (z * cos_a)
    return (new_x, new_y, new_z)


def rotate_z(point_3d, angle_degrees):
    """ROLL one point around the z axis (+x swings toward +y)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = (x * cos_a) - (y * sin_a)
    new_y = (x * sin_a) + (y * cos_a)
    new_z = z
    return (new_x, new_y, new_z)


def rotate_all(point_3d):
    """Spin the cube: tip, then turn, then roll (Lesson 2B's order)."""
    p = rotate_x(point_3d, angle_x)
    p = rotate_y(p, angle_y)
    p = rotate_z(p, angle_z)
    return p


def project(point_3d):
    """Turn one 3D point into a 2D SCREEN point (from Lesson 1).

    You are at the WORLD centre facing +z, so a WORLD point works here.
    """
    x, y, z = point_3d
    screen_x = CENTRE_X + ( (x * FOCAL) / z )
    screen_y = CENTRE_Y - ( (y * FOCAL) / z )
    return (screen_x, screen_y)


def average_z(corners, world_points):
    """How far away is this face? (from Lesson 3)"""
    total = 0
    for corner_number in corners:
        x, y, z = world_points[corner_number]
        total = (total + z)
    return (total / len(corners))          # len(corners) is 4


def is_facing_you(face_points):
    """The clock test (from Lesson 3, unchanged): True if clockwise on
    the SCREEN, which means the face is turned toward you."""
    a_x, a_y = face_points[0]
    b_x, b_y = face_points[1]
    c_x, c_y = face_points[2]
    arrow_a_x = (b_x - a_x)
    arrow_a_y = (b_y - a_y)
    arrow_b_x = (c_x - a_x)
    arrow_b_y = (c_y - a_y)
    cross = ( (arrow_a_x * arrow_b_y) - (arrow_a_y * arrow_b_x) )
    return (cross > 0)


def dot(arrow_1, arrow_2):
    """The dot product (from Lesson 3B)."""
    x1, y1, z1 = arrow_1
    x2, y2, z2 = arrow_2
    return ( (x1 * x2) + (y1 * y2) + (z1 * z2) )


def shade_colour(colour, turned_normal):
    """Brighter when the face points at the light (from Lesson 3B)."""
    brightness = dot(turned_normal, LIGHT)
    if brightness < 0:
        brightness = 0
    shade = ( AMBIENT + ( (1 - AMBIENT) * brightness ) )
    red, green, blue = colour
    return ( round(red * shade), round(green * shade), round(blue * shade) )


def keep_under_360(angle):
    """360 degrees is the same as 0, so start again after a full turn."""
    if angle >= 360:
        angle = (angle - 360)
    return angle


def to_map(x, z):
    """NEW: a WORLD (x, z) -> a pixel on the mini-map.

    Like project(), but with no dividing, because the map is flat.
    +z goes UP the map, and screen y counts DOWN, so we SUBTRACT z.
    Example: you at (2, 0, 1) -> (710 + (2 * 10), 560 - (1 * 10))
                               = (730, 550)
    """
    map_x = MAP_CX + (x * MAP_SCALE)
    map_y = MAP_CY - (z * MAP_SCALE)
    return (map_x, map_y)


def draw_map(world_points):
    """NEW: draw the mini-map: the cube's outline and you, from above."""
    box = pygame.Rect(MAP_LEFT, MAP_TOP, MAP_SIZE, MAP_SIZE)
    pygame.draw.rect(screen, MAP_BACK, box)
    # set_clip: anything we draw outside the box is cut off, so a dot
    # off the edge of the map just disappears.
    screen.set_clip(box)
    # The cube from above = its 4 BOTTOM corners (0, 1, 2, 3), x and z only.
    outline = []
    for corner_number in (0, 1, 2, 3):
        x, y, z = world_points[corner_number]
        outline.append(to_map(x, z))
    pygame.draw.polygon(screen, GREEN, outline, 2)
    # You: a pink dot, with a short line showing the way you face (+z).
    you = to_map(cam_x, cam_z)
    nose = to_map(cam_x, (cam_z + 1.5))      # 1.5 units in front of you
    pygame.draw.line(screen, PINK, you, nose, 2)
    pygame.draw.circle(screen, PINK, you, 4)
    screen.set_clip(None)                    # stop cutting things off
    pygame.draw.rect(screen, WHITE, box, 1)  # thin white border

Part 3: Things behind you 10 MIN

Once you can walk, you can walk past the cube. Then some of its corners are behind you. Which ones? In CAMERA coordinates the answer is easy, because only z tells you.

What happens if we project a point behind you anyway? Dividing by a negative z flips the signs, so the point is drawn on the opposite side of the screen and upside down: a ghost. And a z of exactly 0 crashes the program.

NEAR: how close is too close?

So we need a cut-off: anything with a CAMERA z smaller than some small number is not drawn. We call it NEAR. To choose it, look at where a point just 1 unit to the side lands as it gets closer:

NEAR = 0.1      # closer than this (CAMERA z) is not drawn

The simple rule: skip the whole face

A face is drawn as one polygon from its 4 corners, so if even one corner is too close we skip the whole face. It is simple and it never crashes. The price is that a face sometimes vanishes a little early, when only part of it has gone behind you:

# inside the face loop, before the clock test:
too_close = False
for corner_number in corners:
    if camera_points[corner_number][2] < NEAR:
        too_close = True
if too_close:
    continue

# ---- The three turns (from Lesson 2B, unchanged) -----------------------
def rotate_x(point_3d, angle_degrees):
    """TIP one point around the x axis (+y swings toward +z)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = x
    new_y = (y * cos_a) - (z * sin_a)
    new_z = (y * sin_a) + (z * cos_a)
    return (new_x, new_y, new_z)


def rotate_y(point_3d, angle_degrees):
    """TURN one point around the y axis (+x swings toward +z)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = (x * cos_a) - (z * sin_a)
    new_y = y
    new_z = (x * sin_a) + (z * cos_a)
    return (new_x, new_y, new_z)


def rotate_z(point_3d, angle_degrees):
    """ROLL one point around the z axis (+x swings toward +y)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = (x * cos_a) - (y * sin_a)
    new_y = (x * sin_a) + (y * cos_a)
    new_z = z
    return (new_x, new_y, new_z)


def rotate_all(point_3d):
    """Spin the cube: tip, then turn, then roll (Lesson 2B's order)."""
    p = rotate_x(point_3d, angle_x)
    p = rotate_y(p, angle_y)
    p = rotate_z(p, angle_z)
    return p


def to_camera(world_point):
    """NEW: turn one WORLD point into a CAMERA point (measured from YOU).

    Subtract where you are standing, one letter at a time.
    Worked example (lesson Part 2): you at (2, 0, 1), corner 5 at
    WORLD (1, 1, 4):
        ((1 - 2), (1 - 0), (4 - 1))  =  (-1, 1, 3)
    """
    x, y, z = world_point
    camera_x = (x - cam_x)
    camera_y = (y - cam_y)
    camera_z = (z - cam_z)
    return (camera_x, camera_y, camera_z)


def project(point_3d):
    """Turn one 3D CAMERA point into a 2D SCREEN point (from Lesson 1).

    Only ever call this with z >= NEAR, so we never divide by 0.
    """
    x, y, z = point_3d
    screen_x = CENTRE_X + ( (x * FOCAL) / z )
    screen_y = CENTRE_Y - ( (y * FOCAL) / z )
    return (screen_x, screen_y)


def average_z(corners, camera_points):
    """How far away is this face? (from Lesson 3)

    CHANGED: we now pass in CAMERA points, so z means "distance in
    front of YOU", wherever you are standing. (WORLD z would give the
    wrong answer as soon as you walk round behind the cube.)
    """
    total = 0
    for corner_number in corners:
        x, y, z = camera_points[corner_number]
        total = (total + z)
    return (total / len(corners))          # len(corners) is 4


def is_facing_you(face_points):
    """The clock test (from Lesson 3, unchanged): True if clockwise on
    the SCREEN, which means the face is turned toward you."""
    a_x, a_y = face_points[0]
    b_x, b_y = face_points[1]
    c_x, c_y = face_points[2]
    arrow_a_x = (b_x - a_x)
    arrow_a_y = (b_y - a_y)
    arrow_b_x = (c_x - a_x)
    arrow_b_y = (c_y - a_y)
    cross = ( (arrow_a_x * arrow_b_y) - (arrow_a_y * arrow_b_x) )
    return (cross > 0)


def dot(arrow_1, arrow_2):
    """The dot product (from Lesson 3B)."""
    x1, y1, z1 = arrow_1
    x2, y2, z2 = arrow_2
    return ( (x1 * x2) + (y1 * y2) + (z1 * z2) )


def shade_colour(colour, turned_normal):
    """Brighter when the face points at the light (from Lesson 3B)."""
    brightness = dot(turned_normal, LIGHT)
    if brightness < 0:
        brightness = 0
    shade = ( AMBIENT + ( (1 - AMBIENT) * brightness ) )
    red, green, blue = colour
    return ( round(red * shade), round(green * shade), round(blue * shade) )


def keep_under_360(angle):
    """360 degrees is the same as 0, so start again after a full turn."""
    if angle >= 360:
        angle = (angle - 360)
    return angle


def to_map(x, z):
    """(step 0) a WORLD (x, z) -> a pixel on the mini-map.

    Like project(), but with no dividing, because the map is flat.
    +z goes UP the map, and screen y counts DOWN, so we SUBTRACT z.
    Example: you at (2, 0, 1) -> (710 + (2 * 10), 560 - (1 * 10))
                               = (730, 550)
    """
    map_x = MAP_CX + (x * MAP_SCALE)
    map_y = MAP_CY - (z * MAP_SCALE)
    return (map_x, map_y)

Nothing. The front face's corners are at CAMERA z = (4 - 3.95) = 0.05, which is less than NEAR, so the front face is skipped. The four side faces each share two of those corners, so they are skipped too. That leaves the back face, which has its back to you, so the clock test hides it.

Q5Why not just use NEAR = 0, since it's z = 0 that crashes?

Show answer

A z of 0.0001 would not crash, but a corner 1 unit to the side would land ((1 * 400) / 0.0001) = 4,000,000 px away. Drawing a polygon that big is slow and useless. 0.1 throws those away while still letting you get very close to a wall.

Part 4: Turning 10 MIN

Walking in straight lines along x and z is not much of a game. You need to turn. We store which way you face as one angle, in degrees.

cam_turn = 0          # degrees. 0 = facing +z. Positive = turned left.
TURN_SPEED = 1.5      # degrees per frame: (1.5 * 60) = 90 degrees a second

TURN_SPEED = 1.5 means a quarter turn takes 1 second and a full look round takes (360 / 90) = 4 seconds: quick enough to look about, slow enough to aim.

The world turns the opposite way

Turning works like walking. When you turn left, everything you see swings round to the right. So to draw what a turned camera sees, we keep you facing +z and turn the whole world by the opposite angle, with the rotate_y you already have.

So to_camera() gets a second line:

def to_camera(world_point):
    x, y, z = world_point
    moved = ( (x - cam_x), (y - cam_y), (z - cam_z) )   # 1. subtract
    turned = rotate_y(moved, (-cam_turn))               # 2. undo your turn
    return turned

Why subtract first, then turn?

You turn on the spot where you stand, not round the middle of the map. rotate_y always turns round (0, 0, 0), so we must first make you the (0, 0, 0) by subtracting, and only then turn.

# ---- The three turns (from Lesson 2B, unchanged) -----------------------
def rotate_x(point_3d, angle_degrees):
    """TIP one point around the x axis (+y swings toward +z)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = x
    new_y = (y * cos_a) - (z * sin_a)
    new_z = (y * sin_a) + (z * cos_a)
    return (new_x, new_y, new_z)


def rotate_y(point_3d, angle_degrees):
    """TURN one point around the y axis (+x swings toward +z)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = (x * cos_a) - (z * sin_a)
    new_y = y
    new_z = (x * sin_a) + (z * cos_a)
    return (new_x, new_y, new_z)


def rotate_z(point_3d, angle_degrees):
    """ROLL one point around the z axis (+x swings toward +y)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = (x * cos_a) - (y * sin_a)
    new_y = (x * sin_a) + (y * cos_a)
    new_z = z
    return (new_x, new_y, new_z)


def rotate_all(point_3d):
    """Spin the cube: tip, then turn, then roll (Lesson 2B's order)."""
    p = rotate_x(point_3d, angle_x)
    p = rotate_y(p, angle_y)
    p = rotate_z(p, angle_z)
    return p


def to_camera(world_point):
    """Turn one WORLD point into a CAMERA point (measured from YOU).

    1. Subtract where you are standing (step 1).
    2. NEW: turn the world the OPPOSITE way to the way you turned.

    Worked example (lesson Part 4): you at (2, 0, 1), cam_turn = 30,
    corner 5 at WORLD (1, 1, 4):
        1. ((1 - 2), (1 - 0), (4 - 1))   = (-1, 1, 3)
        2. rotate_y((-1, 1, 3), (-30))   = (0.634, 1, 3.098)
    """
    x, y, z = world_point
    # 1. Subtract: now YOU are the centre (0, 0, 0).
    moved = ( (x - cam_x), (y - cam_y), (z - cam_z) )
    # 2. Undo your turn. Because step 1 already made YOU the centre,
    #    the world swings round where you stand (not round the map's
    #    centre). Swap these two lines and corners jump behind you!
    turned = rotate_y(moved, (-cam_turn))
    return turned


def project(point_3d):
    """Turn one 3D CAMERA point into a 2D SCREEN point (from Lesson 1).

    Only ever call this with z >= NEAR, so we never divide by 0.
    """
    x, y, z = point_3d
    screen_x = CENTRE_X + ( (x * FOCAL) / z )
    screen_y = CENTRE_Y - ( (y * FOCAL) / z )
    return (screen_x, screen_y)


def average_z(corners, camera_points):
    """How far away is this face? (from Lesson 3)

    CHANGED in step 1: we pass in CAMERA points, so z means "distance in
    front of YOU", wherever you are standing. (WORLD z would give the
    wrong answer as soon as you walk round behind the cube.)
    """
    total = 0
    for corner_number in corners:
        x, y, z = camera_points[corner_number]
        total = (total + z)
    return (total / len(corners))          # len(corners) is 4


def is_facing_you(face_points):
    """The clock test (from Lesson 3, unchanged): True if clockwise on
    the SCREEN, which means the face is turned toward you."""
    a_x, a_y = face_points[0]
    b_x, b_y = face_points[1]
    c_x, c_y = face_points[2]
    arrow_a_x = (b_x - a_x)
    arrow_a_y = (b_y - a_y)
    arrow_b_x = (c_x - a_x)
    arrow_b_y = (c_y - a_y)
    cross = ( (arrow_a_x * arrow_b_y) - (arrow_a_y * arrow_b_x) )
    return (cross > 0)


def dot(arrow_1, arrow_2):
    """The dot product (from Lesson 3B)."""
    x1, y1, z1 = arrow_1
    x2, y2, z2 = arrow_2
    return ( (x1 * x2) + (y1 * y2) + (z1 * z2) )


def shade_colour(colour, turned_normal):
    """Brighter when the face points at the light (from Lesson 3B)."""
    brightness = dot(turned_normal, LIGHT)
    if brightness < 0:
        brightness = 0
    shade = ( AMBIENT + ( (1 - AMBIENT) * brightness ) )
    red, green, blue = colour
    return ( round(red * shade), round(green * shade), round(blue * shade) )


def keep_under_360(angle):
    """360 degrees is the same as 0, so start again after a full turn."""
    if angle >= 360:
        angle = (angle - 360)
    return angle


def to_map(x, z):
    """(step 0) a WORLD (x, z) -> a pixel on the mini-map.

    Like project(), but with no dividing, because the map is flat.
    +z goes UP the map, and screen y counts DOWN, so we SUBTRACT z.
    Example: you at (2, 0, 1) -> (710 + (2 * 10), 560 - (1 * 10))
                               = (730, 550)
    """
    map_x = MAP_CX + (x * MAP_SCALE)
    map_y = MAP_CY - (z * MAP_SCALE)
    return (map_x, map_y)

    # Turn the two start arrows by the SAME angle you turned.
    #   cam_turn 0:  forward (0, 0, 1)        right (1, 0, 0)
    #   cam_turn 30: forward (-0.5, 0, 0.866) right (0.866, 0, 0.5)
    # Both arrows are exactly 1 long, so MOVE_SPEED alone decides how
    # far one step goes, whichever way you face.
    forward_x, forward_y, forward_z = rotate_y((0, 0, 1), cam_turn)
    right_x, right_y, right_z = rotate_y((1, 0, 0), cam_turn)

    # ---- CHANGED: walking follows the arrows ---------------------------

        cam_x = (cam_x + (forward_x * MOVE_SPEED))

Part 6: Look up and down 5 MIN

The last piece is tilting your head. Lesson 2B called a turn round the x skewer a TIP, so we call this angle cam_tip. Nodding your head forward is a tip, and it makes you look down.

Undoing it is the same trick a third time: tip the world the opposite way. Your head nods after your body has turned, so it is undone after the turn is undone: last on, first off.

def to_camera(world_point):
    x, y, z = world_point
    moved = ( (x - cam_x), (y - cam_y), (z - cam_z) )   # 1. subtract
    turned = rotate_y(moved, (-cam_turn))               # 2. undo your turn
    tipped = rotate_x(turned, (-cam_tip))               # 3. undo your tip
    return tipped

We keep cam_tip between −60 and 60 (TIP_LIMIT = 60). Walking ignores cam_tip on purpose, so looking at the floor doesn't walk you into it.

#   (0.05 * 60) = 3 units a second.

#   (1.5 * 60) = 90 degrees a second: a quarter turn takes 1 second
#   and a full look round takes (360 / 90) = 4 seconds.

# Nothing closer than that could ever be useful to draw.
NEAR = 0.1

# you walk. The top of the cube stays the brightest face from anywhere.
LIGHT = (0.48, 0.6, -0.64)

# ---- The three turns (from Lesson 2B, unchanged) -----------------------
def rotate_x(point_3d, angle_degrees):
    """TIP one point around the x axis (+y swings toward +z)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = x
    new_y = (y * cos_a) - (z * sin_a)
    new_z = (y * sin_a) + (z * cos_a)
    return (new_x, new_y, new_z)


def rotate_y(point_3d, angle_degrees):
    """TURN one point around the y axis (+x swings toward +z)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = (x * cos_a) - (z * sin_a)
    new_y = y
    new_z = (x * sin_a) + (z * cos_a)
    return (new_x, new_y, new_z)


def rotate_z(point_3d, angle_degrees):
    """ROLL one point around the z axis (+x swings toward +y)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = (x * cos_a) - (y * sin_a)
    new_y = (x * sin_a) + (y * cos_a)
    new_z = z
    return (new_x, new_y, new_z)


def rotate_all(point_3d):
    """Spin the cube: tip, then turn, then roll (Lesson 2B's order)."""
    p = rotate_x(point_3d, angle_x)
    p = rotate_y(p, angle_y)
    p = rotate_z(p, angle_z)
    return p


def to_camera(world_point):
    """Turn one WORLD point into a CAMERA point (measured from YOU).

    1. Subtract where you are standing (step 1).
    2. Undo your turn: turn the world the OPPOSITE way (step 2).
    3. NEW: undo your tip: tip the world the OPPOSITE way.

    Worked example (lesson Part 6): you at (2, 0, 1), cam_turn = 30,
    cam_tip = 0, corner 5 at WORLD (1, 1, 4):
        1. ((1 - 2), (1 - 0), (4 - 1))   = (-1, 1, 3)
        2. rotate_y((-1, 1, 3), (-30))   = (0.634, 1, 3.098)
        3. rotate_x(that, (-0))          = no change
    """
    x, y, z = world_point
    # 1. Subtract: now YOU are the centre (0, 0, 0).
    moved = ( (x - cam_x), (y - cam_y), (z - cam_z) )
    # 2. Undo your turn. Because step 1 already made YOU the centre,
    #    the world swings round where you stand (not round the map's
    #    centre). Swap these two lines and corners jump behind you!
    turned = rotate_y(moved, (-cam_turn))
    # 3. NEW: undo your tip. The head nods AFTER the body turns, so it
    #    is undone after the turn is undone (last on, first off).
    tipped = rotate_x(turned, (-cam_tip))
    return tipped


def project(point_3d):
    """Turn one 3D CAMERA point into a 2D SCREEN point (from Lesson 1).

    Only ever call this with z >= NEAR, so we never divide by 0.
    """
    x, y, z = point_3d
    screen_x = CENTRE_X + ( (x * FOCAL) / z )
    screen_y = CENTRE_Y - ( (y * FOCAL) / z )
    return (screen_x, screen_y)


def average_z(corners, camera_points):
    """How far away is this face? (from Lesson 3)

    CHANGED in step 1: we pass in CAMERA points, so z means "distance in
    front of YOU", wherever you are standing. (WORLD z would give the
    wrong answer as soon as you walk round behind the cube.)
    """
    total = 0
    for corner_number in corners:
        x, y, z = camera_points[corner_number]
        total = (total + z)
    return (total / len(corners))          # len(corners) is 4


def is_facing_you(face_points):
    """The clock test (from Lesson 3, unchanged): True if clockwise on
    the SCREEN, which means the face is turned toward you."""
    a_x, a_y = face_points[0]
    b_x, b_y = face_points[1]
    c_x, c_y = face_points[2]
    arrow_a_x = (b_x - a_x)
    arrow_a_y = (b_y - a_y)
    arrow_b_x = (c_x - a_x)
    arrow_b_y = (c_y - a_y)
    cross = ( (arrow_a_x * arrow_b_y) - (arrow_a_y * arrow_b_x) )
    return (cross > 0)


def dot(arrow_1, arrow_2):
    """The dot product (from Lesson 3B)."""
    x1, y1, z1 = arrow_1
    x2, y2, z2 = arrow_2
    return ( (x1 * x2) + (y1 * y2) + (z1 * z2) )


def shade_colour(colour, turned_normal):
    """Brighter when the face points at the light (from Lesson 3B)."""
    brightness = dot(turned_normal, LIGHT)
    if brightness < 0:
        brightness = 0
    shade = ( AMBIENT + ( (1 - AMBIENT) * brightness ) )
    red, green, blue = colour
    return ( round(red * shade), round(green * shade), round(blue * shade) )


def keep_under_360(angle):
    """360 degrees is the same as 0, so start again after a full turn."""
    if angle >= 360:
        angle = (angle - 360)
    return angle


def to_map(x, z):
    """(step 0) a WORLD (x, z) -> a pixel on the mini-map.

    Like project(), but with no dividing, because the map is flat.
    +z goes UP the map, and screen y counts DOWN, so we SUBTRACT z.
    Example: you at (2, 0, 1) -> (710 + (2 * 10), 560 - (1 * 10))
                               = (730, 550)
    """
    map_x = MAP_CX + (x * MAP_SCALE)
    map_y = MAP_CY - (z * MAP_SCALE)
    return (map_x, map_y)


def draw_map(world_points):
    """(step 0) draw the mini-map: the cube's outline and you, from above."""
    box = pygame.Rect(MAP_LEFT, MAP_TOP, MAP_SIZE, MAP_SIZE)
    pygame.draw.rect(screen, MAP_BACK, box)
    # set_clip: anything we draw outside the box is cut off, so if you
    # walk off the edge of the map your dot just disappears.
    screen.set_clip(box)
    # The cube from above = its 4 BOTTOM corners (0, 1, 2, 3), x and z only.
    outline = []
    for corner_number in (0, 1, 2, 3):
        x, y, z = world_points[corner_number]
        outline.append(to_map(x, z))
    pygame.draw.polygon(screen, GREEN, outline, 2)
    # You: a pink dot, with a short line showing the way you face.
    # (step 2) the line follows your forward arrow.
    forward_x, forward_y, forward_z = rotate_y((0, 0, 1), cam_turn)
    you = to_map(cam_x, cam_z)
    nose = to_map( (cam_x + (forward_x * 1.5)), (cam_z + (forward_z * 1.5)) )
    pygame.draw.line(screen, PINK, you, nose, 2)
    pygame.draw.circle(screen, PINK, you, 4)
    screen.set_clip(None)                    # stop cutting things off
    pygame.draw.rect(screen, WHITE, box, 1)  # thin white border

    keys = pygame.key.get_pressed()

    if keys[pygame.K_RIGHT]:

    # ---- NEW: looking up and down --------------------------------------
    if keys[pygame.K_UP]:
        cam_tip = (cam_tip - TURN_SPEED)      # look up   = negative
    if keys[pygame.K_DOWN]:
        cam_tip = (cam_tip + TURN_SPEED)      # look down = positive
    # Keep it between -TIP_LIMIT and +TIP_LIMIT (-60 and 60).
    if cam_tip > TIP_LIMIT:
        cam_tip = TIP_LIMIT
    if cam_tip < (-TIP_LIMIT):
        cam_tip = (-TIP_LIMIT)

    # ---- (step 2) which way is "forward" and "right" right now? ------------
    # Turn the two start arrows by the SAME angle you turned.
    #   cam_turn 0:  forward (0, 0, 1)        right (1, 0, 0)
    #   cam_turn 30: forward (-0.5, 0, 0.866) right (0.866, 0, 0.5)
    # Both arrows are exactly 1 long, so MOVE_SPEED alone decides how
    # far one step goes, whichever way you face.
    # (cam_tip is NOT used here, so you always walk level.)
    forward_x, forward_y, forward_z = rotate_y((0, 0, 1), cam_turn)
    right_x, right_y, right_z = rotate_y((1, 0, 0), cam_turn)

    # ---- (step 2) walking follows the arrows ---------------------------
    if keys[pygame.K_w]:                       # forward
        cam_x = (cam_x + (forward_x * MOVE_SPEED))
        cam_z = (cam_z + (forward_z * MOVE_SPEED))
    if keys[pygame.K_s]:                       # back = minus forward

Q11Standing at (0, 0, 0) with cam_turn = 0, you look DOWN 30 (cam_tip = 30). Where does corner 5 go?

Show answer

rotate_x((1, 1, 4), (-30)): cos_a = 0.866, sin_a = −0.5. new_y = (1 * 0.866) - (4 * -0.5) = 0.866 + 2 = 2.866. new_z = (1 * -0.5) + (4 * 0.866) = −0.5 + 3.464 = 2.964. Screen y = 300 - ((2.866 * 400) / 2.964) = 300 − 386.8 = −86.8: just off the top of the window. Look down and the cube rises out of view.

Q12Why is the tip undone after the turn, and not before?

Show answer

You turn your body first and nod your head second. To undo a chain of moves you take them off in reverse order, like taking off shoes before socks would go wrong. So undo the turn, then undo the tip.

Q13You walk round behind the cube. Why does the top still look brighter than the back?

Show answer

The light maths uses each face's stored normal, turned with the cube's own spin, and the fixed LIGHT arrow. Neither involves the camera, so where you stand doesn't change how lit a face is, just as walking round a table doesn't change where the sun is.

Wrap up 1 MIN

  • The computer can't move you. It moves the world the opposite way: subtract your position, undo your turn, undo your tip.
  • WORLD coordinates say where things are. CAMERA coordinates say where they are from you, and project() only understands CAMERA coordinates.
  • Anything closer than NEAR = 0.1 (or behind you) is skipped, because z = 0 crashes and negative z draws ghosts.
  • Walk with arrows that turn with you: forward = rotate_y((0, 0, 1), cam_turn).

Q14Final check. You stand at (−1, 0, 2), turned right 30 (cam_turn = -30), looking level. Follow corner 5, WORLD (1, 1, 4), all the way to the screen.

Show answer

1. Subtract: ((1 - -1), (1 - 0), (4 - 2)) = (2, 1, 2).

2. Undo the turn: rotate_y((2, 1, 2), 30), cos_a = 0.866, sin_a = 0.5. new_x = (2 * 0.866) - (2 * 0.5) = 1.732 − 1 = 0.732. new_z = (2 * 0.5) + (2 * 0.866) = 1 + 1.732 = 2.732.

3. Undo the tip: 0, no change. CAMERA (0.732, 1, 2.732). z ≥ 0.1, so draw it.

4. Screen x = 400 + ((0.732 * 400) / 2.732) = 400 + 107.2 = 507.2. Screen y = 300 - ((1 * 400) / 2.732) = 300 − 146.4 = 153.6.

The depth buffer: closest wins, block by block

Since Lesson 3 the program has drawn solid shapes with the painter's order: sort whole faces far to near, then paint them in turn. That works until two shapes cross, and then no order of whole faces is right. Today we fill every face ourselves, one small block at a time, and keep one number for every block of the window: how close the nearest thing painted there is. A face only paints a block if it is closer. That is the depth buffer, and with it the order of faces stops mattering.

The painter's order, step by step

From the start, four faces face you: the board's top and front edge, and the cube's front and left. Here they are in the painter's order, with the picture after each one is painted:

Every average is right, and the sort is right. The trouble is the question the painter asks: "which whole face is nearer?" The board's top starts 3.6 away from you and ends 8.4 away. Its front part is in front of the cube; its back part is behind. One number per face can't say that.

KEY CONCEPT 
Don't ask which FACE is closer.
Ask which face is closer at EACH SPOT on the screen.

The painter's order gives one answer per face. A depth buffer gives one answer per small spot of the window, so a face can be in front at one spot and behind at the next.

Q1In Cube Hunt, a new gold cube appears at a random spot. Lesson 8's far_from_rocks() keeps it out of the rocks, but nothing keeps two gold cubes apart. What could the painter's order draw wrong?

Show answer

If two gold cubes overlap, part of each is inside the other, just like the board and the cube. The painter paints one cube's faces wholly over the other's, so you could see a cube's face that should be hidden inside its neighbour. The depth buffer gets it right block by block.

Part 2: Pixels and blocks 9 MIN

"Each spot of the screen" needs a meaning. The window is a grid of pixels: tiny squares that each show one colour.

The window has (800 * 600) = 480,000 pixels. For each one, the depth buffer has to ask: is it inside this face? How far away is the face there? Is that closer than what is already painted? pygame.draw.polygon() did this inside pygame, in fast compiled code. We now do it in Python, so we can add the depth check, and Python is much slower. We measured it:

One frame at 60 frames a second must take less than (1000 / 60) = 16.7 ms. Checking all 480,000 pixels would take 772 ms: well under 2 frames a second. So we don't check single pixels. We check blocks of 4 × 4 pixels, and paint each block in one colour:

BLOCK = 4
BLOCKS_ACROSS = (WIDTH // BLOCK)    # (800 // 4) = 200
BLOCKS_DOWN = (HEIGHT // BLOCK)     # (600 // 4) = 150
small = pygame.Surface((BLOCKS_ACROSS, BLOCKS_DOWN))
small.set_colorkey(BLACK)

That is (200 * 150) = 30,000 checks: 16 times fewer. Even a face that covers the whole window costs 57 ms, and most frames cover far less (Part 5 has whole-frame numbers). // divides and drops the remainder, so the answers are whole numbers. We paint into small, a 200 × 150 picture with one pixel per block, and at the end of the frame pygame.transform.scale() stretches it 4 times bigger onto the window. set_colorkey(BLACK) makes its black pixels see-through, so the floor lines drawn on the window first show between the shapes.

Part 3: Filling a triangle yourself 12 MIN

To fill a face block by block, we cut it into triangles first: a triangle is the simplest shape to test. A 4-corner face makes two triangles. Both start at the first corner in the face's list (list place 0):

def draw_face(face_points, colour):
    blocks = []
    for screen_x, screen_y in face_points:
        blocks.append( ((screen_x / BLOCK), (screen_y / BLOCK)) )
    fill_triangle(blocks[0], blocks[1], blocks[2], colour)

Which side of an edge?

Lesson 3's clock test took three corners and worked out one number: more than 0 meant clockwise. The same sum answers a second question. Walk along an edge from its start to its end: is a point on your right-hand side, or your left?

def side_of_edge(start, end, point):
    start_x, start_y = start
    end_x, end_y = end
    point_x, point_y = point
    arrow_a_x = (end_x - start_x)
    arrow_a_y = (end_y - start_y)
    arrow_b_x = (point_x - start_x)
    arrow_b_y = (point_y - start_y)
    return ( (arrow_a_x * arrow_b_y) - (arrow_a_y * arrow_b_x) )

def is_facing_you(face_points):
    return (side_of_edge(face_points[0], face_points[1], face_points[2]) > 0)

is_facing_you() is now one line: it is side_of_edge() with the face's third corner as the point.

Inside all three edges

Walk round a clockwise triangle a → b → c → a. A point is inside when it is on your right (0 or more) for all three edges. One "no" is enough to skip it:

Only look near the triangle

Testing all 30,000 blocks for every triangle would waste time on blocks nowhere near it. So we first find the triangle's bounding box: the smallest and biggest x and y of its three corners:

def fill_triangle(a, b, c, colour):
    total = side_of_edge(a, b, c)
    if total <= 0:
        return                       # a sliver with no area: nothing to fill
    a_x, a_y = a
    b_x, b_y = b
    c_x, c_y = c
    left = int(min(a_x, b_x, c_x))
    right = int(max(a_x, b_x, c_x))
    top = int(min(a_y, b_y, c_y))
    bottom = int(max(a_y, b_y, c_y))
    # (the full code also keeps the box inside 0..199 and 0..149)

    for block_y in range(top, (bottom + 1)):
        for block_x in range(left, (right + 1)):
            centre = ( (block_x + 0.5), (block_y + 0.5) )
            weight_a = side_of_edge(b, c, centre)
            weight_b = side_of_edge(c, a, centre)
            weight_c = side_of_edge(a, b, centre)
            if (weight_a < 0) or (weight_b < 0) or (weight_c < 0):
                continue                         # outside: next block
            small.set_at((block_x, block_y), colour)

continue jumps straight to the next block. small.set_at() colours one pixel of the small picture, which becomes one 4 × 4 block on the window. The three side numbers are called weight_a, weight_b and weight_c because Part 4 uses them again for something else.

def matrix_times_point(matrix, point_3d):
    """Put one point through a matrix: each ROW dotted with the point."""
    row_0, row_1, row_2 = matrix
    new_x = dot(row_0, point_3d)
    new_y = dot(row_1, point_3d)
    new_z = dot(row_2, point_3d)
    return (new_x, new_y, new_z)


def tip_matrix(angle_degrees):
    """Lesson 2B's TIP as a grid. x is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (1, 0,     0         ),
        (0, cos_a, (-sin_a)  ),
        (0, sin_a, cos_a     ),
    )


def turn_matrix(angle_degrees):
    """Lesson 2's TURN as a grid. y is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (cos_a, 0, (-sin_a)),
        (0,     1, 0       ),
        (sin_a, 0, cos_a   ),
    )


def roll_matrix(angle_degrees):
    """Lesson 2B's ROLL as a grid. z is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (cos_a, (-sin_a), 0),
        (sin_a, cos_a,    0),
        (0,     0,        1),
    )


def column(matrix, column_number):
    """One COLUMN of a matrix = where that axis arrow lands."""
    row_0, row_1, row_2 = matrix
    return (row_0[column_number], row_1[column_number], row_2[column_number])


def combine(first, second):
    """ONE matrix that does 'first', then 'second' (Lesson 6)."""
    new_col_0 = matrix_times_point(second, column(first, 0))
    new_col_1 = matrix_times_point(second, column(first, 1))
    new_col_2 = matrix_times_point(second, column(first, 2))
    return (
        (new_col_0[0], new_col_1[0], new_col_2[0]),
        (new_col_0[1], new_col_1[1], new_col_2[1]),
        (new_col_0[2], new_col_1[2], new_col_2[2]),
    )


def spin_matrix(angles):
    """A thing's whole spin as ONE matrix: tip, then turn, then roll."""
    tip_then_turn = combine(tip_matrix(angles[0]), turn_matrix(angles[1]))
    return combine(tip_then_turn, roll_matrix(angles[2]))

def to_world(shape_point, thing):
    """(Lesson 5) SHAPE -> WORLD: size, then spin, then place."""
    x, y, z = shape_point
    size = thing["size"]
    sized = ( (x * size), (y * size), (z * size) )
    spun = matrix_times_point(thing["matrix"], sized)
    pos_x, pos_y, pos_z = thing["position"]
    sx, sy, sz = spun
    return ( (sx + pos_x), (sy + pos_y), (sz + pos_z) )


def to_camera(world_point):
    """(Lessons 4 and 6) WORLD -> CAMERA: subtract you, then camera_matrix."""
    x, y, z = world_point
    moved = ( (x - cam_x), (y - cam_y), (z - cam_z) )
    return matrix_times_point(camera_matrix, moved)


def project(point_3d):
    """(Lesson 1) CAMERA -> SCREEN. Only call it with z >= NEAR."""
    x, y, z = point_3d
    screen_x = CENTRE_X + ( (x * FOCAL) / z )
    screen_y = CENTRE_Y - ( (y * FOCAL) / z )
    return (screen_x, screen_y)


def average_z(corners, camera_points):
    """(Lesson 3) how far away is this face? Uses CAMERA z."""
    total = 0
    for corner_number in corners:
        x, y, z = camera_points[corner_number]
        total = (total + z)
    return (total / len(corners))


def side_of_edge(start, end, point):
    """NEW (lesson Part 3): Lesson 3's clock test, for ANY 3 points.

    Walk along the edge from 'start' to 'end'. Is 'point' on your
    right-hand side (the inside of a clockwise face)?
        bigger than 0  -> yes, inside this edge
        exactly 0      -> right on the edge
        less than 0    -> no, outside

    The number is also TWICE the area of the triangle start, end, point
    (in pixels or blocks squared). Step 2 uses that.

    Worked example (lesson Part 3), in BLOCK coordinates:
        side_of_edge((100, 50), (125, 50), (110.5, 60.5))
        = ( ((125 - 100) * (60.5 - 50)) - ((50 - 50) * (110.5 - 100)) )
        = ( (25 * 10.5) - (0 * 10.5) ) = 262.5      -> inside
    """
    start_x, start_y = start
    end_x, end_y = end
    point_x, point_y = point
    arrow_a_x = (end_x - start_x)
    arrow_a_y = (end_y - start_y)
    arrow_b_x = (point_x - start_x)
    arrow_b_y = (point_y - start_y)
    return ( (arrow_a_x * arrow_b_y) - (arrow_a_y * arrow_b_x) )


def is_facing_you(face_points):
    """(Lesson 3) the clock test: True if clockwise on the screen.
    NEW: now just side_of_edge() on the face's first 3 corners."""
    return (side_of_edge(face_points[0], face_points[1], face_points[2]) > 0)


def dot(arrow_1, arrow_2):
    """(Lesson 3) the dot product."""
    x1, y1, z1 = arrow_1
    x2, y2, z2 = arrow_2
    return ( (x1 * x2) + (y1 * y2) + (z1 * z2) )


def shade_colour(colour, pointer):
    """(Lesson 3) brighter when the face points at the light."""
    brightness = dot(pointer, LIGHT)
    if brightness < 0:
        brightness = 0
    shade = ( AMBIENT + ( (1 - AMBIENT) * brightness ) )
    red, green, blue = colour
    return ( round(red * shade), round(green * shade), round(blue * shade) )


def keep_under_360(angle):
    """Keep an angle between 0 and 360."""
    if angle >= 360:
        angle = (angle - 360)
    if angle < 0:
        angle = (angle + 360)
    return angle


def add_faces_of(thing, faces_to_draw):
    """(Lesson 5) work out every face of ONE thing and add the ones to
    paint to the shared list (unchanged from Lesson 7)."""
    model = thing["model"]
    camera_points = []
    screen_points = []

def fill_triangle(a, b, c, colour):
    """NEW (lesson Part 3): fill one triangle, block by block.

    a, b, c : the corners in BLOCK coordinates (block_x, block_y),
              clockwise on the screen
    colour  : the shaded colour of the face

    1. Only look at blocks inside the triangle's bounding box.
    2. For each block, test its CENTRE (block_x + 0.5, block_y + 0.5)
       against the 3 edges, a->b, b->c and c->a.
    3. Inside all 3?  Paint it.
    """
    # Twice the area of the whole triangle. Corners in a line (a thin
    # sliver) give 0: nothing to fill.
    total = side_of_edge(a, b, c)
    if total <= 0:
        return

    a_x, a_y = a
    b_x, b_y = b
    c_x, c_y = c
    # ---- 1. the bounding box, kept inside the 200 x 150 picture ------
    # int() chops off the decimals: block 37.8 is in block 37.
    left = int(min(a_x, b_x, c_x))
    right = int(max(a_x, b_x, c_x))
    top = int(min(a_y, b_y, c_y))
    bottom = int(max(a_y, b_y, c_y))
    if left < 0:
        left = 0
    if top < 0:
        top = 0
    if right > (BLOCKS_ACROSS - 1):
        right = (BLOCKS_ACROSS - 1)
    if bottom > (BLOCKS_DOWN - 1):
        bottom = (BLOCKS_DOWN - 1)

    for block_y in range(top, (bottom + 1)):
        for block_x in range(left, (right + 1)):
            # ---- 2. the inside test, on the block's centre ------------
            # (Step 2 will call these three numbers "weights".)
            centre = ( (block_x + 0.5), (block_y + 0.5) )
            weight_a = side_of_edge(b, c, centre)   # the edge b -> c
            weight_b = side_of_edge(c, a, centre)   # the edge c -> a
            weight_c = side_of_edge(a, b, centre)   # the edge a -> b
            if (weight_a < 0) or (weight_b < 0) or (weight_c < 0):
                continue                            # outside: next block
            # ---- 3. inside all three edges: paint it -----------------
            small.set_at((block_x, block_y), colour)


def draw_face(face_points, colour):
    """NEW (lesson Part 3): fill one face. A 4-corner face is cut into
    2 triangles, both starting at corner 0:
        corners 0, 1, 2   and   corners 0, 2, 3
    Both stay clockwise, like the face.

    The face's corners come in SCREEN pixels. Dividing by BLOCK (4)
    turns them into BLOCK coordinates: SCREEN (500, 200) -> (125, 50).
    """
    blocks = []
    for screen_x, screen_y in face_points:
        blocks.append( ((screen_x / BLOCK), (screen_y / BLOCK)) )
    fill_triangle(blocks[0], blocks[1], blocks[2], colour)
    if len(blocks) == 4:
        fill_triangle(blocks[0], blocks[2], blocks[3], colour)

Part 4: The depth buffer 14 MIN

Now the real idea. Next to the small picture, we keep a list of numbers: one number for each of its 30,000 blocks. Each number is the CAMERA z of the closest thing painted on that block so far. That list is the depth buffer.

FAR = 1000

def clear_depth():
    global depth
    depth = []
    for row in range(BLOCKS_DOWN):
        depth.append([FAR] * BLOCKS_ACROSS)

depth is a list of 150 rows, each a list of 200 numbers, so depth[57][124] is the block 124 across and 57 down: row first, like reading a page. [FAR] * 200 makes a list of 200 copies of FAR in one go. At the start of every frame every block holds FAR = 1000, which means "nothing painted here yet". Everything in our world is much closer than 1000 (the walls are 12 away), so the first face to reach a block always wins it. Lesson 7 used the same trick for the nearest cube: start with a huge number and keep the smallest. global depth lets the function replace the depth list the rest of the program uses.

The rule

For each block a triangle covers, we work out how far away the triangle is at that block (its z: below, we see how). Then:

if z < depth[block_y][block_x]:
    depth[block_y][block_x] = z                  # remember the new closest
    small.set_at((block_x, block_y), colour)      # and paint it
# otherwise do nothing: something closer is already there

One comparison per block. A face can only paint where it is closer than everything painted so far, so whatever order the faces arrive in, the closest one is always what you see.

The z of one block: weights

We only know z at a triangle's three corners. For a block inside, we blend the three corners: the closer the block is to a corner, the more of that corner's z it gets. The amounts are the three numbers the inside test already worked out. Each one is the area (times 2) of the piece of the triangle opposite one corner:

When P sits right on corner a, the piece opposite a is the whole triangle and the other two pieces are nothing, so we get exactly corner a's z. In the middle, we get a mix. Divided by the total, the three shares always add up to 1.

Blend (1 / z), not z

You might expect z = ( ( (weight_a * z_a) + (weight_b * z_b) + (weight_c * z_c) ) / total ). It looks right, but it is wrong for any face that goes away from you, and the board does. The reason is Lesson 1: screen positions are made by dividing by z. Lesson 5's floor shows it best:

So the code blends (1 / z) and turns the answer back into z at the end. (weight_a / z_a) is just (weight_a * (1 / z_a)) written shorter:

one_over_z = ( ( (weight_a / z_a) + (weight_b / z_b) + (weight_c / z_c) ) / total )
z = (1 / one_over_z)

How much does it matter? We checked every block of the test scene against the exact answer. Blending (1 / z) is exact. Blending plain z is off by up to 0.96 on the board's top (6.446 instead of 5.482), and that is enough to change the winner on 270 blocks near the line where the board meets the cube: the crossing comes out in the wrong place.

def matrix_times_point(matrix, point_3d):
    """Put one point through a matrix: each ROW dotted with the point."""
    row_0, row_1, row_2 = matrix
    new_x = dot(row_0, point_3d)
    new_y = dot(row_1, point_3d)
    new_z = dot(row_2, point_3d)
    return (new_x, new_y, new_z)


def tip_matrix(angle_degrees):
    """Lesson 2B's TIP as a grid. x is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (1, 0,     0         ),
        (0, cos_a, (-sin_a)  ),
        (0, sin_a, cos_a     ),
    )


def turn_matrix(angle_degrees):
    """Lesson 2's TURN as a grid. y is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (cos_a, 0, (-sin_a)),
        (0,     1, 0       ),
        (sin_a, 0, cos_a   ),
    )


def roll_matrix(angle_degrees):
    """Lesson 2B's ROLL as a grid. z is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (cos_a, (-sin_a), 0),
        (sin_a, cos_a,    0),
        (0,     0,        1),
    )


def column(matrix, column_number):
    """One COLUMN of a matrix = where that axis arrow lands."""
    row_0, row_1, row_2 = matrix
    return (row_0[column_number], row_1[column_number], row_2[column_number])


def combine(first, second):
    """ONE matrix that does 'first', then 'second' (Lesson 6)."""
    new_col_0 = matrix_times_point(second, column(first, 0))
    new_col_1 = matrix_times_point(second, column(first, 1))
    new_col_2 = matrix_times_point(second, column(first, 2))
    return (
        (new_col_0[0], new_col_1[0], new_col_2[0]),
        (new_col_0[1], new_col_1[1], new_col_2[1]),
        (new_col_0[2], new_col_1[2], new_col_2[2]),
    )


def spin_matrix(angles):
    """A thing's whole spin as ONE matrix: tip, then turn, then roll."""
    tip_then_turn = combine(tip_matrix(angles[0]), turn_matrix(angles[1]))
    return combine(tip_then_turn, roll_matrix(angles[2]))

def to_world(shape_point, thing):
    """(Lesson 5) SHAPE -> WORLD: size, then spin, then place."""
    x, y, z = shape_point
    size = thing["size"]
    sized = ( (x * size), (y * size), (z * size) )
    spun = matrix_times_point(thing["matrix"], sized)
    pos_x, pos_y, pos_z = thing["position"]
    sx, sy, sz = spun
    return ( (sx + pos_x), (sy + pos_y), (sz + pos_z) )


def to_camera(world_point):
    """(Lessons 4 and 6) WORLD -> CAMERA: subtract you, then camera_matrix."""
    x, y, z = world_point
    moved = ( (x - cam_x), (y - cam_y), (z - cam_z) )
    return matrix_times_point(camera_matrix, moved)


def project(point_3d):
    """(Lesson 1) CAMERA -> SCREEN. Only call it with z >= NEAR."""
    x, y, z = point_3d
    screen_x = CENTRE_X + ( (x * FOCAL) / z )
    screen_y = CENTRE_Y - ( (y * FOCAL) / z )
    return (screen_x, screen_y)


def average_z(corners, camera_points):
    """(Lesson 3) how far away is this face? Uses CAMERA z.
    Only the painter's order (P) still needs it."""
    total = 0
    for corner_number in corners:
        x, y, z = camera_points[corner_number]
        total = (total + z)
    return (total / len(corners))


def side_of_edge(start, end, point):
    """(step 1, lesson Part 3) Lesson 3's clock test, for ANY 3 points.

    Walk along the edge from 'start' to 'end'. Is 'point' on your
    right-hand side (the inside of a clockwise face)?
        bigger than 0  -> yes, inside this edge
        exactly 0      -> right on the edge
        less than 0    -> no, outside

    The number is also TWICE the area of the triangle start, end, point
    (in pixels or blocks squared). Part 4 uses that.

    Worked example (lesson Part 3), in BLOCK coordinates:
        side_of_edge((100, 50), (125, 50), (110.5, 60.5))
        = ( ((125 - 100) * (60.5 - 50)) - ((50 - 50) * (110.5 - 100)) )
        = ( (25 * 10.5) - (0 * 10.5) ) = 262.5      -> inside
    """
    start_x, start_y = start
    end_x, end_y = end
    point_x, point_y = point
    arrow_a_x = (end_x - start_x)
    arrow_a_y = (end_y - start_y)
    arrow_b_x = (point_x - start_x)
    arrow_b_y = (point_y - start_y)
    return ( (arrow_a_x * arrow_b_y) - (arrow_a_y * arrow_b_x) )


def is_facing_you(face_points):
    """(Lesson 3) the clock test: True if clockwise on the screen.
    (step 1) Now just side_of_edge() on the face's first 3 corners."""
    return (side_of_edge(face_points[0], face_points[1], face_points[2]) > 0)


def dot(arrow_1, arrow_2):
    """(Lesson 3) the dot product."""
    x1, y1, z1 = arrow_1
    x2, y2, z2 = arrow_2
    return ( (x1 * x2) + (y1 * y2) + (z1 * z2) )


def shade_colour(colour, pointer):
    """(Lesson 3) brighter when the face points at the light."""
    brightness = dot(pointer, LIGHT)
    if brightness < 0:
        brightness = 0
    shade = ( AMBIENT + ( (1 - AMBIENT) * brightness ) )
    red, green, blue = colour
    return ( round(red * shade), round(green * shade), round(blue * shade) )


def keep_under_360(angle):
    """Keep an angle between 0 and 360."""
    if angle >= 360:
        angle = (angle - 360)
    if angle < 0:
        angle = (angle + 360)
    return angle


def add_faces_of(thing, faces_to_draw):
    """(Lesson 5) work out every face of ONE thing and add the ones to
    paint to the shared list.

    (step 1) Each face now also keeps its corners' CAMERA z numbers
    (face_depths), because filling and the depth buffer need them.
    """
    model = thing["model"]
    camera_points = []
    screen_points = []
    for p in model["points"]:
        world = to_world(p, thing)                     # WORLD
        camera = to_camera(world)                      # CAMERA
        camera_points.append(camera)
        if camera[2] >= NEAR:
            screen_points.append(project(camera))      # SCREEN
        else:
            screen_points.append(None)

    for corners, face_colour, pointer in model["faces"]:
        too_close = False
        for corner_number in corners:
            if camera_points[corner_number][2] < NEAR:
                too_close = True
        if too_close:
            continue
        face_points = []
        face_depths = []                               # (step 1)
        for corner_number in corners:
            face_points.append(screen_points[corner_number])
            face_depths.append(camera_points[corner_number][2])
        if not is_facing_you(face_points):
            continue
        distance = average_z(corners, camera_points)
        colour = thing["colour"]
        if use_light:
            spun_pointer = matrix_times_point(thing["matrix"], pointer)
            colour = shade_colour(colour, spun_pointer)
        faces_to_draw.append( (distance, face_points, face_depths, colour) )

def clear_depth():
    """NEW (lesson Part 4): a fresh depth buffer for a new frame.

    150 rows, each a list of 200 copies of FAR:
        depth[0]       is the top row of blocks
        depth[149]     is the bottom row
        depth[50][125] is the block 125 across and 50 down
    [FAR] * 200 makes a list of 200 FARs in one go (lists course).
    """
    global depth
    depth = []
    for row in range(BLOCKS_DOWN):
        depth.append([FAR] * BLOCKS_ACROSS)


def fill_triangle(a, b, c, z_a, z_b, z_c, colour):
    """Fill one triangle, block by block (step 1, lesson Part 3), with
    the depth buffer check (NEW, lesson Part 4).

    a, b, c        : the corners in BLOCK coordinates (block_x, block_y),
                     clockwise on the screen
    z_a, z_b, z_c  : the CAMERA z of each corner (how far away it is)
    colour         : the shaded colour of the face

    1. Only look at blocks inside the triangle's bounding box.
    2. For each block, test its CENTRE (block_x + 0.5, block_y + 0.5)
       against the 3 edges, a->b, b->c and c->a.
    3. Inside all 3?  Blend the corners' z to get this block's z.
    4. Closer than what the depth buffer holds?  Paint it, remember z.
    """
    # Twice the area of the whole triangle. Corners in a line (a thin
    # sliver) give 0: nothing to fill, and we must not divide by 0.
    total = side_of_edge(a, b, c)
    if total <= 0:
        return

    a_x, a_y = a
    b_x, b_y = b
    c_x, c_y = c
    # ---- 1. the bounding box, kept inside the 200 x 150 picture ------
    # int() chops off the decimals: block 37.8 is in block 37.
    left = int(min(a_x, b_x, c_x))
    right = int(max(a_x, b_x, c_x))
    top = int(min(a_y, b_y, c_y))
    bottom = int(max(a_y, b_y, c_y))
    if left < 0:
        left = 0
    if top < 0:
        top = 0
    if right > (BLOCKS_ACROSS - 1):
        right = (BLOCKS_ACROSS - 1)
    if bottom > (BLOCKS_DOWN - 1):
        bottom = (BLOCKS_DOWN - 1)

    for block_y in range(top, (bottom + 1)):
        for block_x in range(left, (right + 1)):
            # ---- 2. the inside test, on the block's centre ------------
            centre = ( (block_x + 0.5), (block_y + 0.5) )
            weight_a = side_of_edge(b, c, centre)   # the piece opposite a
            weight_b = side_of_edge(c, a, centre)   # the piece opposite b
            weight_c = side_of_edge(a, b, centre)   # the piece opposite c
            if (weight_a < 0) or (weight_b < 0) or (weight_c < 0):
                continue                            # outside: next block

            # ---- 3. NEW: this block's z, blended from the corners -----
            # Each weight is the area of the piece of triangle OPPOSITE
            # that corner. Divided by the whole area, the three always
            # add up to 1. Right on corner a: weight_a = total, so the
            # blend gives exactly corner a's number.
            # We blend (1 / z) and turn the answer back into z. Blending
            # z itself puts some blocks of a tipped face nearly 1 unit
            # too far away (lesson Part 4 has the numbers).
            #   (weight_a / z_a) is the same as (weight_a * (1 / z_a)).
            one_over_z = ( ( (weight_a / z_a) + (weight_b / z_b) + (weight_c / z_c) ) / total )
            z = (1 / one_over_z)

            # ---- 4. NEW: the depth buffer rule --------------------------
            if use_depth:
                if z < depth[block_y][block_x]:
                    depth[block_y][block_x] = z
                    small.set_at((block_x, block_y), colour)
            else:
                # P pressed: the old way. Paint over whatever is there.
                small.set_at((block_x, block_y), colour)


def draw_face(face_points, face_depths, colour):
    """(step 1, lesson Part 3) fill one face: a 4-corner face is cut
    into 2 triangles, both starting at corner 0:
        corners 0, 1, 2   and   corners 0, 2, 3
    Both stay clockwise, like the face.

    The face's corners come in SCREEN pixels. Dividing by BLOCK (4)
    turns them into BLOCK coordinates: SCREEN (500, 200) -> (125, 50).
    """
    blocks = []
    for screen_x, screen_y in face_points:
        blocks.append( ((screen_x / BLOCK), (screen_y / BLOCK)) )
    fill_triangle(blocks[0], blocks[1], blocks[2],
                  face_depths[0], face_depths[1], face_depths[2], colour)
    if len(blocks) == 4:
        fill_triangle(blocks[0], blocks[2], blocks[3],
                      face_depths[0], face_depths[2], face_depths[3], colour)


def draw_depth_as_grey():
    """NEW (Z key, lesson Part 4): paint every block a grey that shows
    the number in the depth buffer. Closer = brighter:
        grey = (765 / z), at most 255
        z 3 -> 255 (white),  z 6 -> 128,  z 12 -> 64,  FAR -> 1 (black)
    765 = (255 * 3): anything 3 or closer is full white. The test
    scene is 3.6 to 8.4 away, so it comes out from 213 down to 91.
    """
    for block_y in range(BLOCKS_DOWN):
        for block_x in range(BLOCKS_ACROSS):
            z = depth[block_y][block_x]
            grey = round(765 / z)
            if grey > 255:
                grey = 255
            small.set_at((block_x, block_y), (grey, grey, grey))

Q6A block's depth buffer holds 6.2. Triangle X reaches it with z 6.5, then triangle Y with z 5.9. What does the block end up holding, and which colour?

Show answer

X: is 6.5 < 6.2? No, so skip. Y: is 5.9 < 6.2? Yes, so store 5.9 and paint Y's colour. The block holds 5.9 and shows Y.

Q7A block has shares 0.5, 0.25 and 0.25 of corners with z 4, 8 and 8. What is its z? What would blending plain z give?

Show answer

1 / z: (1 / 4) = 0.25, (1 / 8) = 0.125, 0.125. Blend: ( (0.5 * 0.25) + (0.25 * 0.125) + (0.25 * 0.125) ) = (0.125 + 0.03125 + 0.03125) = 0.1875. z = (1 / 0.1875) = 5.333.

Plain z: ( (0.5 * 4) + (0.25 * 8) + (0.25 * 8) ) = (2 + 2 + 2) = 6, two thirds of a unit too far.

Q8Why does every block start at FAR = 1000 and not at 0?

Show answer

The rule only paints when the new z is smaller than the stored one. Nothing in front of you has z below NEAR = 0.1, so with 0 stored no face could ever be smaller, and nothing would be painted. 1000 is bigger than anything in the world, so the first face always wins.

Show answer

(765 / 7.5) = 102. (765 / 2) = 382.5, which is more than 255, so it is kept at 255: white.

In the game, with a rock filling most of the window, we measured about 31 ms (32 a second): still playable. Step 3 shows "frames a second" on the HUD so you can watch it happen. This is why real games do the depth buffer in the graphics card, which checks millions of pixels at once.

def matrix_times_point(matrix, point_3d):
    """Put one point through a matrix: each ROW dotted with the point."""
    row_0, row_1, row_2 = matrix
    new_x = dot(row_0, point_3d)
    new_y = dot(row_1, point_3d)
    new_z = dot(row_2, point_3d)
    return (new_x, new_y, new_z)


def tip_matrix(angle_degrees):
    """Lesson 2B's TIP as a grid. x is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (1, 0,     0         ),
        (0, cos_a, (-sin_a)  ),
        (0, sin_a, cos_a     ),
    )


def turn_matrix(angle_degrees):
    """Lesson 2's TURN as a grid. y is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (cos_a, 0, (-sin_a)),
        (0,     1, 0       ),
        (sin_a, 0, cos_a   ),
    )


def roll_matrix(angle_degrees):
    """Lesson 2B's ROLL as a grid. z is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (cos_a, (-sin_a), 0),
        (sin_a, cos_a,    0),
        (0,     0,        1),
    )


def column(matrix, column_number):
    """One COLUMN of a matrix = where that axis arrow lands."""
    row_0, row_1, row_2 = matrix
    return (row_0[column_number], row_1[column_number], row_2[column_number])


def combine(first, second):
    """ONE matrix that does 'first', then 'second' (Lesson 6)."""
    new_col_0 = matrix_times_point(second, column(first, 0))
    new_col_1 = matrix_times_point(second, column(first, 1))
    new_col_2 = matrix_times_point(second, column(first, 2))
    return (
        (new_col_0[0], new_col_1[0], new_col_2[0]),
        (new_col_0[1], new_col_1[1], new_col_2[1]),
        (new_col_0[2], new_col_1[2], new_col_2[2]),
    )


def spin_matrix(angles):
    """A thing's whole spin as ONE matrix: tip, then turn, then roll."""
    tip_then_turn = combine(tip_matrix(angles[0]), turn_matrix(angles[1]))
    return combine(tip_then_turn, roll_matrix(angles[2]))

def to_world(shape_point, thing):
    """(Lesson 5) SHAPE -> WORLD: size, then spin, then place."""
    x, y, z = shape_point
    size = thing["size"]
    sized = ( (x * size), (y * size), (z * size) )
    spun = matrix_times_point(thing["matrix"], sized)
    pos_x, pos_y, pos_z = thing["position"]
    sx, sy, sz = spun
    return ( (sx + pos_x), (sy + pos_y), (sz + pos_z) )


def to_camera(world_point):
    """(Lessons 4 and 6) WORLD -> CAMERA: subtract you, then camera_matrix."""
    x, y, z = world_point
    moved = ( (x - cam_x), (y - cam_y), (z - cam_z) )
    return matrix_times_point(camera_matrix, moved)


def project(point_3d):
    """(Lesson 1) CAMERA -> SCREEN. Only call it with z >= NEAR."""
    x, y, z = point_3d
    screen_x = CENTRE_X + ( (x * FOCAL) / z )
    screen_y = CENTRE_Y - ( (y * FOCAL) / z )
    return (screen_x, screen_y)


def average_z(corners, camera_points):
    """(Lesson 3) how far away is this face? Uses CAMERA z.
    NEW: nothing is sorted by it any more. It is kept so that you
    can put faces_to_draw.sort(reverse=True) back in to compare."""
    total = 0
    for corner_number in corners:
        x, y, z = camera_points[corner_number]
        total = (total + z)
    return (total / len(corners))


def side_of_edge(start, end, point):
    """NEW (step 1, lesson Part 3): Lesson 3's clock test, for ANY 3 points.

    Walk along the edge from 'start' to 'end'. Is 'point' on your
    right-hand side (the inside of a clockwise face)?
        bigger than 0  -> yes, inside this edge
        exactly 0      -> right on the edge
        less than 0    -> no, outside

    The number is also TWICE the area of the triangle start, end, point
    (in pixels or blocks squared). lesson Part 4 uses that.

    Worked example (lesson Part 3), in BLOCK coordinates:
        side_of_edge((100, 50), (125, 50), (110.5, 60.5))
        = ( ((125 - 100) * (60.5 - 50)) - ((50 - 50) * (110.5 - 100)) )
        = ( (25 * 10.5) - (0 * 10.5) ) = 262.5      -> inside
    """
    start_x, start_y = start
    end_x, end_y = end
    point_x, point_y = point
    arrow_a_x = (end_x - start_x)
    arrow_a_y = (end_y - start_y)
    arrow_b_x = (point_x - start_x)
    arrow_b_y = (point_y - start_y)
    return ( (arrow_a_x * arrow_b_y) - (arrow_a_y * arrow_b_x) )


def is_facing_you(face_points):
    """(Lesson 3) the clock test: True if clockwise on the screen.
    NEW: now just side_of_edge() on the face's first 3 corners."""
    return (side_of_edge(face_points[0], face_points[1], face_points[2]) > 0)


def dot(arrow_1, arrow_2):
    """(Lesson 3) the dot product."""
    x1, y1, z1 = arrow_1
    x2, y2, z2 = arrow_2
    return ( (x1 * x2) + (y1 * y2) + (z1 * z2) )


def shade_colour(colour, pointer):
    """(Lesson 3) brighter when the face points at the light."""
    brightness = dot(pointer, LIGHT)
    if brightness < 0:
        brightness = 0
    shade = ( AMBIENT + ( (1 - AMBIENT) * brightness ) )
    red, green, blue = colour
    return ( round(red * shade), round(green * shade), round(blue * shade) )


def keep_under_360(angle):
    """Keep an angle between 0 and 360."""
    if angle >= 360:
        angle = (angle - 360)
    if angle < 0:
        angle = (angle + 360)
    return angle


def add_faces_of(thing, faces_to_draw):
    """(Lesson 5) work out every face of ONE thing and add the ones to
    paint to the shared list.

    NEW (Lesson 10): each face also keeps the CAMERA z of every corner
    left after clipping (face_depths): the depth buffer needs them.

    (Lesson 8) each face is CLIPPED in CAMERA coordinates first,
    and only then projected. So we no longer project every corner up
    front: a face's cut points only exist once that face is clipped.
    """
    model = thing["model"]
    camera_points = []
    for p in model["points"]:
        world = to_world(p, thing)                     # WORLD
        camera_points.append(to_camera(world))         # CAMERA

    for corners, face_colour, pointer in model["faces"]:
        # (Lesson 8) this face's corners in CAMERA coordinates, clockwise.
        face_camera = []
        for corner_number in corners:
            face_camera.append(camera_points[corner_number])

        if use_clipping:
            # (Lesson 8) cut the face at the NEAR wall (Lesson 8 Part 3).
            face_camera = clip_face(face_camera)
            # Fewer than 3 corners left: nothing to paint.
            if len(face_camera) < 3:
                continue
        else:
            # Lesson 4's old rule, for comparing (K): any corner behind
            # the NEAR wall? Skip the whole face.
            too_close = False
            for camera in face_camera:
                if camera[2] < NEAR:
                    too_close = True
            if too_close:
                continue

        # Every corner left is now in front of NEAR, so project() is safe.
        face_points = []
        face_depths = []                               # NEW
        for camera in face_camera:
            face_points.append(project(camera))        # SCREEN
            face_depths.append(camera[2])              # NEW: its CAMERA z
        # The clock test works on any number of corners (it only looks
        # at the first 3), and clipping keeps them clockwise.
        if not is_facing_you(face_points):
            continue
        distance = average_z(corners, camera_points)
        colour = thing["colour"]
        if use_light:
            spun_pointer = matrix_times_point(thing["matrix"], pointer)
            colour = shade_colour(colour, spun_pointer)
        faces_to_draw.append( (distance, face_points, face_depths, colour) )

def clear_depth():

def fill_triangle(a, b, c, z_a, z_b, z_c, colour):
    """Fill one triangle, block by block (step 1, lesson Part 3), with
    the depth buffer check (step 2, lesson Part 4).

    a, b, c        : the corners in BLOCK coordinates (block_x, block_y),
                     clockwise on the screen
    z_a, z_b, z_c  : the CAMERA z of each corner (how far away it is)
    colour         : the shaded colour of the face

    1. Only look at blocks inside the triangle's bounding box.
    2. For each block, test its CENTRE (block_x + 0.5, block_y + 0.5)
       against the 3 edges, a->b, b->c and c->a.
    3. Inside all 3?  Blend the corners' z to get this block's z.
    4. Closer than what the depth buffer holds?  Paint it, remember z.
    """
    # Twice the area of the whole triangle. Corners in a line (a thin
    # sliver) give 0: nothing to fill, and we must not divide by 0.
    total = side_of_edge(a, b, c)
    if total <= 0:
        return

    a_x, a_y = a
    b_x, b_y = b
    c_x, c_y = c
    # ---- 1. the bounding box, kept inside the 200 x 150 picture ------
    # int() chops off the decimals: block 37.8 is in block 37.
    left = int(min(a_x, b_x, c_x))
    right = int(max(a_x, b_x, c_x))
    top = int(min(a_y, b_y, c_y))
    bottom = int(max(a_y, b_y, c_y))
    if left < 0:
        left = 0
    if top < 0:
        top = 0
    if right > (BLOCKS_ACROSS - 1):
        right = (BLOCKS_ACROSS - 1)
    if bottom > (BLOCKS_DOWN - 1):
        bottom = (BLOCKS_DOWN - 1)

    for block_y in range(top, (bottom + 1)):
        for block_x in range(left, (right + 1)):
            # ---- 2. the inside test, on the block's centre ------------
            centre = ( (block_x + 0.5), (block_y + 0.5) )
            weight_a = side_of_edge(b, c, centre)   # the piece opposite a
            weight_b = side_of_edge(c, a, centre)   # the piece opposite b
            weight_c = side_of_edge(a, b, centre)   # the piece opposite c
            if (weight_a < 0) or (weight_b < 0) or (weight_c < 0):
                continue                            # outside: next block

            # ---- 3. this block's z, blended from the corners -----
            # Each weight is the area of the piece of triangle OPPOSITE
            # that corner. Divided by the whole area, the three always
            # add up to 1. Right on corner a: weight_a = total, so the
            # blend gives exactly corner a's number.
            # We blend (1 / z) and turn the answer back into z. Blending
            # z itself puts some blocks of a tipped face nearly 1 unit
            # too far away (lesson Part 4 has the numbers).
            #   (weight_a / z_a) is the same as (weight_a * (1 / z_a)).
            one_over_z = ( ( (weight_a / z_a) + (weight_b / z_b) + (weight_c / z_c) ) / total )
            z = (1 / one_over_z)

            # ---- 4. the depth buffer rule -------------------------------
            if z < depth[block_y][block_x]:
                depth[block_y][block_x] = z
                small.set_at((block_x, block_y), colour)


def draw_face(face_points, face_depths, colour):
    """(step 1, lesson Part 3) fill one face, as triangles.

    NEW (lesson Part 5): after Lesson 8's clipping a face can have 3, 4
    or 5 corners, so we cut it like a fan, every triangle starting at
    corner 0:
        3 corners: 0,1,2
        4 corners: 0,1,2   0,2,3
        5 corners: 0,1,2   0,2,3   0,3,4
    A face with N corners makes (N - 2) triangles, all clockwise.

    The corners come in SCREEN pixels. Dividing by BLOCK (4) turns them
    into BLOCK coordinates: SCREEN (500, 200) -> (125, 50).
    """
    blocks = []
    for screen_x, screen_y in face_points:
        blocks.append( ((screen_x / BLOCK), (screen_y / BLOCK)) )
    # corner_number goes 1, 2, ... up to (N - 2): one triangle each.
    for corner_number in range(1, (len(blocks) - 1)):
        next_number = (corner_number + 1)
        fill_triangle(blocks[0], blocks[corner_number], blocks[next_number],
                      face_depths[0], face_depths[corner_number],
                      face_depths[next_number], colour)

# CLIPPING (Lesson 8)
# ======================================================================
# Everything here works in CAMERA coordinates: (0, 0, 0) is your eye,
# +x is right, +y is up, +z is straight ahead. The NEAR wall is the
# flat sheet z = NEAR (0.1) just in front of your eye.
#   "in"  = in front of the wall:  z >= NEAR   (safe to project)
#   "out" = behind the wall:       z <  NEAR   (must never be projected)

def cut_at_near(point_a, point_b):
    """(Lesson 8): the CAMERA point where the line from point_a to point_b
    crosses the NEAR wall. One end must be in, the other out.

    t says how far along the line the wall is: 0 = at point_a,
    1 = at point_b, 0.5 = halfway (Lesson 8 Part 2).

        t = ( (NEAR - a_z) / (b_z - a_z) )

    Then each of x and y moves the same fraction t of its own gap:

        x = ( a_x + (t * (b_x - a_x)) )

    Worked example (Lesson 8 Part 2): a = (-2, -1, -1), b = (2, -1, 3)
        t = ( (0.1 - (-1)) / (3 - (-1)) ) = (1.1 / 4) = 0.275
        x = ( -2 + (0.275 * (2 - (-2))) ) = ( -2 + 1.1 ) = -0.9
        y = ( -1 + (0.275 * (-1 - (-1))) ) = -1
        z = NEAR = 0.1          -> (-0.9, -1, 0.1)
    """
    a_x, a_y, a_z = point_a
    b_x, b_y, b_z = point_b
    t = ( (NEAR - a_z) / (b_z - a_z) )
    cut_x = ( a_x + (t * (b_x - a_x)) )
    cut_y = ( a_y + (t * (b_y - a_y)) )
    # The same sum for z would give exactly NEAR, which is the whole
    # point of t, so we just use NEAR.
    return (cut_x, cut_y, NEAR)


def clip_line(start, end):
    """(Lesson 8): keep the part of a CAMERA line that is in front of NEAR.

    Gives back (start, end) with any end behind you swapped for the
    cut point, or None ("nothing to draw") if both ends are behind.
    """
    start_in = (start[2] >= NEAR)
    end_in = (end[2] >= NEAR)
    if start_in and end_in:
        return (start, end)                       # all in front: keep it all
    if (not start_in) and (not end_in):
        return None                               # all behind: nothing
    cut = cut_at_near(start, end)
    if start_in:
        return (start, cut)                       # end was behind
    return (cut, end)                             # start was behind


def clip_face(face_corners):
    """(Lesson 8) cut one face at the NEAR wall (Lesson 8 Part 3).

    face_corners: the face's corners in CAMERA coordinates, clockwise.
    Gives back the corners of the part in front of NEAR, still in
    clockwise order. That can be 3, 4 or 5 corners, or an empty list
    if the whole face is behind you.

    We walk round the face one edge at a time. Each edge goes from the
    PREVIOUS corner to the CURRENT one, and there are only 4 cases:

        previous  current   keep
        in        in        current
        in        out       the cut point
        out       in        the cut point, then current
        out       out       nothing

    face_corners[-1] means "the LAST item in the list". Starting with
    it as "previous" makes the first edge go last corner -> first
    corner, so the walk goes all the way round and closes the face.

    Worked example (Lesson 8 Part 3): the right face of rock 0, seen from
    WORLD (2.5, 0, 3). CAMERA corners in clockwise order:
        5 (-1, 2, -0.5) out    6 (-1, 2, 2.5) in
        2 (-1, -1, 2.5) in     1 (-1, -1, -0.5) out
    Edges 1->5 nothing,  5->6 cut (-1, 2, 0.1) then 6,
          6->2 keep 2,    2->1 cut (-1, -1, 0.1)
    Result: 4 corners  (-1, 2, 0.1) (-1, 2, 2.5) (-1, -1, 2.5) (-1, -1, 0.1)
    """
    kept = []
    previous = face_corners[-1]
    for current in face_corners:
        previous_in = (previous[2] >= NEAR)
        current_in = (current[2] >= NEAR)
        if previous_in and current_in:
            kept.append(current)
        elif previous_in and (not current_in):
            kept.append(cut_at_near(previous, current))
        elif (not previous_in) and current_in:
            kept.append(cut_at_near(previous, current))
            kept.append(current)
        # out -> out: keep nothing
        previous = current
    return kept

def distance_3d(point_a, point_b):
    """(Lesson 7) how far apart are two WORLD points? (Lesson 7 Part 2)

    Subtract, square each part, add them up, square-root the total:
    Pythagoras done twice, in one line.

    Worked example (Lesson 7 Part 2): you at (1, 0, 3), cube 0 at (3, 1, 5)
        dx = (3 - 1) = 2,  dy = (1 - 0) = 1,  dz = (5 - 3) = 2
        math.sqrt( (2 * 2) + (1 * 1) + (2 * 2) ) = math.sqrt(9) = 3
    """
    ax, ay, az = point_a
    bx, by, bz = point_b
    dx = (bx - ax)
    dy = (by - ay)
    dz = (bz - az)
    return math.sqrt( (dx * dx) + (dy * dy) + (dz * dz) )


def far_from_rocks(spot):
    """(Lesson 8): True if this WORLD spot is at least ROCK_CLEARANCE (3) from
    the centre of every rock, so a new gold cube never hides inside one.

    Worked example (Lesson 8 Part 1): spot (1, 1, 5) and rock 0 at
    (0, 0.5, 4): math.sqrt( (1 * 1) + (0.5 * 0.5) + (1 * 1) ) = 1.5,
    less than 3, so False: try again.
    """
    for rock_spot in ROCK_SPOTS:
        if distance_3d(spot, rock_spot) < ROCK_CLEARANCE:
            return False
    return True


def new_pickup_spot():
    """(Lesson 7) a random WORLD spot for a cube, at least
    MIN_SPAWN_DISTANCE from you (Lesson 7 Part 4).

    "while True" repeats for ever, until "return" jumps out. Usually the
    first try is far enough; about 1 try in 5 is too close and we
    simply pick again.
    """
    you = (cam_x, cam_y, cam_z)
    while True:
        new_x = random.uniform((-FIELD), FIELD)
        new_y = random.uniform(PICKUP_LOW, PICKUP_HIGH)
        new_z = random.uniform((-FIELD), FIELD)
        spot = (new_x, new_y, new_z)
        # (Lesson 8): "and far_from_rocks(spot)": BOTH must be True.
        if (distance_3d(you, spot) >= MIN_SPAWN_DISTANCE) and far_from_rocks(spot):
            return spot

((2.1 / 16.7) * 100) = about 13% of one frame: you could draw 7 faces that size and still keep 60 frames a second.

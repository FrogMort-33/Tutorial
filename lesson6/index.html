Matrices

Since Lesson 2 every turn has been its own little formula: tip, turn, roll, then undo your turn and undo your tip. Today we pack each turn into a 3 × 3 grid of numbers called a matrix, and then join several grids into one. The picture on the screen does not change at all. What changes is how much work the computer does to draw it, and how tidy the code is. This is how real 3D engines store every turn.

Where this lesson fits

Before: Lesson 5, A small world, filled the world with seven shapes and a floor grid.
Today: every turn becomes a matrix, so the same world is drawn with far fewer cos and sin calls.
Next: Lesson 7, A mini game, flies the camera round the world to collect cubes, using today's tidy code.

Lesson 6 adds no new picture. It is a "tidy-up" lesson: everything you see stays exactly the same, which makes it a good place to check your understanding of Lessons 2 to 5.

Part 1: What is a matrix? 8 MIN

A matrix (plural: matrices) is a grid of numbers. Ours are always 3 rows by 3 columns, because a point has 3 numbers going in (x, y, z) and 3 numbers coming out (new x, new y, new z). Here is the first one we will use. It is Lesson 2's "turn by 30°" rule; Part 3 shows where every number comes from.

Matrix × point

To put a point through a matrix, take each row in turn and do Lesson 3's dot product with the point: multiply the first numbers together, the second numbers together, the third numbers together, then add the three answers. Row 0 gives the new x, row 1 the new y, row 2 the new z.

In code it is three calls to the dot() function you already have:

def matrix_times_point(matrix, point_3d):
    row_0, row_1, row_2 = matrix
    new_x = dot(row_0, point_3d)
    new_y = dot(row_1, point_3d)
    new_z = dot(row_2, point_3d)
    return (new_x, new_y, new_z)

Q1Put corner 0, SHAPE (−1, −1, −1), through turn_30. Where does it end up?

Show answer

new_x = (0.866 * -1) + (0 * -1) + (-0.5 * -1) = (−0.866) + (0) + (0.5) = −0.366.

new_y = (0 * -1) + (1 * -1) + (0 * -1) = −1.

new_z = (0.5 * -1) + (0 * -1) + (0.866 * -1) = (−0.5) + (0) + (−0.866) = −1.366.

(−0.366, −1, −1.366): the same as rotate_y((-1, -1, -1), 30).

Q2What is turn_30[0][2], and which letter of the point does it multiply?

Show answer

Row 0, column 2: −0.5. Column 2 always multiplies z, and row 0 makes the new x. So it is the "(-0.5 * z)" part of new_x.

Part 2: Two warm-up grids 4 MIN

Before turning anything, two simpler grids show what the numbers do. Think of each grid as a machine: point in, point out. The diagonal (top-left to bottom-right) says how much of each letter to keep; the other six numbers mix the letters together.

The do-nothing grid (the identity)

1s down the diagonal, 0s everywhere else. Whatever goes in comes out unchanged. You'll meet it again: turning by 0° gives exactly this grid, and so does turning one way and then back again.

Q3Make a grid that squashes the cube to half its height. What does it do to corner 5?

Show answer

((1, 0, 0), (0, 0.5, 0), (0, 0, 1)): keep all of x and z, keep half of y. Corner 5 becomes ((1 * 1), (0.5 * 1), (1 * -1)) = (1, 0.5, −1).

Part 3: Turns as grids 12 MIN

Where did the turn grid's numbers come from? Take Lesson 2's rotate_y rule and write every line with all three letters, x then y then z, putting a 0 in front of any letter that was missing. The numbers in front of the letters are the grid.

So turn_matrix(angle) works out cos and sin once, and puts them in the right places:

def turn_matrix(angle_degrees):
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (cos_a, 0, (-sin_a)),
        (0,     1, 0       ),     # y is the skewer: it never changes
        (sin_a, 0, cos_a   ),
    )

Another way to read a grid: columns are arrows

Put the arrow (1, 0, 0), which points along +x, through a grid. The 1 picks out the first number of each row and the 0s throw the rest away, so the answer is exactly column 0. The same goes for (0, 1, 0) and column 1, and (0, 0, 1) and column 2. So a grid's three columns are where the +x, +y and +z arrows land. We'll use this twice: to join grids (Part 4) and to find which way is forward (Part 6).

The other two turns

Lesson 2B's tip (around x) and roll (around z) pack the same way. In every grid the skewer, the letter that doesn't move, gets a 1 where its row and column cross and 0s along the rest of that row and column. The swinger and target share the cos and sin.

Part 4: Joining grids 10 MIN

So far a grid only saves us a little typing. The real trick is that two grids can be joined into one grid that does both jobs. Lesson 2B tipped, then turned, then rolled each corner. If we can join those three into one grid, each corner needs just one "matrix × point".

How do we join them? Use the column idea from Part 3. Column 0 of the first grid is where it left the +x arrow. Put that arrow through the second grid, and you have where +x ends up after both. Do the same for the other two columns and you have the joined grid.

In code, combine(first, second) does exactly those three "matrix × point" sums, then stores the columns back as rows:

def combine(first, second):
    new_col_0 = matrix_times_point(second, column(first, 0))
    new_col_1 = matrix_times_point(second, column(first, 1))
    new_col_2 = matrix_times_point(second, column(first, 2))
    return (
        (new_col_0[0], new_col_1[0], new_col_2[0]),
        (new_col_0[1], new_col_1[1], new_col_2[1]),
        (new_col_0[2], new_col_1[2], new_col_2[2]),
    )

Join the roll on as well and you have a thing's whole spin as one grid. spin_matrix(angles) takes the same [tip, turn, roll] list as Lesson 5's thing["angles"]:

def spin_matrix(angles):
    tip_then_turn = combine(tip_matrix(angles[0]), turn_matrix(angles[1]))
    return combine(tip_then_turn, roll_matrix(angles[2]))

Order still matters

Lesson 2B showed that tipping then turning is not the same as turning then tipping. Joining grids can't change that: combine(a, b) and combine(b, a) are different grids. With 90° every number is 0, 1 or −1, so it's easy to check by hand.

Show answer

Turning left 30° and then right 30° puts everything back where it was, so it must be the do-nothing grid ((1, 0, 0), (0, 1, 0), (0, 0, 1)). Step 1 can print it to check (you'll see numbers like 0.0000000000000001 instead of exact 0s).

Q8Check that combine(turn_matrix(30), turn_matrix(60)) has the same column 0 as turn_matrix(90).

Show answer

Column 0 of turn 30 is (0.866, 0, 0.5). Through turn 60 (cos 0.5, sin 0.866): new_x = (0.5 * 0.866) + (0 * 0) + (-0.866 * 0.5) = 0.433 − 0.433 = 0. new_y = 0. new_z = (0.866 * 0.866) + (0 * 0) + (0.5 * 0.5) = 0.75 + 0.25 = 1.

(0, 0, 1): exactly column 0 of turn_matrix(90). Two turns round the same skewer simply add up.

Part 5: The camera's grid 4 MIN

Lesson 4's to_camera() did three things: subtract where you stand, undo your turn (turn the world by -cam_turn), then undo your tip (tip the world by -cam_tip). The two "undo" steps are turns, so they join into one grid:

camera_matrix = combine(turn_matrix(-cam_turn), tip_matrix(-cam_tip))

The subtraction stays a subtraction. A 3 × 3 grid can turn, stretch and squash, but it always keeps (0, 0, 0) where it is, so it can't slide things about. (Real engines use 4 × 4 grids with an extra row and column to do the sliding too. We won't need that.)

Q9You stand at (0, 0, 0) and turn left 90° (cam_turn = 90, cam_tip = 0). Write camera_matrix and put corner 5, WORLD (1, 1, 4), through it. Is it drawn?

Show answer

turn_matrix(-90): cos(−90°) = 0, sin(−90°) = −1, so the grid is ((0, 0, 1), (0, 1, 0), (-1, 0, 0)). The tip grid is the do-nothing grid, so this is camera_matrix.

Subtracting (0, 0, 0) changes nothing. new_x = (0 * 1) + (0 * 1) + (1 * 4) = 4. new_y = 1. new_z = (-1 * 1) + (0 * 1) + (0 * 4) = −1.

CAMERA (4, 1, −1): z is less than NEAR (0.1), so it's behind you and is not drawn. Lesson 4 found the same answer.

Part 6: Why bother? 6 MIN

Every picture today matched the old answers exactly, so what did we gain? Count the work. We ran Lesson 5's small world and today's two scripts, and counted every call to math.cos and math.sin while one frame was drawn:

The biggest saving is the camera. The floor grid alone sends 1,088 points through to_camera() every frame, and in Lesson 5 each one worked out cos and sin of the same two camera angles all over again. Now those angles are worked out once, packed into camera_matrix, and every point just does 9 multiplications and 6 additions. The more things you add (and Lesson 7 adds lots), the bigger the saving.

There is a second gain: tidiness. A thing's whole pose lives in one value, thing["matrix"], and the walking arrows come straight out of a grid's columns (Part 3):

body_turn = turn_matrix(cam_turn)
forward_x, forward_y, forward_z = column(body_turn, 2)   # where +z lands
right_x, right_y, right_z = column(body_turn, 0)         # where +x lands

Wrap up 2 MIN

  • A matrix is a 3 × 3 grid of numbers. Matrix × point = one dot product per row.
  • Read a grid's columns as where the +x, +y and +z arrows land.
  • Every turn rule from Lessons 2 and 2B is a grid: the skewer gets the 1, the others share cos and sin.
  • combine(first, second) joins two grids into one. Order still matters.
  • Build each grid once per frame, then reuse it for every point: 5,068 cos and sin calls became 50.

Q11Final check (Lesson 4's last question, the matrix way). You stand at (−1, 0, 2), turned right 30 (cam_turn = -30), looking level. Build camera_matrix and follow corner 5, WORLD (1, 1, 4), to the screen.

Show answer

1. camera_matrix = combine(turn_matrix(30), tip_matrix(0)). The tip grid does nothing, so it is turn_matrix(30): ((0.866, 0, -0.5), (0, 1, 0), (0.5, 0, 0.866)).

2. Subtract: ((1 - -1), (1 - 0), (4 - 2)) = (2, 1, 2).

3. new_x = (0.866 * 2) + (0 * 1) + (-0.5 * 2) = 1.732 − 1 = 0.732. new_y = 1. new_z = (0.5 * 2) + (0 * 1) + (0.866 * 2) = 1 + 1.732 = 2.732. CAMERA (0.732, 1, 2.732), and z ≥ 0.1 so it's drawn.

4. Screen x = 400 + ((0.732 * 400) / 2.732) = 400 + 107.2 = 507.2. Screen y = 300 - ((1 * 400) / 2.732) = 300 − 146.4 = 153.6. Exactly Lesson 4's answer.

#      dotted with the point (Lesson 3's dot product) to make one new
#      number. 3 rows -> 3 new numbers -> the new point.
#
#   3. tip_matrix, turn_matrix, roll_matrix: Lesson 2B's three rules,

#      grid is built, not once for every point.
#
#   4. combine(first, second): ONE grid that does "first, then second".
#
#   5. spin_matrix([tip, turn, roll]): tip, then turn, then roll, as
#      one grid (Lesson 2B's order). It replaces rotate_all. It takes a

import math


# ---- The OLD way: Lesson 2B's three turns, unchanged -------------------
# We keep them here ONLY to check the new matrices against them.
def rotate_x(point_3d, angle_degrees):
    """TIP one point around the x axis (+y swings toward +z)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = x
    new_y = (y * cos_a) - (z * sin_a)
    new_z = (y * sin_a) + (z * cos_a)
    return (new_x, new_y, new_z)


def rotate_y(point_3d, angle_degrees):
    """TURN one point around the y axis (+x swings toward +z)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = (x * cos_a) - (z * sin_a)
    new_y = y
    new_z = (x * sin_a) + (z * cos_a)
    return (new_x, new_y, new_z)


def rotate_z(point_3d, angle_degrees):
    """ROLL one point around the z axis (+x swings toward +y)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = (x * cos_a) - (y * sin_a)
    new_y = (x * sin_a) + (y * cos_a)
    new_z = z
    return (new_x, new_y, new_z)


# ---- The dot product (from Lesson 3, unchanged) ------------------------
def dot(arrow_1, arrow_2):
    """Multiply x by x, y by y, z by z, then add the three together."""
    x1, y1, z1 = arrow_1
    x2, y2, z2 = arrow_2
    return ( (x1 * x2) + (y1 * y2) + (z1 * z2) )


# ======================================================================
# NEW: MATRICES
# ======================================================================

# ---- NEW: the do-nothing matrix (the IDENTITY) -------------------------
# 1s down the diagonal (top-left to bottom-right), 0s everywhere else.
# Row 0 says "keep ALL of x and none of y or z", and so on.
# Any point that goes through it comes out exactly the same.
DO_NOTHING = (
    (1, 0, 0),     # row 0 -> new_x = (1 * x) + (0 * y) + (0 * z) = x
    (0, 1, 0),     # row 1 -> new_y = (0 * x) + (1 * y) + (0 * z) = y
    (0, 0, 1),     # row 2 -> new_z = (0 * x) + (0 * y) + (1 * z) = z
)


def matrix_times_point(matrix, point_3d):
    """NEW: put one point through a matrix.

    Each ROW of the matrix is dotted with the point:
        new_x = row 0 . point
        new_y = row 1 . point
        new_z = row 2 . point

    Worked example (lesson Part 1): turn_matrix(30) x corner 5 (1, 1, -1)
        new_x = (0.866 * 1) + (0 * 1) + (-0.5 * -1)  = 1.366
        new_y = (0 * 1)     + (1 * 1) + (0 * -1)     = 1
        new_z = (0.5 * 1)   + (0 * 1) + (0.866 * -1) = -0.366
    """
    row_0, row_1, row_2 = matrix
    new_x = dot(row_0, point_3d)
    new_y = dot(row_1, point_3d)
    new_z = dot(row_2, point_3d)
    return (new_x, new_y, new_z)


def tip_matrix(angle_degrees):
    """NEW: Lesson 2B's TIP (rotate_x) as a grid.

    The old rule, written with all three letters in every line:
        new_x = (1 * x) + (0 * y)     + (0 * z)
        new_y = (0 * x) + (cos_a * y) + (-sin_a * z)
        new_z = (0 * x) + (sin_a * y) + (cos_a * z)
    The numbers in front of x, y and z ARE the grid.
    """
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (1, 0,     0         ),   # x is the skewer: it never changes
        (0, cos_a, (-sin_a)  ),
        (0, sin_a, cos_a     ),
    )


def turn_matrix(angle_degrees):
    """NEW: Lesson 2's TURN (rotate_y) as a grid.
        new_x = (cos_a * x) + (0 * y) + (-sin_a * z)
        new_y = (0 * x)     + (1 * y) + (0 * z)
        new_z = (sin_a * x) + (0 * y) + (cos_a * z)
    """
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (cos_a, 0, (-sin_a)),
        (0,     1, 0       ),     # y is the skewer: it never changes
        (sin_a, 0, cos_a   ),
    )


def roll_matrix(angle_degrees):
    """NEW: Lesson 2B's ROLL (rotate_z) as a grid.
        new_x = (cos_a * x) + (-sin_a * y) + (0 * z)
        new_y = (sin_a * x) + (cos_a * y)  + (0 * z)
        new_z = (0 * x)     + (0 * y)      + (1 * z)
    """
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (cos_a, (-sin_a), 0),
        (sin_a, cos_a,    0),
        (0,     0,        1),     # z is the skewer: it never changes
    )


def column(matrix, column_number):
    """NEW: read one COLUMN of a matrix, top to bottom, as a point.
    Column 0 is where the +x arrow (1, 0, 0) lands, column 1 is where
    +y lands, column 2 is where +z lands (lesson Part 3)."""
    row_0, row_1, row_2 = matrix
    return (row_0[column_number], row_1[column_number], row_2[column_number])


def combine(first, second):
    """NEW: ONE matrix that does 'first', then 'second'.

    The idea (lesson Part 4): a matrix's columns are where the three
    axis arrows land. So take each arrow where 'first' left it (its
    column) and put it through 'second'. Those three answers are the
    columns of the joined matrix.

    Worked example: combine(tip_matrix(30), turn_matrix(30))
        column 0 of tip = (1, 0, 0)
        turn_matrix(30) x (1, 0, 0) = (0.866, 0, 0.5)  -> new column 0
    """
    new_col_0 = matrix_times_point(second, column(first, 0))
    new_col_1 = matrix_times_point(second, column(first, 1))
    new_col_2 = matrix_times_point(second, column(first, 2))
    # We worked out COLUMNS, but a matrix is stored as ROWS, so we read
    # them back across: row 0 is the first number of each column, etc.
    return (
        (new_col_0[0], new_col_1[0], new_col_2[0]),
        (new_col_0[1], new_col_1[1], new_col_2[1]),
        (new_col_0[2], new_col_1[2], new_col_2[2]),
    )


def spin_matrix(angles):
    """NEW: tip, then turn, then roll (Lesson 2B's order) as ONE grid.

def show_point(point_3d):
    """(1.36602540, 1, -0.3660254) -> '(1.366, 1.0, -0.366)'.
    round(..., 3) keeps 3 decimal places, like the lesson page.
    The '+ 0' turns a '-0.0' into a plain '0.0'."""
    x, y, z = point_3d
    return ("(" + str(round(x, 3) + 0) + ", " + str(round(y, 3) + 0) +
            ", " + str(round(z, 3) + 0) + ")")


def show_matrix(name, matrix):
    """Print a matrix as 3 lines, one row per line."""
    print(name)
    for row in matrix:
        print("    ", show_point(row))


def check(label, new_answer, old_answer):
    """Print both answers and say if they match.
    'Match' means every number is within 0.000001 of the other one.
    (Computers store numbers like 0.866 with a tiny rounding error, so
    two ways of getting the same answer can differ in the 15th place.)"""
    same = True
    for k in range(3):
        if abs(new_answer[k] - old_answer[k]) > 0.000001:
            same = False
    if same:
        result = "MATCH"
    else:
        result = "DIFFERENT!"
    print(label)
    print("    matrix:", show_point(new_answer))
    print("    old:   ", show_point(old_answer), "  ->", result)

# ---- Lesson 2B's tip and turn, kept ONLY for the camera and walking ----
# NEW: rotate_z and rotate_all are gone: every thing's spin is a
# matrix now. Step 3 removes these two as well.
def rotate_x(point_3d, angle_degrees):
    """TIP one point around the x axis (+y swings toward +z)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = x
    new_y = (y * cos_a) - (z * sin_a)
    new_z = (y * sin_a) + (z * cos_a)
    return (new_x, new_y, new_z)


def rotate_y(point_3d, angle_degrees):
    """TURN one point around the y axis (+x swings toward +z)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = (x * cos_a) - (z * sin_a)
    new_y = y
    new_z = (x * sin_a) + (z * cos_a)
    return (new_x, new_y, new_z)


# ======================================================================
# (step 1) MATRIX TOOLS - every turn as a 3 x 3 grid of numbers
# ======================================================================
# A matrix is a tuple of 3 ROWS, each a tuple of 3 numbers.
#   matrix[2][0] means row 2, column 0.
# Row 0 makes the new x, row 1 the new y, row 2 the new z.

def matrix_times_point(matrix, point_3d):
    """(step 1) put one point through a matrix: each ROW is dotted with
    the point (Lesson 3's dot product) to make one new number.

    turn_matrix(30) x corner 5 (1, 1, -1):
        new_x = (0.866 * 1) + (0 * 1) + (-0.5 * -1)  = 1.366
        new_y = (0 * 1)     + (1 * 1) + (0 * -1)     = 1
        new_z = (0.5 * 1)   + (0 * 1) + (0.866 * -1) = -0.366
    """
    row_0, row_1, row_2 = matrix
    new_x = dot(row_0, point_3d)
    new_y = dot(row_1, point_3d)
    new_z = dot(row_2, point_3d)
    return (new_x, new_y, new_z)


def tip_matrix(angle_degrees):
    """(step 1) Lesson 2B's TIP (rotate_x) as a grid. x is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (1, 0,     0         ),
        (0, cos_a, (-sin_a)  ),
        (0, sin_a, cos_a     ),
    )


def turn_matrix(angle_degrees):
    """(step 1) Lesson 2's TURN (rotate_y) as a grid. y is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (cos_a, 0, (-sin_a)),
        (0,     1, 0       ),
        (sin_a, 0, cos_a   ),
    )


def roll_matrix(angle_degrees):
    """(step 1) Lesson 2B's ROLL (rotate_z) as a grid. z is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (cos_a, (-sin_a), 0),
        (sin_a, cos_a,    0),
        (0,     0,        1),
    )


def column(matrix, column_number):
    """(step 1) one COLUMN of a matrix, top to bottom.
    Column 0 = where +x (1, 0, 0) lands, column 1 = where +y lands,
    column 2 = where +z lands."""
    row_0, row_1, row_2 = matrix
    return (row_0[column_number], row_1[column_number], row_2[column_number])


def combine(first, second):
    """(step 1) ONE matrix that does 'first', then 'second'.
    Put each column of 'first' (where it left each axis arrow) through
    'second'. The three answers are the columns of the joined matrix."""
    new_col_0 = matrix_times_point(second, column(first, 0))
    new_col_1 = matrix_times_point(second, column(first, 1))
    new_col_2 = matrix_times_point(second, column(first, 2))
    # Columns worked out -> stored back as rows.
    return (
        (new_col_0[0], new_col_1[0], new_col_2[0]),
        (new_col_0[1], new_col_1[1], new_col_2[1]),
        (new_col_0[2], new_col_1[2], new_col_2[2]),
    )


def spin_matrix(angles):
    """NEW: a thing's whole spin as ONE matrix: tip, then turn, then
    roll (Lesson 2B's order). It replaces Lesson 5's rotate_all.
    angles is the thing's list [tip, turn, roll] in degrees.
    spin_matrix([30, 30, 30]) x corner 5 = (0.225, 1.708, 0.183),
    the same as Lesson 2B."""
    tip_then_turn = combine(tip_matrix(angles[0]), turn_matrix(angles[1]))
    return combine(tip_then_turn, roll_matrix(angles[2]))


def to_world(shape_point, thing):
    """(Lesson 5) one SHAPE point of a thing -> a WORLD point.

    1. size:  multiply by the thing's size (grow or shrink round its
              own centre).
    2. spin:  CHANGED (Lesson 6): put it through the thing's spin
              matrix, thing["matrix"], built once this frame.
    3. place: add the thing's position.

    Worked example (lesson Part 5): the small cube, size 0.5, still,
    at (2, -0.5, 4). Its corner 5 is SHAPE (1, 1, -1):
        1. ((1 * 0.5), (1 * 0.5), (-1 * 0.5)) = (0.5, 0.5, -0.5)
        2. angles 0 -> the do-nothing matrix   = no change
        3. ((0.5 + 2), (0.5 + -0.5), (-0.5 + 4)) = (2.5, 0, 3.5)
    """
    x, y, z = shape_point
    size = thing["size"]
    sized = ( (x * size), (y * size), (z * size) )         # 1. size
    spun = matrix_times_point(thing["matrix"], sized)       # 2. spin
    pos_x, pos_y, pos_z = thing["position"]
    sx, sy, sz = spun
    return ( (sx + pos_x), (sy + pos_y), (sz + pos_z) )     # 3. place


def to_camera(world_point):
    """One WORLD point -> one CAMERA point (from Lesson 4, unchanged).
    Subtract where you stand, undo your turn, undo your tip."""
    x, y, z = world_point
    moved = ( (x - cam_x), (y - cam_y), (z - cam_z) )
    turned = rotate_y(moved, (-cam_turn))
    tipped = rotate_x(turned, (-cam_tip))
    return tipped


def project(point_3d):
    """One CAMERA point -> one SCREEN point (from Lesson 1).
    Only ever call this with z >= NEAR, so we never divide by 0."""
    x, y, z = point_3d
    screen_x = CENTRE_X + ( (x * FOCAL) / z )
    screen_y = CENTRE_Y - ( (y * FOCAL) / z )
    return (screen_x, screen_y)


def average_z(corners, camera_points):
    """How far away is this face? (from Lesson 3, uses CAMERA points).

    It divides by len(corners), so it works for a triangle (3 corners)
    just as well as for a square (4). Nothing to change!
    """
    total = 0
    for corner_number in corners:
        x, y, z = camera_points[corner_number]
        total = (total + z)
    return (total / len(corners))

    arrow_a_y = (b_y - a_y)
    arrow_b_x = (c_x - a_x)
    arrow_b_y = (c_y - a_y)
    cross = ( (arrow_a_x * arrow_b_y) - (arrow_a_y * arrow_b_x) )
    return (cross > 0)


def dot(arrow_1, arrow_2):
    """The dot product (from Lesson 3)."""
    x1, y1, z1 = arrow_1
    x2, y2, z2 = arrow_2
    return ( (x1 * x2) + (y1 * y2) + (z1 * z2) )


def shade_colour(colour, pointer):
    """Brighter when the face points at the light (from Lesson 3)."""
    brightness = dot(pointer, LIGHT)
    if brightness < 0:
        brightness = 0
    shade = ( AMBIENT + ( (1 - AMBIENT) * brightness ) )
    red, green, blue = colour
    return ( round(red * shade), round(green * shade), round(blue * shade) )


def keep_under_360(angle):
    """Keep an angle between 0 and 360.
    (Lesson 5) CHANGED: a NEGATIVE speed (the big pyramid) counts DOWN,
    so we also add 360 when it drops below 0."""
    if angle >= 360:
        angle = (angle - 360)
    if angle < 0:
        angle = (angle + 360)
    return angle


def add_faces_of(thing, faces_to_draw):
    """(Lesson 5) work out every face of ONE thing and add the ones we
    should paint to the shared list faces_to_draw.

    This is Lesson 4's face loop, moved into a function so we can run
    it once for EACH thing. Every thing adds to the SAME list, so the
    painter's sort later sees all faces of all things together.
    """
    model = thing["model"]

    # ---- spin -> place -> camera, for every corner of this thing ----
    camera_points = []
    screen_points = []
    for p in model["points"]:
        world = to_world(p, thing)                     # WORLD
        camera = to_camera(world)                      # CAMERA
        camera_points.append(camera)
        if camera[2] >= NEAR:
            screen_points.append(project(camera))      # SCREEN
        else:
            screen_points.append(None)

    for corners, face_colour, pointer in model["faces"]:
        # 0. skip the face if ANY corner is too close or behind you.
        too_close = False
        for corner_number in corners:
            if camera_points[corner_number][2] < NEAR:
                too_close = True
        if too_close:
            continue

        face_points = []
        for corner_number in corners:
            face_points.append(screen_points[corner_number])

        # 1. The clock test (Lesson 3).
        if not is_facing_you(face_points):
            continue

        # 2. How far away is it? (CAMERA z, Lesson 4)
        distance = average_z(corners, camera_points)

        # 3. What colour?
        colour = face_colour
        if one_colour:
            colour = thing["colour"]
        if use_light:
            # The pointer must spin WITH the thing, so it goes through
            # the SAME spin matrix (Lesson 6). We do NOT multiply it by the size:
            # a bigger face still points the same way, and the arrow
            # must stay exactly 1 long for the light maths.
            spun_pointer = matrix_times_point(thing["matrix"], pointer)
            colour = shade_colour(colour, spun_pointer)

        faces_to_draw.append( (distance, face_points, colour) )


def draw_floor():
    """(Lesson 5) draw the floor grid at y = FLOOR_Y, in 1-unit pieces.

    Two sets of lines:
      * lines running AWAY from you (fixed x, z changes)
      * lines running ACROSS        (fixed z, x changes)
    Each line is cut into pieces 1 unit long. A piece is drawn only if
    BOTH its ends are in front of you (CAMERA z >= NEAR). A short piece
    means only a short gap at your feet, not a missing line.
    """
    # Lines running away: x = -8, -7, ... 8.  range() stops BEFORE the
    # end number, so we add 1 to include 8 itself.
    for x in range(GRID_LEFT, (GRID_RIGHT + 1)):
        for z in range(GRID_NEAR, GRID_FAR):

    # Lines running across: z = -3, -2, ... 13.
    for z in range(GRID_NEAR, (GRID_FAR + 1)):
        for x in range(GRID_LEFT, GRID_RIGHT):
            draw_floor_piece( (x, FLOOR_Y, z), ((x + 1), FLOOR_Y, z) )


def draw_floor_piece(world_start, world_end):

# (step 1) MATRIX TOOLS - every turn as a 3 x 3 grid of numbers
# ======================================================================
# A matrix is a tuple of 3 ROWS, each a tuple of 3 numbers.
#   matrix[2][0] means row 2, column 0.
# Row 0 makes the new x, row 1 the new y, row 2 the new z.

def matrix_times_point(matrix, point_3d):
    """(step 1) put one point through a matrix: each ROW is dotted with
    the point (Lesson 3's dot product) to make one new number.

    turn_matrix(30) x corner 5 (1, 1, -1):
        new_x = (0.866 * 1) + (0 * 1) + (-0.5 * -1)  = 1.366
        new_y = (0 * 1)     + (1 * 1) + (0 * -1)     = 1
        new_z = (0.5 * 1)   + (0 * 1) + (0.866 * -1) = -0.366
    """
    row_0, row_1, row_2 = matrix
    new_x = dot(row_0, point_3d)
    new_y = dot(row_1, point_3d)
    new_z = dot(row_2, point_3d)
    return (new_x, new_y, new_z)


def tip_matrix(angle_degrees):
    """(step 1) Lesson 2B's TIP (rotate_x) as a grid. x is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (1, 0,     0         ),
        (0, cos_a, (-sin_a)  ),
        (0, sin_a, cos_a     ),
    )


def turn_matrix(angle_degrees):
    """(step 1) Lesson 2's TURN (rotate_y) as a grid. y is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (cos_a, 0, (-sin_a)),
        (0,     1, 0       ),
        (sin_a, 0, cos_a   ),
    )


def roll_matrix(angle_degrees):
    """(step 1) Lesson 2B's ROLL (rotate_z) as a grid. z is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (cos_a, (-sin_a), 0),
        (sin_a, cos_a,    0),
        (0,     0,        1),
    )


def column(matrix, column_number):
    """(step 1) one COLUMN of a matrix, top to bottom.
    Column 0 = where +x (1, 0, 0) lands, column 1 = where +y lands,
    column 2 = where +z lands."""
    row_0, row_1, row_2 = matrix
    return (row_0[column_number], row_1[column_number], row_2[column_number])


def combine(first, second):
    """(step 1) ONE matrix that does 'first', then 'second'.
    Put each column of 'first' (where it left each axis arrow) through
    'second'. The three answers are the columns of the joined matrix."""
    new_col_0 = matrix_times_point(second, column(first, 0))
    new_col_1 = matrix_times_point(second, column(first, 1))
    new_col_2 = matrix_times_point(second, column(first, 2))
    # Columns worked out -> stored back as rows.
    return (
        (new_col_0[0], new_col_1[0], new_col_2[0]),
        (new_col_0[1], new_col_1[1], new_col_2[1]),
        (new_col_0[2], new_col_1[2], new_col_2[2]),
    )


def spin_matrix(angles):
    """(step 2) a thing's whole spin as ONE matrix: tip, then turn, then
    roll (Lesson 2B's order). It replaces Lesson 5's rotate_all.
    angles is the thing's list [tip, turn, roll] in degrees.
    spin_matrix([30, 30, 30]) x corner 5 = (0.225, 1.708, 0.183),
    the same as Lesson 2B."""
    tip_then_turn = combine(tip_matrix(angles[0]), turn_matrix(angles[1]))
    return combine(tip_then_turn, roll_matrix(angles[2]))


def to_world(shape_point, thing):
    """(Lesson 5) one SHAPE point of a thing -> a WORLD point.

    1. size:  multiply by the thing's size (grow or shrink round its
              own centre).
    2. spin:  CHANGED (Lesson 6): put it through the thing's spin
              matrix, thing["matrix"], built once this frame.
    3. place: add the thing's position.

    Worked example (lesson Part 5): the small cube, size 0.5, still,
    at (2, -0.5, 4). Its corner 5 is SHAPE (1, 1, -1):
        1. ((1 * 0.5), (1 * 0.5), (-1 * 0.5)) = (0.5, 0.5, -0.5)
        2. angles 0 -> the do-nothing matrix   = no change
        3. ((0.5 + 2), (0.5 + -0.5), (-0.5 + 4)) = (2.5, 0, 3.5)
    """
    x, y, z = shape_point
    size = thing["size"]
    sized = ( (x * size), (y * size), (z * size) )         # 1. size
    spun = matrix_times_point(thing["matrix"], sized)       # 2. spin
    pos_x, pos_y, pos_z = thing["position"]
    sx, sy, sz = spun
    return ( (sx + pos_x), (sy + pos_y), (sz + pos_z) )     # 3. place


def to_camera(world_point):
    """One WORLD point -> one CAMERA point (from Lesson 4).

    CHANGED (step 3): subtract where you stand, then ONE matrix does
    both "undo your turn" and "undo your tip". camera_matrix is built
    once per frame in the main loop, before anything is drawn.

    Worked example (lesson Part 5): you at (2, 0, 1), cam_turn 30,
    cam_tip 0, corner 5 at WORLD (1, 1, 4):
        1. ((1 - 2), (1 - 0), (4 - 1))          = (-1, 1, 3)
        2. camera_matrix x (-1, 1, 3)
             new_x = (0.866 * -1) + (0 * 1) + (0.5 * 3)   = 0.634
             new_y = (0 * -1)     + (1 * 1) + (0 * 3)     = 1
             new_z = (-0.5 * -1)  + (0 * 1) + (0.866 * 3) = 3.098
    """
    x, y, z = world_point
    moved = ( (x - cam_x), (y - cam_y), (z - cam_z) )      # 1. subtract
    return matrix_times_point(camera_matrix, moved)        # 2. both undos


def project(point_3d):
    """One CAMERA point -> one SCREEN point (from Lesson 1).
    Only ever call this with z >= NEAR, so we never divide by 0."""
    x, y, z = point_3d
    screen_x = CENTRE_X + ( (x * FOCAL) / z )
    screen_y = CENTRE_Y - ( (y * FOCAL) / z )
    return (screen_x, screen_y)


def average_z(corners, camera_points):
    """How far away is this face? (from Lesson 3, uses CAMERA points).

    It divides by len(corners), so it works for a triangle (3 corners)
    just as well as for a square (4). Nothing to change!
    """
    total = 0
    for corner_number in corners:
        x, y, z = camera_points[corner_number]
        total = (total + z)
    return (total / len(corners))


def is_facing_you(face_points):
    """The clock test (from Lesson 3, unchanged). It only looks at the
    first 3 corners, so it works for triangles too."""
    a_x, a_y = face_points[0]
    b_x, b_y = face_points[1]
    c_x, c_y = face_points[2]
    arrow_a_x = (b_x - a_x)
    arrow_a_y = (b_y - a_y)
    arrow_b_x = (c_x - a_x)
    arrow_b_y = (c_y - a_y)
    cross = ( (arrow_a_x * arrow_b_y) - (arrow_a_y * arrow_b_x) )
    return (cross > 0)


def dot(arrow_1, arrow_2):
    """The dot product (from Lesson 3)."""
    x1, y1, z1 = arrow_1
    x2, y2, z2 = arrow_2
    return ( (x1 * x2) + (y1 * y2) + (z1 * z2) )


def shade_colour(colour, pointer):
    """Brighter when the face points at the light (from Lesson 3)."""
    brightness = dot(pointer, LIGHT)
    if brightness < 0:
        brightness = 0
    shade = ( AMBIENT + ( (1 - AMBIENT) * brightness ) )
    red, green, blue = colour
    return ( round(red * shade), round(green * shade), round(blue * shade) )


def keep_under_360(angle):
    """Keep an angle between 0 and 360.
    (Lesson 5) CHANGED: a NEGATIVE speed (the big pyramid) counts DOWN,
    so we also add 360 when it drops below 0."""
    if angle >= 360:
        angle = (angle - 360)
    if angle < 0:
        angle = (angle + 360)
    return angle


def add_faces_of(thing, faces_to_draw):
    """(Lesson 5) work out every face of ONE thing and add the ones we
    should paint to the shared list faces_to_draw.

    This is Lesson 4's face loop, moved into a function so we can run
    it once for EACH thing. Every thing adds to the SAME list, so the
    painter's sort later sees all faces of all things together.
    """
    model = thing["model"]

    # ---- spin -> place -> camera, for every corner of this thing ----
    camera_points = []
    screen_points = []
    for p in model["points"]:
        world = to_world(p, thing)                     # WORLD
        camera = to_camera(world)                      # CAMERA
        camera_points.append(camera)
        if camera[2] >= NEAR:
            screen_points.append(project(camera))      # SCREEN
        else:
            screen_points.append(None)

    for corners, face_colour, pointer in model["faces"]:
        # 0. skip the face if ANY corner is too close or behind you.
        too_close = False
        for corner_number in corners:
            if camera_points[corner_number][2] < NEAR:
                too_close = True
        if too_close:
            continue

        face_points = []
        for corner_number in corners:
            face_points.append(screen_points[corner_number])

        # 1. The clock test (Lesson 3).
        if not is_facing_you(face_points):
            continue

        # 2. How far away is it? (CAMERA z, Lesson 4)
        distance = average_z(corners, camera_points)

        # 3. What colour?
        colour = face_colour
        if one_colour:
            colour = thing["colour"]
        if use_light:
            # The pointer must spin WITH the thing, so it goes through
            # the SAME spin matrix (Lesson 6). We do NOT multiply it by the size:
            # a bigger face still points the same way, and the arrow
            # must stay exactly 1 long for the light maths.
            spun_pointer = matrix_times_point(thing["matrix"], pointer)
            colour = shade_colour(colour, spun_pointer)

        faces_to_draw.append( (distance, face_points, colour) )


def draw_floor():
    """(Lesson 5) draw the floor grid at y = FLOOR_Y, in 1-unit pieces.

    Two sets of lines:
      * lines running AWAY from you (fixed x, z changes)
      * lines running ACROSS        (fixed z, x changes)
    Each line is cut into pieces 1 unit long. A piece is drawn only if
    BOTH its ends are in front of you (CAMERA z >= NEAR). A short piece
    means only a short gap at your feet, not a missing line.
    """
    # Lines running away: x = -8, -7, ... 8.  range() stops BEFORE the
    # end number, so we add 1 to include 8 itself.
    for x in range(GRID_LEFT, (GRID_RIGHT + 1)):
        for z in range(GRID_NEAR, GRID_FAR):
            draw_floor_piece( (x, FLOOR_Y, z), (x, FLOOR_Y, (z + 1)) )
    # Lines running across: z = -3, -2, ... 13.
    for z in range(GRID_NEAR, (GRID_FAR + 1)):
        for x in range(GRID_LEFT, GRID_RIGHT):
            draw_floor_piece( (x, FLOOR_Y, z), ((x + 1), FLOOR_Y, z) )


def draw_floor_piece(world_start, world_end):
    """(Lesson 5) one 1-unit piece of floor line, WORLD -> CAMERA -> SCREEN."""
    start = to_camera(world_start)
    end = to_camera(world_end)
    if (start[2] < NEAR) or (end[2] < NEAR):
        return                                   # behind you: skip it
    pygame.draw.line(screen, GRID_COLOUR, project(start), project(end), 1)



def draw_matrix(matrix, name, left, top):
    """(step 2) draw a matrix's 9 numbers in a small box, rounded to 2
    places. Rows are coloured like the lesson's diagrams:
    row 0 (new x) blue, row 1 (new y) yellow, row 2 (new z) orange.
    The box is 220 x 110 px."""
    box = pygame.Rect(left, top, 220, 110)
    pygame.draw.rect(screen, MAP_BACK, box)
    pygame.draw.rect(screen, WHITE, box, 1)
    screen.blit(font.render(name, True, WHITE), ((left + 8), (top + 6)))
    row_colours = (ROW_X_BLUE, ROW_Y_YELLOW, ROW_Z_ORANGE)
    for row_number in range(3):
        row = matrix[row_number]
        for column_number in range(3):
            # round(..., 2) + 0 : 2 decimal places, and no "-0.0"
            number = (round(row[column_number], 2) + 0)
            text = font.render(str(number), True, row_colours[row_number])
            x = (left + 12 + (column_number * 70))
            y = (top + 32 + (row_number * 25))
            screen.blit(text, (x, y))


def to_map(x, z):
    """A WORLD (x, z) -> a pixel on the mini-map (from Lesson 4)."""
    map_x = MAP_CX + (x * MAP_SCALE)
    map_y = MAP_CY - (z * MAP_SCALE)
    return (map_x, map_y)


def draw_map():
    """Draw the mini-map: every thing's base and you, from above.

    (Lesson 5) a loop over ALL things. Corners 0, 1, 2, 3 are the bottom
    corners of BOTH models (that is why the pyramid's base uses the
    cube's numbers), so the same 4 numbers work for every thing.
    """
    box = pygame.Rect(MAP_LEFT, MAP_TOP, MAP_SIZE, MAP_SIZE)
    pygame.draw.rect(screen, MAP_BACK, box)
    screen.set_clip(box)
    for thing in things:
        outline = []
        for corner_number in (0, 1, 2, 3):
            corner = thing["model"]["points"][corner_number]
            x, y, z = to_world(corner, thing)
            outline.append(to_map(x, z))
        pygame.draw.polygon(screen, thing["colour"], outline, 2)
    # (step 3) your forward arrow = column 2 of your turn matrix.
    forward_x, forward_y, forward_z = column(turn_matrix(cam_turn), 2)
    you = to_map(cam_x, cam_z)
    nose = to_map( (cam_x + (forward_x * 1.5)), (cam_z + (forward_z * 1.5)) )
    pygame.draw.line(screen, PINK, you, nose, 2)
    pygame.draw.circle(screen, PINK, you, 4)
    screen.set_clip(None)
    pygame.draw.rect(screen, WHITE, box, 1)

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_SPACE:
                spinning = not spinning
            if event.key == pygame.K_l:
                use_light = not use_light
            if event.key == pygame.K_c:
                one_colour = not one_colour
            if event.key == pygame.K_g:
                show_grid = not show_grid
            if event.key == pygame.K_m:          # (step 2)
                show_matrices = not show_matrices
            if event.key == pygame.K_r:          # back to the start
                cam_x = 0
                cam_y = 0
                cam_z = 0
                cam_turn = 0
                cam_tip = 0
                for thing in things:
                    thing["angles"] = [0, 0, 0]

    # ---- Keys you HOLD (from Lesson 4, unchanged) ---------------------
    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT]:
        cam_turn = (cam_turn + TURN_SPEED)
    if keys[pygame.K_RIGHT]:
        cam_turn = (cam_turn - TURN_SPEED)
    if keys[pygame.K_UP]:
        cam_tip = (cam_tip - TURN_SPEED)
    if keys[pygame.K_DOWN]:
        cam_tip = (cam_tip + TURN_SPEED)
    if cam_tip > TIP_LIMIT:
        cam_tip = TIP_LIMIT
    if cam_tip < (-TIP_LIMIT):
        cam_tip = (-TIP_LIMIT)

    # ---- (step 3) which way is forward and right? -------------------
    # Lesson 4 turned the arrows (0, 0, 1) and (1, 0, 0) with rotate_y.
    # A matrix's columns ARE where those arrows land (lesson Part 3),
    # so we just read them out of your turn matrix:
    #   cam_turn 30: forward = column 2 = (-0.5, 0, 0.866)
    #                right   = column 0 = (0.866, 0, 0.5)
    # (Your tip is NOT used, so you still walk level, as in Lesson 4.)
    body_turn = turn_matrix(cam_turn)
    forward_x, forward_y, forward_z = column(body_turn, 2)
    right_x, right_y, right_z = column(body_turn, 0)
    if keys[pygame.K_w]:
        cam_x = (cam_x + (forward_x * MOVE_SPEED))
        cam_z = (cam_z + (forward_z * MOVE_SPEED))
    if keys[pygame.K_s]:
        cam_x = (cam_x - (forward_x * MOVE_SPEED))
        cam_z = (cam_z - (forward_z * MOVE_SPEED))
    if keys[pygame.K_d]:
        cam_x = (cam_x + (right_x * MOVE_SPEED))
        cam_z = (cam_z + (right_z * MOVE_SPEED))
    if keys[pygame.K_a]:
        cam_x = (cam_x - (right_x * MOVE_SPEED))
        cam_z = (cam_z - (right_z * MOVE_SPEED))
    if keys[pygame.K_e]:
        cam_y = (cam_y + MOVE_SPEED)
    if keys[pygame.K_q]:
        cam_y = (cam_y - MOVE_SPEED)

    # ---- (Lesson 5) every thing spins at its OWN speeds --------------------
    if spinning:
        for thing in things:
            angles = thing["angles"]
            speeds = thing["speeds"]
            angles[0] = keep_under_360( (angles[0] + speeds[0]) )   # tip
            angles[1] = keep_under_360( (angles[1] + speeds[1]) )   # turn
            angles[2] = keep_under_360( (angles[2] + speeds[2]) )   # roll

    # ---- (step 2) build each thing's spin matrix ONCE this frame ----
    # Every corner, every face pointer and the mini-map then reuse it.
    for thing in things:
        thing["matrix"] = spin_matrix(thing["angles"])

    # ---- NEW: build the camera's matrix ONCE this frame -------------
    # Lesson 4's order: undo your turn FIRST, then undo your tip.
    # It is used by to_camera() for every thing and every floor line.
    camera_matrix = combine(turn_matrix(-cam_turn), tip_matrix(-cam_tip))

    screen.fill(BLACK)

    # ---- (Lesson 5) the floor first, so every shape is painted on top of it -
    if show_grid:
        draw_floor()

    # ---- (Lesson 5) ONE list for the faces of EVERY thing --------------------
    faces_to_draw = []
    for thing in things:
        add_faces_of(thing, faces_to_draw)

    # ---- The painter's method: furthest first, ALL faces together ----
    faces_to_draw.sort(reverse=True)
    for distance, face_points, colour in faces_to_draw:
        pygame.draw.polygon(screen, colour, face_points)
        pygame.draw.polygon(screen, BLACK, face_points, 2)

    draw_map()

    # ---- (step 2) the matrix numbers, top-right --------------------
    # things[4] is the floating LILAC cube: the only one that tips,
    # turns AND rolls, so all 9 of its numbers keep changing.
    if show_matrices:
        draw_matrix(things[4]["matrix"], "lilac cube spin", 570, 115)
        # NEW: the camera's grid. Turn with LEFT / RIGHT and watch it.
        draw_matrix(camera_matrix, "camera_matrix", 570, 235)

    text = ("you are at (" + str(round(cam_x, 2)) + ", " +
            str(round(cam_y, 2)) + ", " + str(round(cam_z, 2)) + ")")
    text = (text + "   turn " + str(round(cam_turn, 1)) +
            "   tip " + str(round(cam_tip, 1)))
    screen.blit(font.render(text, True, PINK), (20, 20))
    screen.blit(font.render("ARROWS = turn and look,  W A S D = walk,  Q / E = down / up", True, YELLOW), (20, 50))
    screen.blit(font.render("SPACE = pause,  R = reset,  L = light,  C = colours,  G = grid,  M = matrices", True, YELLOW), (20, 80))

    pygame.display.flip()
    clock.tick(60)

pygame.quit()

Clipping: cutting faces at the near wall

Fly right up beside something big in Cube Hunt and a whole wall of it can vanish. Lesson 4 told the program to skip any face with a corner behind you, and that was the safe choice then. Today we do better: we cut each face, and each floor line, exactly where it crosses a wall just in front of your eye, and draw the part that is still in front. The maths is one new idea: how far along a line, from 0 to 1.

Where this lesson fits

Today: clipping: cut faces and lines cleanly at the NEAR wall instead of throwing them away.

def matrix_times_point(matrix, point_3d):
    """Put one point through a matrix: each ROW dotted with the point."""
    row_0, row_1, row_2 = matrix
    new_x = dot(row_0, point_3d)
    new_y = dot(row_1, point_3d)
    new_z = dot(row_2, point_3d)
    return (new_x, new_y, new_z)


def tip_matrix(angle_degrees):
    """Lesson 2B's TIP as a grid. x is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (1, 0,     0         ),
        (0, cos_a, (-sin_a)  ),
        (0, sin_a, cos_a     ),
    )


def turn_matrix(angle_degrees):
    """Lesson 2's TURN as a grid. y is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (cos_a, 0, (-sin_a)),
        (0,     1, 0       ),
        (sin_a, 0, cos_a   ),
    )


def roll_matrix(angle_degrees):
    """Lesson 2B's ROLL as a grid. z is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (cos_a, (-sin_a), 0),
        (sin_a, cos_a,    0),
        (0,     0,        1),
    )


def column(matrix, column_number):
    """One COLUMN of a matrix = where that axis arrow lands."""
    row_0, row_1, row_2 = matrix
    return (row_0[column_number], row_1[column_number], row_2[column_number])


def combine(first, second):
    """ONE matrix that does 'first', then 'second' (Lesson 6)."""
    new_col_0 = matrix_times_point(second, column(first, 0))
    new_col_1 = matrix_times_point(second, column(first, 1))
    new_col_2 = matrix_times_point(second, column(first, 2))
    return (
        (new_col_0[0], new_col_1[0], new_col_2[0]),
        (new_col_0[1], new_col_1[1], new_col_2[1]),
        (new_col_0[2], new_col_1[2], new_col_2[2]),
    )


def spin_matrix(angles):
    """A thing's whole spin as ONE matrix: tip, then turn, then roll."""
    tip_then_turn = combine(tip_matrix(angles[0]), turn_matrix(angles[1]))
    return combine(tip_then_turn, roll_matrix(angles[2]))

def to_world(shape_point, thing):
    """(Lesson 5) SHAPE -> WORLD: size, then spin, then place."""
    x, y, z = shape_point
    size = thing["size"]
    sized = ( (x * size), (y * size), (z * size) )
    spun = matrix_times_point(thing["matrix"], sized)
    pos_x, pos_y, pos_z = thing["position"]
    sx, sy, sz = spun
    return ( (sx + pos_x), (sy + pos_y), (sz + pos_z) )


def to_camera(world_point):
    """(Lessons 4 and 6) WORLD -> CAMERA: subtract you, then camera_matrix."""
    x, y, z = world_point
    moved = ( (x - cam_x), (y - cam_y), (z - cam_z) )
    return matrix_times_point(camera_matrix, moved)


def project(point_3d):
    """(Lesson 1) CAMERA -> SCREEN. Only call it with z >= NEAR."""
    x, y, z = point_3d
    screen_x = CENTRE_X + ( (x * FOCAL) / z )
    screen_y = CENTRE_Y - ( (y * FOCAL) / z )
    return (screen_x, screen_y)


def average_z(corners, camera_points):
    """(Lesson 3) how far away is this face? Uses CAMERA z."""
    total = 0
    for corner_number in corners:
        x, y, z = camera_points[corner_number]
        total = (total + z)
    return (total / len(corners))


def is_facing_you(face_points):
    """(Lesson 3) the clock test: True if clockwise on the screen."""
    a_x, a_y = face_points[0]
    b_x, b_y = face_points[1]
    c_x, c_y = face_points[2]
    arrow_a_x = (b_x - a_x)
    arrow_a_y = (b_y - a_y)
    arrow_b_x = (c_x - a_x)
    arrow_b_y = (c_y - a_y)
    cross = ( (arrow_a_x * arrow_b_y) - (arrow_a_y * arrow_b_x) )
    return (cross > 0)


def dot(arrow_1, arrow_2):
    """(Lesson 3) the dot product."""
    x1, y1, z1 = arrow_1
    x2, y2, z2 = arrow_2
    return ( (x1 * x2) + (y1 * y2) + (z1 * z2) )


def shade_colour(colour, pointer):
    """(Lesson 3) brighter when the face points at the light."""
    brightness = dot(pointer, LIGHT)
    if brightness < 0:
        brightness = 0
    shade = ( AMBIENT + ( (1 - AMBIENT) * brightness ) )
    red, green, blue = colour
    return ( round(red * shade), round(green * shade), round(blue * shade) )


def keep_under_360(angle):
    """Keep an angle between 0 and 360."""
    if angle >= 360:
        angle = (angle - 360)
    if angle < 0:
        angle = (angle + 360)
    return angle


def add_faces_of(thing, faces_to_draw):
    """(Lesson 5) work out every face of ONE thing and add the ones to
    paint to the shared list (unchanged from Lesson 6)."""
    model = thing["model"]
    camera_points = []
    screen_points = []
    for p in model["points"]:
        world = to_world(p, thing)                     # WORLD
        camera = to_camera(world)                      # CAMERA
        camera_points.append(camera)
        if camera[2] >= NEAR:
            screen_points.append(project(camera))      # SCREEN
        else:
            screen_points.append(None)

    for corners, face_colour, pointer in model["faces"]:
        too_close = False
        for corner_number in corners:
            if camera_points[corner_number][2] < NEAR:
                too_close = True
        if too_close:
            continue
        face_points = []
        for corner_number in corners:
            face_points.append(screen_points[corner_number])
        if not is_facing_you(face_points):
            continue
        distance = average_z(corners, camera_points)
        colour = thing["colour"]
        if use_light:
            spun_pointer = matrix_times_point(thing["matrix"], pointer)
            colour = shade_colour(colour, spun_pointer)
        faces_to_draw.append( (distance, face_points, colour) )

def distance_3d(point_a, point_b):
    """(Lesson 7) how far apart are two WORLD points? (lesson Part 2)

    Subtract, square each part, add them up, square-root the total:
    Pythagoras done twice, in one line.

    Worked example (lesson Part 2): you at (1, 0, 3), cube 0 at (3, 1, 5)
        dx = (3 - 1) = 2,  dy = (1 - 0) = 1,  dz = (5 - 3) = 2
        math.sqrt( (2 * 2) + (1 * 1) + (2 * 2) ) = math.sqrt(9) = 3
    """
    ax, ay, az = point_a
    bx, by, bz = point_b
    dx = (bx - ax)
    dy = (by - ay)
    dz = (bz - az)
    return math.sqrt( (dx * dx) + (dy * dy) + (dz * dz) )


def far_from_rocks(spot):
    """NEW: True if this WORLD spot is at least ROCK_CLEARANCE (3) from
    the centre of every rock, so a new gold cube never hides inside one.

    Worked example (lesson Part 1): spot (1, 1, 5) and rock 0 at
    (0, 0.5, 4): math.sqrt( (1 * 1) + (0.5 * 0.5) + (1 * 1) ) = 1.5,
    less than 3, so False: try again.
    """
    for rock_spot in ROCK_SPOTS:
        if distance_3d(spot, rock_spot) < ROCK_CLEARANCE:
            return False
    return True


def new_pickup_spot():
    """(Lesson 7) a random WORLD spot for a cube, at least
    MIN_SPAWN_DISTANCE from you (lesson Part 4).

    "while True" repeats for ever, until "return" jumps out. Usually the
    first try is far enough; about 1 try in 5 is too close and we
    simply pick again.
    """
    you = (cam_x, cam_y, cam_z)
    while True:
        new_x = random.uniform((-FIELD), FIELD)
        new_y = random.uniform(PICKUP_LOW, PICKUP_HIGH)
        new_z = random.uniform((-FIELD), FIELD)
        spot = (new_x, new_y, new_z)
        # NEW: "and far_from_rocks(spot)": BOTH must be True.
        if (distance_3d(you, spot) >= MIN_SPAWN_DISTANCE) and far_from_rocks(spot):
            return spot

t: how far along a line

To say where on a line something happens, we use one number, called t. It is a fraction of the way from one end to the other:

Finding t for the NEAR wall

Now turn it round. We know where the wall is (z = 0.1) and want t. Look only at z: how far is it from A to the wall, out of the whole way from A to B?

The cut point

t is the same for x, y and z, because the cut point is one point on one line. So once t comes from z, use it to walk x and y the same fraction of their gaps:

KEY CONCEPT 
t     = ( (NEAR - a_z) / (b_z - a_z) )
cut_x = ( a_x + (t * (b_x - a_x)) )
cut_y = ( a_y + (t * (b_y - a_y)) )
cut_z = NEAR

These four lines are the only new maths today. Every cut in this lesson, for floor lines and for faces, is this sum.

def cut_at_near(point_a, point_b):
    a_x, a_y, a_z = point_a
    b_x, b_y, b_z = point_b
    t = ( (NEAR - a_z) / (b_z - a_z) )
    cut_x = ( a_x + (t * (b_x - a_x)) )
    cut_y = ( a_y + (t * (b_y - a_y)) )
    return (cut_x, cut_y, NEAR)

Can (b_z - a_z) ever be 0 and crash? Only if both ends have the same z, and then they are both in or both out, so we never call cut_at_near() for that line. We only ever cut a line that crosses the wall.

clip_line: three cases

def clip_line(start, end):
    start_in = (start[2] >= NEAR)
    end_in = (end[2] >= NEAR)
    if start_in and end_in:
        return (start, end)                       # all in front: keep it all
    if (not start_in) and (not end_in):
        return None                               # all behind: nothing
    cut = cut_at_near(start, end)
    if start_in:
        return (start, cut)                       # end was behind
    return (cut, end)                             # start was behind

None is Python's word for "nothing". The caller checks if clipped is None: return before drawing.

def matrix_times_point(matrix, point_3d):
    """Put one point through a matrix: each ROW dotted with the point."""
    row_0, row_1, row_2 = matrix
    new_x = dot(row_0, point_3d)
    new_y = dot(row_1, point_3d)
    new_z = dot(row_2, point_3d)
    return (new_x, new_y, new_z)


def tip_matrix(angle_degrees):
    """Lesson 2B's TIP as a grid. x is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (1, 0,     0         ),
        (0, cos_a, (-sin_a)  ),
        (0, sin_a, cos_a     ),
    )


def turn_matrix(angle_degrees):
    """Lesson 2's TURN as a grid. y is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (cos_a, 0, (-sin_a)),
        (0,     1, 0       ),
        (sin_a, 0, cos_a   ),
    )


def roll_matrix(angle_degrees):
    """Lesson 2B's ROLL as a grid. z is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (cos_a, (-sin_a), 0),
        (sin_a, cos_a,    0),
        (0,     0,        1),
    )


def column(matrix, column_number):
    """One COLUMN of a matrix = where that axis arrow lands."""
    row_0, row_1, row_2 = matrix
    return (row_0[column_number], row_1[column_number], row_2[column_number])


def combine(first, second):
    """ONE matrix that does 'first', then 'second' (Lesson 6)."""
    new_col_0 = matrix_times_point(second, column(first, 0))
    new_col_1 = matrix_times_point(second, column(first, 1))
    new_col_2 = matrix_times_point(second, column(first, 2))
    return (
        (new_col_0[0], new_col_1[0], new_col_2[0]),
        (new_col_0[1], new_col_1[1], new_col_2[1]),
        (new_col_0[2], new_col_1[2], new_col_2[2]),
    )


def spin_matrix(angles):
    """A thing's whole spin as ONE matrix: tip, then turn, then roll."""
    tip_then_turn = combine(tip_matrix(angles[0]), turn_matrix(angles[1]))
    return combine(tip_then_turn, roll_matrix(angles[2]))

def to_world(shape_point, thing):
    """(Lesson 5) SHAPE -> WORLD: size, then spin, then place."""
    x, y, z = shape_point
    size = thing["size"]
    sized = ( (x * size), (y * size), (z * size) )
    spun = matrix_times_point(thing["matrix"], sized)
    pos_x, pos_y, pos_z = thing["position"]
    sx, sy, sz = spun
    return ( (sx + pos_x), (sy + pos_y), (sz + pos_z) )


def to_camera(world_point):
    """(Lessons 4 and 6) WORLD -> CAMERA: subtract you, then camera_matrix."""
    x, y, z = world_point
    moved = ( (x - cam_x), (y - cam_y), (z - cam_z) )
    return matrix_times_point(camera_matrix, moved)


def project(point_3d):
    """(Lesson 1) CAMERA -> SCREEN. Only call it with z >= NEAR."""
    x, y, z = point_3d
    screen_x = CENTRE_X + ( (x * FOCAL) / z )
    screen_y = CENTRE_Y - ( (y * FOCAL) / z )
    return (screen_x, screen_y)


def average_z(corners, camera_points):
    """(Lesson 3) how far away is this face? Uses CAMERA z."""
    total = 0
    for corner_number in corners:
        x, y, z = camera_points[corner_number]
        total = (total + z)
    return (total / len(corners))


def is_facing_you(face_points):
    """(Lesson 3) the clock test: True if clockwise on the screen."""
    a_x, a_y = face_points[0]
    b_x, b_y = face_points[1]
    c_x, c_y = face_points[2]
    arrow_a_x = (b_x - a_x)
    arrow_a_y = (b_y - a_y)
    arrow_b_x = (c_x - a_x)
    arrow_b_y = (c_y - a_y)
    cross = ( (arrow_a_x * arrow_b_y) - (arrow_a_y * arrow_b_x) )
    return (cross > 0)


def dot(arrow_1, arrow_2):
    """(Lesson 3) the dot product."""
    x1, y1, z1 = arrow_1
    x2, y2, z2 = arrow_2
    return ( (x1 * x2) + (y1 * y2) + (z1 * z2) )


def shade_colour(colour, pointer):
    """(Lesson 3) brighter when the face points at the light."""
    brightness = dot(pointer, LIGHT)
    if brightness < 0:
        brightness = 0
    shade = ( AMBIENT + ( (1 - AMBIENT) * brightness ) )
    red, green, blue = colour
    return ( round(red * shade), round(green * shade), round(blue * shade) )


def keep_under_360(angle):
    """Keep an angle between 0 and 360."""
    if angle >= 360:
        angle = (angle - 360)
    if angle < 0:
        angle = (angle + 360)
    return angle


def add_faces_of(thing, faces_to_draw):
    """(Lesson 5) work out every face of ONE thing and add the ones to
    paint to the shared list (unchanged from Lesson 6)."""
    model = thing["model"]
    camera_points = []
    screen_points = []
    for p in model["points"]:
        world = to_world(p, thing)                     # WORLD
        camera = to_camera(world)                      # CAMERA
        camera_points.append(camera)
        if camera[2] >= NEAR:
            screen_points.append(project(camera))      # SCREEN
        else:
            screen_points.append(None)

    for corners, face_colour, pointer in model["faces"]:
        too_close = False
        for corner_number in corners:
            if camera_points[corner_number][2] < NEAR:
                too_close = True
        if too_close:
            continue
        face_points = []
        for corner_number in corners:
            face_points.append(screen_points[corner_number])
        if not is_facing_you(face_points):
            continue
        distance = average_z(corners, camera_points)
        colour = thing["colour"]
        if use_light:
            spun_pointer = matrix_times_point(thing["matrix"], pointer)
            colour = shade_colour(colour, spun_pointer)
        faces_to_draw.append( (distance, face_points, colour) )

# CLIPPING (Lesson 8)
# ======================================================================
# Everything here works in CAMERA coordinates: (0, 0, 0) is your eye,
# +x is right, +y is up, +z is straight ahead. The NEAR wall is the
# flat sheet z = NEAR (0.1) just in front of your eye.
#   "in"  = in front of the wall:  z >= NEAR   (safe to project)
#   "out" = behind the wall:       z <  NEAR   (must never be projected)

def cut_at_near(point_a, point_b):
    """NEW: the CAMERA point where the line from point_a to point_b
    crosses the NEAR wall. One end must be in, the other out.

    t says how far along the line the wall is: 0 = at point_a,
    1 = at point_b, 0.5 = halfway (lesson Part 2).

        t = ( (NEAR - a_z) / (b_z - a_z) )

    Then each of x and y moves the same fraction t of its own gap:

        x = ( a_x + (t * (b_x - a_x)) )

    Worked example (lesson Part 2): a = (-2, -1, -1), b = (2, -1, 3)
        t = ( (0.1 - (-1)) / (3 - (-1)) ) = (1.1 / 4) = 0.275
        x = ( -2 + (0.275 * (2 - (-2))) ) = ( -2 + 1.1 ) = -0.9
        y = ( -1 + (0.275 * (-1 - (-1))) ) = -1
        z = NEAR = 0.1          -> (-0.9, -1, 0.1)
    """
    a_x, a_y, a_z = point_a
    b_x, b_y, b_z = point_b
    t = ( (NEAR - a_z) / (b_z - a_z) )
    cut_x = ( a_x + (t * (b_x - a_x)) )
    cut_y = ( a_y + (t * (b_y - a_y)) )
    # The same sum for z would give exactly NEAR, which is the whole
    # point of t, so we just use NEAR.
    return (cut_x, cut_y, NEAR)


def clip_line(start, end):
    """NEW: keep the part of a CAMERA line that is in front of NEAR.

    Gives back (start, end) with any end behind you swapped for the
    cut point, or None ("nothing to draw") if both ends are behind.
    """
    start_in = (start[2] >= NEAR)
    end_in = (end[2] >= NEAR)
    if start_in and end_in:
        return (start, end)                       # all in front: keep it all
    if (not start_in) and (not end_in):
        return None                               # all behind: nothing
    cut = cut_at_near(start, end)
    if start_in:
        return (start, cut)                       # end was behind
    return (cut, end)                             # start was behind

def distance_3d(point_a, point_b):
    """(Lesson 7) how far apart are two WORLD points? (lesson Part 2)

    Subtract, square each part, add them up, square-root the total:
    Pythagoras done twice, in one line.

    Worked example (lesson Part 2): you at (1, 0, 3), cube 0 at (3, 1, 5)
        dx = (3 - 1) = 2,  dy = (1 - 0) = 1,  dz = (5 - 3) = 2
        math.sqrt( (2 * 2) + (1 * 1) + (2 * 2) ) = math.sqrt(9) = 3
    """
    ax, ay, az = point_a
    bx, by, bz = point_b
    dx = (bx - ax)
    dy = (by - ay)
    dz = (bz - az)
    return math.sqrt( (dx * dx) + (dy * dy) + (dz * dz) )


def far_from_rocks(spot):
    """(step 1): True if this WORLD spot is at least ROCK_CLEARANCE (3) from
    the centre of every rock, so a new gold cube never hides inside one.

    Worked example (lesson Part 1): spot (1, 1, 5) and rock 0 at
    (0, 0.5, 4): math.sqrt( (1 * 1) + (0.5 * 0.5) + (1 * 1) ) = 1.5,
    less than 3, so False: try again.
    """
    for rock_spot in ROCK_SPOTS:
        if distance_3d(spot, rock_spot) < ROCK_CLEARANCE:
            return False
    return True


def new_pickup_spot():
    """(Lesson 7) a random WORLD spot for a cube, at least
    MIN_SPAWN_DISTANCE from you (lesson Part 4).

    "while True" repeats for ever, until "return" jumps out. Usually the
    first try is far enough; about 1 try in 5 is too close and we
    simply pick again.
    """
    you = (cam_x, cam_y, cam_z)
    while True:
        new_x = random.uniform((-FIELD), FIELD)
        new_y = random.uniform(PICKUP_LOW, PICKUP_HIGH)
        new_z = random.uniform((-FIELD), FIELD)
        spot = (new_x, new_y, new_z)
        # (step 1): "and far_from_rocks(spot)": BOTH must be True.
        if (distance_3d(you, spot) >= MIN_SPAWN_DISTANCE) and far_from_rocks(spot):
            return spot

Part 3: Cutting a face 14 MIN

A face is a ring of corners joined by edges. Each edge is a line, and we already know how to cut a line. So we walk once round the face, one edge at a time, and write down the corners we keep. Each edge goes from the previous corner to the current one, and there are only four cases:

KEY CONCEPT 
previous  current   keep
in        in        current
in        out       the cut point
out       in        the cut point, then current
out       out       nothing

Four rules, applied to every edge in turn. Because we go round in order, the kept corners come out in the same clockwise order as the face, so the clock test from Lesson 3 still works on them.

How many corners come back?

A 4-corner face does not always come back with 4 corners. It depends on how many are behind the wall:

def clip_face(face_corners):
    kept = []
    previous = face_corners[-1]          # [-1] = the LAST corner in the list
    for current in face_corners:
        previous_in = (previous[2] >= NEAR)
        current_in = (current[2] >= NEAR)
        if previous_in and current_in:
            kept.append(current)
        elif previous_in and (not current_in):
            kept.append(cut_at_near(previous, current))
        elif (not previous_in) and current_in:
            kept.append(cut_at_near(previous, current))
            kept.append(current)
        # out -> out: keep nothing
        previous = current
    return kept

Why start with previous = face_corners[-1]? In Python, [-1] means "the last item in the list". Starting there makes the first edge go from the last corner to the first one, which closes the ring. A 4-corner face has 4 edges, and the loop visits each exactly once.

def matrix_times_point(matrix, point_3d):
    """Put one point through a matrix: each ROW dotted with the point."""
    row_0, row_1, row_2 = matrix
    new_x = dot(row_0, point_3d)
    new_y = dot(row_1, point_3d)
    new_z = dot(row_2, point_3d)
    return (new_x, new_y, new_z)


def tip_matrix(angle_degrees):
    """Lesson 2B's TIP as a grid. x is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (1, 0,     0         ),
        (0, cos_a, (-sin_a)  ),
        (0, sin_a, cos_a     ),
    )

        (0,     0,        1),
    )


def column(matrix, column_number):
    """One COLUMN of a matrix = where that axis arrow lands."""
    row_0, row_1, row_2 = matrix
    return (row_0[column_number], row_1[column_number], row_2[column_number])


def combine(first, second):
    """ONE matrix that does 'first', then 'second' (Lesson 6)."""
    new_col_0 = matrix_times_point(second, column(first, 0))
    new_col_1 = matrix_times_point(second, column(first, 1))
    new_col_2 = matrix_times_point(second, column(first, 2))
    return (
        (new_col_0[0], new_col_1[0], new_col_2[0]),
        (new_col_0[1], new_col_1[1], new_col_2[1]),
        (new_col_0[2], new_col_1[2], new_col_2[2]),
    )


def spin_matrix(angles):
    """A thing's whole spin as ONE matrix: tip, then turn, then roll."""
    tip_then_turn = combine(tip_matrix(angles[0]), turn_matrix(angles[1]))
    return combine(tip_then_turn, roll_matrix(angles[2]))

def to_world(shape_point, thing):
    """(Lesson 5) SHAPE -> WORLD: size, then spin, then place."""
    x, y, z = shape_point
    size = thing["size"]
    sized = ( (x * size), (y * size), (z * size) )
    spun = matrix_times_point(thing["matrix"], sized)
    pos_x, pos_y, pos_z = thing["position"]
    sx, sy, sz = spun
    return ( (sx + pos_x), (sy + pos_y), (sz + pos_z) )


def to_camera(world_point):
    """(Lessons 4 and 6) WORLD -> CAMERA: subtract you, then camera_matrix."""
    x, y, z = world_point
    moved = ( (x - cam_x), (y - cam_y), (z - cam_z) )
    return matrix_times_point(camera_matrix, moved)


def project(point_3d):
    """(Lesson 1) CAMERA -> SCREEN. Only call it with z >= NEAR."""
    x, y, z = point_3d
    screen_x = CENTRE_X + ( (x * FOCAL) / z )
    screen_y = CENTRE_Y - ( (y * FOCAL) / z )
    return (screen_x, screen_y)


def average_z(corners, camera_points):
    """(Lesson 3) how far away is this face? Uses CAMERA z."""
    total = 0
    for corner_number in corners:
        x, y, z = camera_points[corner_number]
        total = (total + z)
    return (total / len(corners))


def is_facing_you(face_points):
    """(Lesson 3) the clock test: True if clockwise on the screen."""
    a_x, a_y = face_points[0]
    b_x, b_y = face_points[1]
    c_x, c_y = face_points[2]
    arrow_a_x = (b_x - a_x)
    arrow_a_y = (b_y - a_y)
    arrow_b_x = (c_x - a_x)
    arrow_b_y = (c_y - a_y)
    cross = ( (arrow_a_x * arrow_b_y) - (arrow_a_y * arrow_b_x) )
    return (cross > 0)


def dot(arrow_1, arrow_2):
    """(Lesson 3) the dot product."""
    x1, y1, z1 = arrow_1
    x2, y2, z2 = arrow_2
    return ( (x1 * x2) + (y1 * y2) + (z1 * z2) )


def shade_colour(colour, pointer):
    """(Lesson 3) brighter when the face points at the light."""
    brightness = dot(pointer, LIGHT)
    if brightness < 0:
        brightness = 0
    shade = ( AMBIENT + ( (1 - AMBIENT) * brightness ) )
    red, green, blue = colour
    return ( round(red * shade), round(green * shade), round(blue * shade) )


def keep_under_360(angle):
    """Keep an angle between 0 and 360."""
    if angle >= 360:
        angle = (angle - 360)
    if angle < 0:
        angle = (angle + 360)
    return angle


def add_faces_of(thing, faces_to_draw):
    """(Lesson 5) work out every face of ONE thing and add the ones to
    paint to the shared list.

    NEW in Lesson 8: each face is CLIPPED in CAMERA coordinates first,
    and only then projected. So we no longer project every corner up
    front: a face's cut points only exist once that face is clipped.
    """
    model = thing["model"]
    camera_points = []
    for p in model["points"]:
        world = to_world(p, thing)                     # WORLD
        camera_points.append(to_camera(world))         # CAMERA

    for corners, face_colour, pointer in model["faces"]:
        # NEW: this face's corners in CAMERA coordinates, clockwise.
        face_camera = []
        for corner_number in corners:
            face_camera.append(camera_points[corner_number])

        if use_clipping:
            # NEW: cut the face at the NEAR wall (lesson Part 3).
            face_camera = clip_face(face_camera)
            # Fewer than 3 corners left: nothing to paint.
            if len(face_camera) < 3:
                continue
        else:
            # Lesson 4's old rule, for comparing (K): any corner behind
            # the NEAR wall? Skip the whole face.
            too_close = False
            for camera in face_camera:
                if camera[2] < NEAR:
                    too_close = True
            if too_close:
                continue

        # Every corner left is now in front of NEAR, so project() is safe.
        face_points = []
        for camera in face_camera:
            face_points.append(project(camera))        # SCREEN
        # The clock test works on any number of corners (it only looks
        # at the first 3), and clipping keeps them clockwise.
        if not is_facing_you(face_points):
            continue
        distance = average_z(corners, camera_points)
        colour = thing["colour"]
        if use_light:
            spun_pointer = matrix_times_point(thing["matrix"], pointer)
            colour = shade_colour(colour, spun_pointer)
        faces_to_draw.append( (distance, face_points, colour) )

# CLIPPING (Lesson 8)
# ======================================================================
# Everything here works in CAMERA coordinates: (0, 0, 0) is your eye,
# +x is right, +y is up, +z is straight ahead. The NEAR wall is the
# flat sheet z = NEAR (0.1) just in front of your eye.
#   "in"  = in front of the wall:  z >= NEAR   (safe to project)
#   "out" = behind the wall:       z <  NEAR   (must never be projected)

def cut_at_near(point_a, point_b):
    """(step 2): the CAMERA point where the line from point_a to point_b
    crosses the NEAR wall. One end must be in, the other out.

    t says how far along the line the wall is: 0 = at point_a,
    1 = at point_b, 0.5 = halfway (lesson Part 2).

        t = ( (NEAR - a_z) / (b_z - a_z) )

    Then each of x and y moves the same fraction t of its own gap:

        x = ( a_x + (t * (b_x - a_x)) )

    Worked example (lesson Part 2): a = (-2, -1, -1), b = (2, -1, 3)
        t = ( (0.1 - (-1)) / (3 - (-1)) ) = (1.1 / 4) = 0.275
        x = ( -2 + (0.275 * (2 - (-2))) ) = ( -2 + 1.1 ) = -0.9
        y = ( -1 + (0.275 * (-1 - (-1))) ) = -1
        z = NEAR = 0.1          -> (-0.9, -1, 0.1)
    """
    a_x, a_y, a_z = point_a
    b_x, b_y, b_z = point_b
    t = ( (NEAR - a_z) / (b_z - a_z) )
    cut_x = ( a_x + (t * (b_x - a_x)) )
    cut_y = ( a_y + (t * (b_y - a_y)) )
    # The same sum for z would give exactly NEAR, which is the whole
    # point of t, so we just use NEAR.
    return (cut_x, cut_y, NEAR)


def clip_line(start, end):
    """(step 2): keep the part of a CAMERA line that is in front of NEAR.

    Gives back (start, end) with any end behind you swapped for the
    cut point, or None ("nothing to draw") if both ends are behind.
    """
    start_in = (start[2] >= NEAR)
    end_in = (end[2] >= NEAR)
    if start_in and end_in:
        return (start, end)                       # all in front: keep it all
    if (not start_in) and (not end_in):
        return None                               # all behind: nothing
    cut = cut_at_near(start, end)
    if start_in:
        return (start, cut)                       # end was behind
    return (cut, end)                             # start was behind


def clip_face(face_corners):
    """NEW: cut one face at the NEAR wall (lesson Part 3).

    face_corners: the face's corners in CAMERA coordinates, clockwise.
    Gives back the corners of the part in front of NEAR, still in
    clockwise order. That can be 3, 4 or 5 corners, or an empty list
    if the whole face is behind you.

    We walk round the face one edge at a time. Each edge goes from the
    PREVIOUS corner to the CURRENT one, and there are only 4 cases:

        previous  current   keep
        in        in        current
        in        out       the cut point
        out       in        the cut point, then current
        out       out       nothing

    face_corners[-1] means "the LAST item in the list". Starting with
    it as "previous" makes the first edge go last corner -> first
    corner, so the walk goes all the way round and closes the face.

    Worked example (lesson Part 3): the right face of rock 0, seen from
    WORLD (2.5, 0, 3). CAMERA corners in clockwise order:
        5 (-1, 2, -0.5) out    6 (-1, 2, 2.5) in
        2 (-1, -1, 2.5) in     1 (-1, -1, -0.5) out
    Edges 1->5 nothing,  5->6 cut (-1, 2, 0.1) then 6,
          6->2 keep 2,    2->1 cut (-1, -1, 0.1)
    Result: 4 corners  (-1, 2, 0.1) (-1, 2, 2.5) (-1, -1, 2.5) (-1, -1, 0.1)
    """
    kept = []
    previous = face_corners[-1]
    for current in face_corners:
        previous_in = (previous[2] >= NEAR)
        current_in = (current[2] >= NEAR)
        if previous_in and current_in:
            kept.append(current)
        elif previous_in and (not current_in):
            kept.append(cut_at_near(previous, current))
        elif (not previous_in) and current_in:
            kept.append(cut_at_near(previous, current))
            kept.append(current)
        # out -> out: keep nothing
        previous = current
    return kept

def distance_3d(point_a, point_b):
    """(Lesson 7) how far apart are two WORLD points? (lesson Part 2)

    Subtract, square each part, add them up, square-root the total:
    Pythagoras done twice, in one line.

    Worked example (lesson Part 2): you at (1, 0, 3), cube 0 at (3, 1, 5)
        dx = (3 - 1) = 2,  dy = (1 - 0) = 1,  dz = (5 - 3) = 2
        math.sqrt( (2 * 2) + (1 * 1) + (2 * 2) ) = math.sqrt(9) = 3
    """
    ax, ay, az = point_a
    bx, by, bz = point_b
    dx = (bx - ax)
    dy = (by - ay)
    dz = (bz - az)
    return math.sqrt( (dx * dx) + (dy * dy) + (dz * dz) )


def far_from_rocks(spot):
    """(step 1): True if this WORLD spot is at least ROCK_CLEARANCE (3) from
    the centre of every rock, so a new gold cube never hides inside one.

    Worked example (lesson Part 1): spot (1, 1, 5) and rock 0 at
    (0, 0.5, 4): math.sqrt( (1 * 1) + (0.5 * 0.5) + (1 * 1) ) = 1.5,
    less than 3, so False: try again.
    """
    for rock_spot in ROCK_SPOTS:
        if distance_3d(spot, rock_spot) < ROCK_CLEARANCE:
            return False
    return True


def new_pickup_spot():
    """(Lesson 7) a random WORLD spot for a cube, at least
    MIN_SPAWN_DISTANCE from you (lesson Part 4).

    "while True" repeats for ever, until "return" jumps out. Usually the
    first try is far enough; about 1 try in 5 is too close and we
    simply pick again.
    """
    you = (cam_x, cam_y, cam_z)
    while True:
        new_x = random.uniform((-FIELD), FIELD)
        new_y = random.uniform(PICKUP_LOW, PICKUP_HIGH)
        new_z = random.uniform((-FIELD), FIELD)
        spot = (new_x, new_y, new_z)
        # (step 1): "and far_from_rocks(spot)": BOTH must be True.
        if (distance_3d(you, spot) >= MIN_SPAWN_DISTANCE) and far_from_rocks(spot):
            return spot

Q10Why must we clip in CAMERA coordinates, and not first project and then cut on the screen?

project() divides by z. A corner with negative z lands on the wrong side of the screen (corner 5 at x = 1200 instead of far to the left), and z = 0 crashes. By the time it is a screen point, the information about where it really was is wrong. In CAMERA coordinates the NEAR wall is just "z = 0.1", the easiest flat sheet there is to cut against.

Wrap up 4 MIN

  • Lesson 4's rule skipped any face or line with a corner behind NEAR. Next to something big, that throws away whole walls (Fig 8.1.5).
  • Projecting such a corner anyway flips it to the wrong side (Fig 8.1.6). The fix is to cut at NEAR, then project.
  • A CAMERA point is in when z >= NEAR. Only z matters.
  • Where a line crosses the wall: t = ( (NEAR - a_z) / (b_z - a_z) ), then ( a + (t * (b - a)) ) for x and y.
  • clip_line() has 3 cases; clip_face() walks the edges with 4 rules and can return 3, 4 or 5 corners, or none.
  • The floor is now 50 long lines instead of 1,200 pieces.

Q11Final check, using the whole course. You stand at the start, (0, 0, 0), turned left 90 (cam_turn = 90), looking level. Take the floor's cross line at z = 1, from WORLD (−12, −1, 1) to (12, −1, 1). Take it to CAMERA, clip it, and find where it is on the screen.

Show answer

1. camera_matrix (Lesson 6) = combine(turn_matrix(-90), tip_matrix(0)) = turn_matrix(-90). cos(−90) = 0 and sin(−90) = −1, so its rows are (0, 0, 1), (0, 1, 0), (−1, 0, 0). In words: CAMERA x = WORLD z, y = y, CAMERA z = −(WORLD x).

2. Start (−12, −1, 1) → CAMERA (1, −1, 12). End (12, −1, 1) → CAMERA (1, −1, −12). The start is in front of you, the end behind: you are facing −x, so the line runs from ahead to behind.

3. Clip (today): t = ( (0.1 - 12) / (-12 - 12) ) = (-11.9 / -24) = 0.4958. x = ( 1 + (0.4958 * (1 - 1)) ) = 1, y = −1. The end becomes the cut (1, −1, 0.1).

4. Project (Lesson 1): start x = (400 + ((1 * 400) / 12)) = 433.3, y = (300 - ((-1 * 400) / 12)) = 333.3. Cut x = (400 + ((1 * 400) / 0.1)) = 4400, y = (300 - ((-1 * 400) / 0.1)) = 4300.

5. The line goes from (433.3, 333.3) down and right at 45 degrees towards (4400, 4300), and leaves the window through the bottom edge at (700, 600). With Lesson 7's rule, the whole line would have been skipped.

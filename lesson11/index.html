Part 1: Velocity 7 MIN

Hold W in Cube Hunt and your speed jumps from 0 to full in one frame. Let go and it jumps back to 0. Here are the real numbers, frame by frame, beside what we will build today:

To speed up smoothly, the program needs to remember how fast you are going. That memory is your velocity: three numbers that say how far you move along x, y and z each frame.

vel_x = 0        # units a frame, along x (start: standing still)
vel_y = 0
vel_z = 0

# every frame:
cam_x = (cam_x + vel_x)
cam_y = (cam_y + vel_y)
cam_z = (cam_z + vel_z)

Keys will no longer move cam_x directly. They will change the velocity, and the velocity moves you. That one extra step is what gives you speeding up and slowing down.

Part 2: Thrust and drag 14 MIN

Thrust: keys push

Each frame W is held, it adds a small push, THRUST, to your velocity along the forward arrow:

Drag: keep 90%

Where they balance: the top speed

Push and drag fight every frame. When you're slow, drag takes away less than thrust adds, so you speed up. When you're fast, drag takes away more. They are equal at exactly one speed:

KEY CONCEPT 
vel = (vel * DRAG)              # 1. drag
vel = (vel + (arrow * THRUST))  # 2. push
cam = (cam + vel)               # 3. move

Every moving thing in a game does these three jobs every frame. Keys only ever change the velocity; the velocity changes where you are.

Why 0.005 and 0.9?

Many pairs give the same top speed of 0.05. What changes is how it feels:

THRUST = 0.005
DRAG = 0.9          # top speed (0.005 / (1 - 0.9)) = 0.05 = Lesson 7's MOVE_SPEED

def matrix_times_point(matrix, point_3d):
    """Put one point through a matrix: each ROW dotted with the point."""
    row_0, row_1, row_2 = matrix
    new_x = dot(row_0, point_3d)
    new_y = dot(row_1, point_3d)
    new_z = dot(row_2, point_3d)
    return (new_x, new_y, new_z)


def tip_matrix(angle_degrees):
    """Lesson 2B's TIP as a grid. x is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (1, 0,     0         ),
        (0, cos_a, (-sin_a)  ),
        (0, sin_a, cos_a     ),
    )


def turn_matrix(angle_degrees):
    """Lesson 2's TURN as a grid. y is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (cos_a, 0, (-sin_a)),
        (0,     1, 0       ),
        (sin_a, 0, cos_a   ),
    )


def roll_matrix(angle_degrees):
    """Lesson 2B's ROLL as a grid. z is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (cos_a, (-sin_a), 0),
        (sin_a, cos_a,    0),
        (0,     0,        1),
    )


def column(matrix, column_number):
    """One COLUMN of a matrix = where that axis arrow lands."""
    row_0, row_1, row_2 = matrix
    return (row_0[column_number], row_1[column_number], row_2[column_number])


def combine(first, second):
    """ONE matrix that does 'first', then 'second' (Lesson 6)."""
    new_col_0 = matrix_times_point(second, column(first, 0))
    new_col_1 = matrix_times_point(second, column(first, 1))
    new_col_2 = matrix_times_point(second, column(first, 2))
    return (
        (new_col_0[0], new_col_1[0], new_col_2[0]),
        (new_col_0[1], new_col_1[1], new_col_2[1]),
        (new_col_0[2], new_col_1[2], new_col_2[2]),
    )


def spin_matrix(angles):
    """A thing's whole spin as ONE matrix: tip, then turn, then roll."""
    tip_then_turn = combine(tip_matrix(angles[0]), turn_matrix(angles[1]))
    return combine(tip_then_turn, roll_matrix(angles[2]))

def to_world(shape_point, thing):
    """(Lesson 5) SHAPE -> WORLD: size, then spin, then place."""
    x, y, z = shape_point
    size = thing["size"]
    sized = ( (x * size), (y * size), (z * size) )
    spun = matrix_times_point(thing["matrix"], sized)
    pos_x, pos_y, pos_z = thing["position"]
    sx, sy, sz = spun
    return ( (sx + pos_x), (sy + pos_y), (sz + pos_z) )


def to_camera(world_point):
    """(Lessons 4 and 6) WORLD -> CAMERA: subtract you, then camera_matrix."""
    x, y, z = world_point
    moved = ( (x - cam_x), (y - cam_y), (z - cam_z) )
    return matrix_times_point(camera_matrix, moved)


def project(point_3d):
    """(Lesson 1) CAMERA -> SCREEN. Only call it with z >= NEAR."""
    x, y, z = point_3d
    screen_x = CENTRE_X + ( (x * FOCAL) / z )
    screen_y = CENTRE_Y - ( (y * FOCAL) / z )
    return (screen_x, screen_y)


def average_z(corners, camera_points):
    """(Lesson 3) how far away is this face? Uses CAMERA z."""
    total = 0
    for corner_number in corners:
        x, y, z = camera_points[corner_number]
        total = (total + z)
    return (total / len(corners))


def is_facing_you(face_points):
    """(Lesson 3) the clock test: True if clockwise on the screen."""
    a_x, a_y = face_points[0]
    b_x, b_y = face_points[1]
    c_x, c_y = face_points[2]
    arrow_a_x = (b_x - a_x)
    arrow_a_y = (b_y - a_y)
    arrow_b_x = (c_x - a_x)
    arrow_b_y = (c_y - a_y)
    cross = ( (arrow_a_x * arrow_b_y) - (arrow_a_y * arrow_b_x) )
    return (cross > 0)


def dot(arrow_1, arrow_2):
    """(Lesson 3) the dot product."""
    x1, y1, z1 = arrow_1
    x2, y2, z2 = arrow_2
    return ( (x1 * x2) + (y1 * y2) + (z1 * z2) )


def shade_colour(colour, pointer):
    """(Lesson 3) brighter when the face points at the light."""
    brightness = dot(pointer, LIGHT)
    if brightness < 0:
        brightness = 0
    shade = ( AMBIENT + ( (1 - AMBIENT) * brightness ) )
    red, green, blue = colour
    return ( round(red * shade), round(green * shade), round(blue * shade) )


def keep_under_360(angle):
    """Keep an angle between 0 and 360."""
    if angle >= 360:
        angle = (angle - 360)
    if angle < 0:
        angle = (angle + 360)
    return angle


def add_faces_of(thing, faces_to_draw):
    """(Lesson 5) work out every face of ONE thing and add the ones to
    paint to the shared list (unchanged from Lesson 6)."""
    model = thing["model"]
    camera_points = []
    screen_points = []
    for p in model["points"]:
        world = to_world(p, thing)                     # WORLD
        camera = to_camera(world)                      # CAMERA
        camera_points.append(camera)
        if camera[2] >= NEAR:
            screen_points.append(project(camera))      # SCREEN
        else:
            screen_points.append(None)

    for corners, face_colour, pointer in model["faces"]:
        too_close = False
        for corner_number in corners:
            if camera_points[corner_number][2] < NEAR:
                too_close = True
        if too_close:
            continue
        face_points = []
        for corner_number in corners:
            face_points.append(screen_points[corner_number])
        if not is_facing_you(face_points):
            continue
        distance = average_z(corners, camera_points)
        colour = thing["colour"]
        if use_light:
            spun_pointer = matrix_times_point(thing["matrix"], pointer)
            colour = shade_colour(colour, spun_pointer)
        faces_to_draw.append( (distance, face_points, colour) )

def distance_3d(point_a, point_b):
    """(step 1) how far apart are two WORLD points? (lesson Part 2)

    Subtract, square each part, add them up, square-root the total:
    Pythagoras done twice, in one line.

    Worked example (lesson Part 2): you at (1, 0, 3), cube 0 at (3, 1, 5)
        dx = (3 - 1) = 2,  dy = (1 - 0) = 1,  dz = (5 - 3) = 2
        math.sqrt( (2 * 2) + (1 * 1) + (2 * 2) ) = math.sqrt(9) = 3
    """
    ax, ay, az = point_a
    bx, by, bz = point_b
    dx = (bx - ax)
    dy = (by - ay)
    dz = (bz - az)
    return math.sqrt( (dx * dx) + (dy * dy) + (dz * dz) )


def new_pickup_spot():
    """(step 2) a random WORLD spot for a cube, at least
    MIN_SPAWN_DISTANCE from you (lesson Part 4).

    "while True" repeats for ever, until "return" jumps out. Usually the
    first try is far enough; about 1 try in 5 is too close and we
    simply pick again.
    """
    you = (cam_x, cam_y, cam_z)
    while True:
        new_x = random.uniform((-FIELD), FIELD)
        new_y = random.uniform(PICKUP_LOW, PICKUP_HIGH)
        new_z = random.uniform((-FIELD), FIELD)
        spot = (new_x, new_y, new_z)
        if distance_3d(you, spot) >= MIN_SPAWN_DISTANCE:

Your eye and your feet

The camera is your eye. To stand on things, the program also needs to know where your feet are:

Gravity

Gravity is just a push, like thrust, that always points down and never lets go:

GRAVITY = 0.01
vel_y = (vel_y - GRAVITY)     # every frame
cam_y = (cam_y + vel_y)

The floor check

if feet_y < FLOOR_Y:
    cam_y = (FLOOR_Y + EYE_HEIGHT)

Jumping

A jump is one line. While your feet are on something, SPACE sets vel_y to JUMP_SPEED. Gravity does all the rest:

KEY CONCEPT 
if SPACE and on_ground:  vel_y = JUMP_SPEED
vel_y = (vel_y - GRAVITY)       # every frame
cam_y = (cam_y + vel_y)

A jump only sets the velocity once. The arc, the slowing down at the top and the fall all come from gravity, the same line every frame.

GRAVITY = 0.01
JUMP_SPEED = 0.2     # feet rise 1.9, about 39 frames (0.65 s) in the air

def matrix_times_point(matrix, point_3d):
    """Put one point through a matrix: each ROW dotted with the point."""
    row_0, row_1, row_2 = matrix
    new_x = dot(row_0, point_3d)
    new_y = dot(row_1, point_3d)
    new_z = dot(row_2, point_3d)
    return (new_x, new_y, new_z)


def tip_matrix(angle_degrees):
    """Lesson 2B's TIP as a grid. x is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (1, 0,     0         ),
        (0, cos_a, (-sin_a)  ),
        (0, sin_a, cos_a     ),
    )


def turn_matrix(angle_degrees):
    """Lesson 2's TURN as a grid. y is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (cos_a, 0, (-sin_a)),
        (0,     1, 0       ),
        (sin_a, 0, cos_a   ),
    )


def roll_matrix(angle_degrees):
    """Lesson 2B's ROLL as a grid. z is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (cos_a, (-sin_a), 0),
        (sin_a, cos_a,    0),
        (0,     0,        1),
    )


def column(matrix, column_number):
    """One COLUMN of a matrix = where that axis arrow lands."""
    row_0, row_1, row_2 = matrix
    return (row_0[column_number], row_1[column_number], row_2[column_number])


def combine(first, second):
    """ONE matrix that does 'first', then 'second' (Lesson 6)."""
    new_col_0 = matrix_times_point(second, column(first, 0))
    new_col_1 = matrix_times_point(second, column(first, 1))
    new_col_2 = matrix_times_point(second, column(first, 2))
    return (
        (new_col_0[0], new_col_1[0], new_col_2[0]),
        (new_col_0[1], new_col_1[1], new_col_2[1]),
        (new_col_0[2], new_col_1[2], new_col_2[2]),
    )


def spin_matrix(angles):
    """A thing's whole spin as ONE matrix: tip, then turn, then roll."""
    tip_then_turn = combine(tip_matrix(angles[0]), turn_matrix(angles[1]))
    return combine(tip_then_turn, roll_matrix(angles[2]))

def to_world(shape_point, thing):
    """(Lesson 5) SHAPE -> WORLD: size, then spin, then place."""
    x, y, z = shape_point
    size = thing["size"]
    sized = ( (x * size), (y * size), (z * size) )
    spun = matrix_times_point(thing["matrix"], sized)
    pos_x, pos_y, pos_z = thing["position"]
    sx, sy, sz = spun
    return ( (sx + pos_x), (sy + pos_y), (sz + pos_z) )


def to_camera(world_point):
    """(Lessons 4 and 6) WORLD -> CAMERA: subtract you, then camera_matrix."""
    x, y, z = world_point
    moved = ( (x - cam_x), (y - cam_y), (z - cam_z) )
    return matrix_times_point(camera_matrix, moved)


def project(point_3d):
    """(Lesson 1) CAMERA -> SCREEN. Only call it with z >= NEAR."""
    x, y, z = point_3d
    screen_x = CENTRE_X + ( (x * FOCAL) / z )
    screen_y = CENTRE_Y - ( (y * FOCAL) / z )
    return (screen_x, screen_y)


def average_z(corners, camera_points):
    """(Lesson 3) how far away is this face? Uses CAMERA z."""
    total = 0
    for corner_number in corners:
        x, y, z = camera_points[corner_number]
        total = (total + z)
    return (total / len(corners))


def is_facing_you(face_points):
    """(Lesson 3) the clock test: True if clockwise on the screen."""
    a_x, a_y = face_points[0]
    b_x, b_y = face_points[1]
    c_x, c_y = face_points[2]
    arrow_a_x = (b_x - a_x)
    arrow_a_y = (b_y - a_y)
    arrow_b_x = (c_x - a_x)
    arrow_b_y = (c_y - a_y)
    cross = ( (arrow_a_x * arrow_b_y) - (arrow_a_y * arrow_b_x) )
    return (cross > 0)


def dot(arrow_1, arrow_2):
    """(Lesson 3) the dot product."""
    x1, y1, z1 = arrow_1
    x2, y2, z2 = arrow_2
    return ( (x1 * x2) + (y1 * y2) + (z1 * z2) )


def shade_colour(colour, pointer):
    """(Lesson 3) brighter when the face points at the light."""
    brightness = dot(pointer, LIGHT)
    if brightness < 0:
        brightness = 0
    shade = ( AMBIENT + ( (1 - AMBIENT) * brightness ) )
    red, green, blue = colour
    return ( round(red * shade), round(green * shade), round(blue * shade) )


def keep_under_360(angle):
    """Keep an angle between 0 and 360."""
    if angle >= 360:
        angle = (angle - 360)
    if angle < 0:
        angle = (angle + 360)
    return angle


def add_faces_of(thing, faces_to_draw):
    """(Lesson 5) work out every face of ONE thing and add the ones to
    paint to the shared list (unchanged from Lesson 6)."""
    model = thing["model"]
    camera_points = []
    screen_points = []
    for p in model["points"]:
        world = to_world(p, thing)                     # WORLD
        camera = to_camera(world)                      # CAMERA
        camera_points.append(camera)
        if camera[2] >= NEAR:
            screen_points.append(project(camera))      # SCREEN
        else:
            screen_points.append(None)

    for corners, face_colour, pointer in model["faces"]:
        too_close = False
        for corner_number in corners:
            if camera_points[corner_number][2] < NEAR:
                too_close = True
        if too_close:
            continue
        face_points = []
        for corner_number in corners:
            face_points.append(screen_points[corner_number])
        if not is_facing_you(face_points):
            continue
        distance = average_z(corners, camera_points)
        colour = thing["colour"]
        if use_light:
            spun_pointer = matrix_times_point(thing["matrix"], pointer)
            colour = shade_colour(colour, spun_pointer)
        faces_to_draw.append( (distance, face_points, colour) )


def draw_floor():
    """(Lesson 5) the floor grid, in 1-unit pieces (now -12 to 12)."""
    for x in range(GRID_LEFT, (GRID_RIGHT + 1)):
        for z in range(GRID_NEAR, GRID_FAR):
            draw_floor_piece( (x, FLOOR_Y, z), (x, FLOOR_Y, (z + 1)) )

        for x in range(GRID_LEFT, GRID_RIGHT):
            draw_floor_piece( (x, FLOOR_Y, z), ((x + 1), FLOOR_Y, z) )

    """(Lesson 5) one 1-unit piece of floor line."""
    start = to_camera(world_start)
    end = to_camera(world_end)
    if (start[2] < NEAR) or (end[2] < NEAR):
        return
    pygame.draw.line(screen, GRID_COLOUR, project(start), project(end), 1)

def distance_3d(point_a, point_b):
    """(step 1) how far apart are two WORLD points? (lesson Part 2)

    Subtract, square each part, add them up, square-root the total:
    Pythagoras done twice, in one line.

    Worked example (lesson Part 2): you at (1, 0, 3), cube 0 at (3, 1, 5)
        dx = (3 - 1) = 2,  dy = (1 - 0) = 1,  dz = (5 - 3) = 2
        math.sqrt( (2 * 2) + (1 * 1) + (2 * 2) ) = math.sqrt(9) = 3
    """
    ax, ay, az = point_a
    bx, by, bz = point_b
    dx = (bx - ax)
    dy = (by - ay)
    dz = (bz - az)
    return math.sqrt( (dx * dx) + (dy * dy) + (dz * dz) )


def new_pickup_spot():
    """(step 2) a random WORLD spot for a cube, at least
    MIN_SPAWN_DISTANCE from you (lesson Part 4).

    "while True" repeats for ever, until "return" jumps out. Usually the
    first try is far enough; about 1 try in 5 is too close and we
    simply pick again.
    """
    you = (cam_x, cam_y, cam_z)
    while True:
        new_x = random.uniform((-FIELD), FIELD)
        new_y = random.uniform(PICKUP_LOW, PICKUP_HIGH)
        new_z = random.uniform((-FIELD), FIELD)
        spot = (new_x, new_y, new_z)
        if distance_3d(you, spot) >= MIN_SPAWN_DISTANCE:
            return spot


def to_map(x, z):
    """A WORLD (x, z) -> a pixel on the mini-map (from Lesson 4)."""
    map_x = MAP_CX + (x * MAP_SCALE)
    map_y = MAP_CY - (z * MAP_SCALE)
    return (map_x, map_y)

            cam_tip = (cam_tip - TURN_SPEED)
        if keys[pygame.K_DOWN]:

        if cam_tip > TIP_LIMIT:

        right_x, right_y, right_z = column(turn_matrix(cam_turn), 0)

        # ==============================================================
        # SIDEWAYS (x and z): exactly step 1's three jobs
        # ==============================================================
        # Job 1: DRAG, now on x and z only. (Drag on vel_y would spoil
        # the jump's neat numbers, and air hardly slows a fall anyway.)
        vel_x = (vel_x * DRAG)
        vel_z = (vel_z * DRAG)

        # Job 2: THRUST along the level arrows. forward_y and right_y

        if keys[pygame.K_w]:

            vel_z = (vel_z + (right_z * THRUST))
        if keys[pygame.K_a]:
            vel_x = (vel_x - (right_x * THRUST))
            vel_z = (vel_z - (right_z * THRUST))

        # Job 3: MOVE.
        cam_x = (cam_x + vel_x)
        cam_z = (cam_z + vel_z)

        # Walls (Lesson 7 + step 1): back ON the wall, that velocity 0.
        if cam_x > WALL:
            cam_x = WALL
            vel_x = 0
        if cam_x < (-WALL):
            cam_x = (-WALL)
            vel_x = 0
        if cam_z > WALL:
            cam_z = WALL
            vel_z = 0
        if cam_z < (-WALL):
            cam_z = (-WALL)
            vel_z = 0

        # ==============================================================

        #   jump frame:    (0.2 - 0.01) = 0.19
        vel_y = (vel_y - GRAVITY)

        # MOVE up or down.
        cam_y = (cam_y + vel_y)

        # FLOOR: where are your feet? Below the floor -> stand ON it.
        # Standing still this happens every frame: gravity pulls you
        # 0.01 into the floor, and we put you straight back.
        on_ground = False
        feet_y = (cam_y - EYE_HEIGHT)
        if feet_y < FLOOR_Y:

Show answer

Going up, vel_y is 0.18, 0.16, … 0.02: (0.02 * (1 + 2 + ... + 9)) = (0.02 * 45) = 0.9. 0.9 is less than 1, so no.

Q5You walk off a ledge 1 unit above the floor. How many frames until you land?

Show answer

After n frames you've fallen (0.01 * (1 + 2 + ... + n)). n = 13 gives (0.01 * 91) = 0.91; n = 14 gives (0.01 * 105) = 1.05, past the floor. So you land on frame 14, about 0.23 s.

Q6What would happen if we forgot the line on_ground = False?

Show answer

Once you'd stood on the floor, on_ground would stay True for ever, even in the air. Holding SPACE would set vel_y = 0.2 every frame and you'd fly straight up.

KEY CONCEPT 
boxes overlap = (overlap on x) and (overlap on y) and (overlap on z)

def boxes_overlap(box_a, box_b):

def matrix_times_point(matrix, point_3d):
    """Put one point through a matrix: each ROW dotted with the point."""
    row_0, row_1, row_2 = matrix
    new_x = dot(row_0, point_3d)
    new_y = dot(row_1, point_3d)
    new_z = dot(row_2, point_3d)
    return (new_x, new_y, new_z)


def tip_matrix(angle_degrees):
    """Lesson 2B's TIP as a grid. x is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (1, 0,     0         ),
        (0, cos_a, (-sin_a)  ),
        (0, sin_a, cos_a     ),
    )


def turn_matrix(angle_degrees):
    """Lesson 2's TURN as a grid. y is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (cos_a, 0, (-sin_a)),
        (0,     1, 0       ),
        (sin_a, 0, cos_a   ),
    )


def roll_matrix(angle_degrees):
    """Lesson 2B's ROLL as a grid. z is the skewer."""
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    return (
        (cos_a, (-sin_a), 0),
        (sin_a, cos_a,    0),
        (0,     0,        1),
    )


def column(matrix, column_number):
    """One COLUMN of a matrix = where that axis arrow lands."""
    row_0, row_1, row_2 = matrix
    return (row_0[column_number], row_1[column_number], row_2[column_number])


def combine(first, second):
    """ONE matrix that does 'first', then 'second' (Lesson 6)."""
    new_col_0 = matrix_times_point(second, column(first, 0))
    new_col_1 = matrix_times_point(second, column(first, 1))
    new_col_2 = matrix_times_point(second, column(first, 2))
    return (
        (new_col_0[0], new_col_1[0], new_col_2[0]),
        (new_col_0[1], new_col_1[1], new_col_2[1]),
        (new_col_0[2], new_col_1[2], new_col_2[2]),
    )


def spin_matrix(angles):
    """A thing's whole spin as ONE matrix: tip, then turn, then roll."""
    tip_then_turn = combine(tip_matrix(angles[0]), turn_matrix(angles[1]))
    return combine(tip_then_turn, roll_matrix(angles[2]))

def to_world(shape_point, thing):
    """(Lesson 5) SHAPE -> WORLD: size, then spin, then place."""
    x, y, z = shape_point
    size = thing["size"]
    sized = ( (x * size), (y * size), (z * size) )
    spun = matrix_times_point(thing["matrix"], sized)
    pos_x, pos_y, pos_z = thing["position"]
    sx, sy, sz = spun
    return ( (sx + pos_x), (sy + pos_y), (sz + pos_z) )


def to_camera(world_point):
    """(Lessons 4 and 6) WORLD -> CAMERA: subtract you, then camera_matrix."""
    x, y, z = world_point
    moved = ( (x - cam_x), (y - cam_y), (z - cam_z) )
    return matrix_times_point(camera_matrix, moved)


def project(point_3d):
    """(Lesson 1) CAMERA -> SCREEN. Only call it with z >= NEAR."""
    x, y, z = point_3d
    screen_x = CENTRE_X + ( (x * FOCAL) / z )
    screen_y = CENTRE_Y - ( (y * FOCAL) / z )
    return (screen_x, screen_y)


def average_z(corners, camera_points):
    """(Lesson 3) how far away is this face? Uses CAMERA z."""
    total = 0
    for corner_number in corners:
        x, y, z = camera_points[corner_number]
        total = (total + z)
    return (total / len(corners))


def is_facing_you(face_points):
    """(Lesson 3) the clock test: True if clockwise on the screen."""
    a_x, a_y = face_points[0]
    b_x, b_y = face_points[1]
    c_x, c_y = face_points[2]
    arrow_a_x = (b_x - a_x)
    arrow_a_y = (b_y - a_y)
    arrow_b_x = (c_x - a_x)
    arrow_b_y = (c_y - a_y)
    cross = ( (arrow_a_x * arrow_b_y) - (arrow_a_y * arrow_b_x) )
    return (cross > 0)


def dot(arrow_1, arrow_2):
    """(Lesson 3) the dot product."""
    x1, y1, z1 = arrow_1
    x2, y2, z2 = arrow_2
    return ( (x1 * x2) + (y1 * y2) + (z1 * z2) )

        too_close = False

            if camera_points[corner_number][2] < NEAR:
                too_close = True

            continue
        face_points = []

            face_points.append(screen_points[corner_number])
        if not is_facing_you(face_points):
            continue
        distance = average_z(corners, camera_points)
        colour = thing["colour"]
        if use_light:
            spun_pointer = matrix_times_point(thing["matrix"], pointer)
            colour = shade_colour(colour, spun_pointer)
        faces_to_draw.append( (distance, face_points, colour) )

def distance_3d(point_a, point_b):
    """(step 1) how far apart are two WORLD points? (lesson Part 2)

    Subtract, square each part, add them up, square-root the total:
    Pythagoras done twice, in one line.

    Worked example (lesson Part 2): you at (1, 0, 3), cube 0 at (3, 1, 5)
        dx = (3 - 1) = 2,  dy = (1 - 0) = 1,  dz = (5 - 3) = 2
        math.sqrt( (2 * 2) + (1 * 1) + (2 * 2) ) = math.sqrt(9) = 3
    """
    ax, ay, az = point_a
    bx, by, bz = point_b
    dx = (bx - ax)
    dy = (by - ay)
    dz = (bz - az)
    return math.sqrt( (dx * dx) + (dy * dy) + (dz * dz) )

def player_box():
    """NEW: YOUR body as a box, in WORLD coordinates (lesson Part 4).

    A box is 6 numbers: (min_x, max_x, min_y, max_y, min_z, max_z).
    Your eye (the camera) is at the top, in the middle:
        x:  cam_x - 0.25  to  cam_x + 0.25
        y:  your feet (cam_y - 0.5)  to  your eye (cam_y)
        z:  cam_z - 0.25  to  cam_z + 0.25
    Standing at the start, (0, -0.5, 0):
        (-0.25, 0.25,  -1, -0.5,  -0.25, 0.25)
    """
    return ( (cam_x - PLAYER_RADIUS), (cam_x + PLAYER_RADIUS),
             (cam_y - EYE_HEIGHT),    cam_y,
             (cam_z - PLAYER_RADIUS), (cam_z + PLAYER_RADIUS) )


def crate_box(crate):
    """NEW: a crate as a box, in WORLD coordinates (lesson Part 4).

    It reaches "size" each way from its centre. Crate A, centre
    (0, -0.5, 3), size 0.5:
        x: (0 - 0.5) to (0 + 0.5)        = -0.5 to 0.5
        y: (-0.5 - 0.5) to (-0.5 + 0.5)  = -1   to 0     (floor to top)
        z: (3 - 0.5) to (3 + 0.5)        =  2.5 to 3.5
    """
    x, y, z = crate["position"]
    size = crate["size"]
    return ( (x - size), (x + size),
             (y - size), (y + size),
             (z - size), (z + size) )


def overlap_on_line(a_min, a_max, b_min, b_max):
    """NEW: do two pieces of ONE number line overlap? (lesson Part 4)

    They overlap if A starts before B ends AND B starts before A ends.
        A 1 to 3,  B 2 to 5:   (1 < 5) and (2 < 3)  -> True
        A 1 to 3,  B 4 to 5:   (1 < 5) and (4 < 3)  -> False
    "<", not "<=": two pieces that only touch (A 1 to 3, B 3 to 5) do
    NOT overlap. That is what lets you stand exactly ON a crate's top.
    """
    return (a_min < b_max) and (b_min < a_max)


def boxes_overlap(box_a, box_b):
    """NEW: do two boxes overlap? Only if they overlap on the x line
    AND the y line AND the z line (lesson Part 4, the KEY CONCEPT).
    One gap on any one line, and they don't touch."""
    a_min_x, a_max_x, a_min_y, a_max_y, a_min_z, a_max_z = box_a
    b_min_x, b_max_x, b_min_y, b_max_y, b_min_z, b_max_z = box_b
    on_x = overlap_on_line(a_min_x, a_max_x, b_min_x, b_max_x)
    on_y = overlap_on_line(a_min_y, a_max_y, b_min_y, b_max_y)
    on_z = overlap_on_line(a_min_z, a_max_z, b_min_z, b_max_z)
    return (on_x and on_y and on_z)


def crate_you_are_in():
    """NEW: the box of the first crate your body overlaps, or None if
    you are not inside any crate (lesson Part 5)."""
    you = player_box()
    for crate in crates:
        box = crate_box(crate)
        if boxes_overlap(you, box):
            return box
    return None


def new_pickup_spot():
    """(step 2) a random WORLD spot for a cube, at least
    MIN_SPAWN_DISTANCE from you (lesson Part 4).

    "while True" repeats for ever, until "return" jumps out. Usually the
    first try is far enough; about 1 try in 5 is too close and we
    simply pick again.
    """
    you = (cam_x, cam_y, cam_z)
    while True:
        new_x = random.uniform((-FIELD), FIELD)
        new_y = random.uniform(PICKUP_LOW, PICKUP_HIGH)
        new_z = random.uniform((-FIELD), FIELD)
        spot = (new_x, new_y, new_z)
        # NEW: the gold cube's own box (it reaches 0.5 each way)...
        cube_box = ( (new_x - PICKUP_SIZE), (new_x + PICKUP_SIZE),
                     (new_y - PICKUP_SIZE), (new_y + PICKUP_SIZE),
                     (new_z - PICKUP_SIZE), (new_z + PICKUP_SIZE) )
        # ...must not overlap any crate, or you could never reach it.
        inside_a_crate = False
        for crate in crates:
            if boxes_overlap(cube_box, crate_box(crate)):
                inside_a_crate = True
        if inside_a_crate:
            continue          # "continue" = skip the rest, try again
        if distance_3d(you, spot) >= MIN_SPAWN_DISTANCE:
            return spot

    return (map_x, map_y)

        # ---- Turning and looking (from Lesson 4, unchanged) ----------
        if keys[pygame.K_LEFT]:

        if keys[pygame.K_RIGHT]:
            cam_turn = (cam_turn - TURN_SPEED)
        if keys[pygame.K_UP]:

        if keys[pygame.K_DOWN]:

        if cam_tip > TIP_LIMIT:

        if cam_tip < (-TIP_LIMIT):

        # ---- NEW: walk where your BODY faces (lesson Part 3) ----------
        # Lesson 6's level arrows, from cam_turn only. Looking up no
        # longer lifts you: only a jump can do that now.
        forward_x, forward_y, forward_z = column(turn_matrix(cam_turn), 2)
        right_x, right_y, right_z = column(turn_matrix(cam_turn), 0)

        # ==============================================================
        # SIDEWAYS (x and z): exactly step 1's three jobs
        # ==============================================================
        # Job 1: DRAG, now on x and z only. (Drag on vel_y would spoil
        # the jump's neat numbers, and air hardly slows a fall anyway.)
        vel_x = (vel_x * DRAG)
        vel_z = (vel_z * DRAG)

        # Job 2: THRUST along the level arrows. forward_y and right_y
        # are always 0 now, so we only need x and z.
        if keys[pygame.K_w]:
            vel_x = (vel_x + (forward_x * THRUST))
            vel_z = (vel_z + (forward_z * THRUST))
        if keys[pygame.K_s]:
            vel_x = (vel_x - (forward_x * THRUST))
            vel_z = (vel_z - (forward_z * THRUST))

            vel_z = (vel_z + (right_z * THRUST))
        if keys[pygame.K_a]:
            vel_x = (vel_x - (right_x * THRUST))
            vel_z = (vel_z - (right_z * THRUST))

        # NEW: MOVE ONE AXIS AT A TIME, AND PUSH BACK OUT (Part 5)
        # ==============================================================
        # Why one at a time? After moving ONLY x, if you are now inside
        # a crate it can only be because of x, so you know which side
        # you came in through: the side your vel_x was heading for.

        # ---- x ------------------------------------------------------
        cam_x = (cam_x + vel_x)
        box = crate_you_are_in()
        if box is not None:
            min_x, max_x, min_y, max_y, min_z, max_z = box
            if vel_x > 0:
                # Moving +x (right): you hit the crate's LEFT side,
                # min_x. Put YOUR right side (cam_x + 0.25) on it.
                cam_x = (min_x - PLAYER_RADIUS)
            else:

                cam_x = (max_x + PLAYER_RADIUS)

        # Worked example (lesson Part 5): walking at you z 2.22 into

        # its near side 2.5 -> cam_z = (2.5 - 0.25) = 2.25, vel_z = 0.

            if vel_z > 0:

            else:

            vel_z = 0

            vel_x = 0
        if cam_x < (-WALL):

        # things: falling onto a top is LANDING. -----------------------
        cam_y = (cam_y + vel_y)
        on_ground = False
        box = crate_you_are_in()
        if box is not None:
            min_x, max_x, min_y, max_y, min_z, max_z = box
            if vel_y < 0:

                # Put them back ON it, exactly like the floor.
                # Crate A: top 0, so cam_y = (0 + 0.5) = 0.5.

            else:

Q9You walk −x into crate B's right side (B's box x is 4 to 6). Before the move cam_x = 6.27, vel_x = −0.05, and your z and y overlap B. Where do you end up?

Show answer

cam_x = (6.27 + -0.05) = 6.22; your box x is (6.22 - 0.25) = 5.97 to 6.47. (5.97 < 6) and (4 < 6.47): inside. vel_x < 0, so you hit max_x: cam_x = (6 + 0.25) = 6.25, vel_x = 0.

Q10Standing on crate A, what is cam_y? And how high can your eye get if you jump from there?

Show answer

cam_y = (0 + 0.5) = 0.5. A jump adds 1.9, so (0.5 + 1.9) = 2.4.

Q11A new cube is tried at (5, 1.4, 2), then at (5, 1.6, 2). Which is kept (crate B: x 4 to 6, y −1 to 1, z 1 to 3)?

Show answer

The cube reaches 0.5 each way. First: y 0.9 to 1.9, and (0.9 < 1), so y overlaps, as do x and z: rejected. Second: y 1.1 to 2.1, and (1.1 < 1) is False, a gap: kept. It floats just above B, so stand on B to get it.

Wrap up 3 MIN

  • Velocity: how far you move each frame. Keys push it; it moves you.
  • Drag and thrust balance at (THRUST / (1 - DRAG)): 0.05 a frame, 3 units a second.
  • Gravity takes 0.01 off vel_y every frame. A jump sets vel_y to 0.2 once; your feet rise 1.9.
  • Two boxes overlap only if they overlap on x and y and z.
  • Move one axis at a time, and push back out the side you came in through.

Q12Final check. You stand at the start, eye (0, −0.5, 0), looking level ahead. Follow crate A's corner 5, SHAPE (1, 1, −1), to the screen. Then walk until you bump A (cam_z = 2.25) and do it again.

Show answer

1. Size (Lesson 5): ((1 * 0.5), (1 * 0.5), (-1 * 0.5)) = (0.5, 0.5, −0.5). Crates never spin, so the spin changes nothing.

2. Place: ((0.5 + 0), (0.5 + -0.5), (-0.5 + 3)) = WORLD (0.5, 0, 2.5): the top-right corner of A's near side.

3. At the start, subtract you: ((0.5 - 0), (0 - -0.5), (2.5 - 0)) = CAMERA (0.5, 0.5, 2.5). Project: x = 400 + ((0.5 * 400) / 2.5) = 480, y = 300 - ((0.5 * 400) / 2.5) = 220. SCREEN (480, 220).

4. Bumped at (0, −0.5, 2.25): CAMERA (0.5, 0.5, 0.25). z = 0.25 is more than NEAR = 0.1, so it is drawn. x = 400 + ((0.5 * 400) / 0.25) = 1200, past the 800 px window edge. The face is so close it fills the whole window, exactly as Fig 11.4.3 promised.

A small world

One cube in empty space makes it hard to feel that you are moving. Today the world fills up: a floor to stand on, a new shape (the pyramid), and seven things placed around you, each with its own place, its own size and its own spin. The trick is to stop writing "the cube" in the code and start writing "every thing in a list".

Where this fits

Before: Lesson 4, Moving the camera. You learned to_camera(): subtract where you stand, undo your turn, undo your tip. You walked round one cube.

Today: Lesson 5, A small world. Many shapes from a list, each with its own position, size and spin, all sorted together, standing on a floor grid.

Next: Lesson 6, Matrices. Today's separate tip, turn and roll steps get packed into one 3 × 3 grid of numbers, the way real 3D engines do it.

Recap: the recipe so far 3 MIN

Lesson 4 ended with a camera you could walk, turn and tip. Every frame each of the cube's 8 corners went SHAPE → spin → + cube_position → WORLD → to_camera() → NEAR check → project() → SCREEN. There was exactly one cube, so its spin angles and position lived in plain variables.

Part 1: A second shape, the pyramid 8 MIN

So far every shape has been a cube. A pyramid is the simplest new shape: a square base with a single point on top. Like the cube, it is described in SHAPE coordinates, measured from its own centre (0, 0, 0), with x right, y up and z away.

pyramid_points = [
    (-1, -1, -1),   # 0  bottom-left-front
    ( 1, -1, -1),   # 1  bottom-right-front
    ( 1, -1,  1),   # 2  bottom-right-back
    (-1, -1,  1),   # 3  bottom-left-back
    ( 0,  1,  0),   # 4  the tip
]

Its faces follow Lesson 3's rule: list each face's corners clockwise as seen from outside. Four faces are triangles, so they list 3 corners; the base is a square and lists 4.

Do Lesson 3's tools need changing for triangles? Let's test them on a real face with real numbers, before trusting them.

Show answer

A thing's SHAPE corner becomes a WORLD corner by adding that thing's position: the same "+ cube_position" as Lesson 4, but now each thing brings its own. We give it a name, to_world(), because Part 5 will add more steps to it.

def to_world(shape_point, thing):
    x, y, z = shape_point
    pos_x, pos_y, pos_z = thing["position"]
    return ( (x + pos_x), (y + pos_y), (z + pos_z) )

Part 4: One list, one sort 6 MIN

Lesson 4's face loop (NEAR check, clock test, average_z, light) moves into a function, add_faces_of(thing, faces_to_draw). The main loop calls it once for each thing, and every call adds to the same list. Only after all things are done do we sort and paint.

faces_to_draw = []                       # ONE list for every thing
for thing in things:
    add_faces_of(thing, faces_to_draw)   # adds this thing's faces

faces_to_draw.sort(reverse=True)         # ONE sort, furthest first
for distance, face_points, colour in faces_to_draw:
    pygame.draw.polygon(screen, colour, face_points)
    pygame.draw.polygon(screen, BLACK, face_points, 2)

Part 5: Each thing's own size and spin 12 MIN

A world where every shape is the same size and nothing moves looks like a shop window. So each thing gets three more keys: "size", "angles" and "speeds".

size

Size and spin before the position

Lesson 2 taught "rotate before adding distance". Size follows the same rule, and Fig 5.5.2 shows why:

def to_world(shape_point, thing):
    x, y, z = shape_point
    size = thing["size"]
    sized = ( (x * size), (y * size), (z * size) )      # 1. size
    spun = rotate_all(sized, thing["angles"])            # 2. spin
    pos_x, pos_y, pos_z = thing["position"]
    sx, sy, sz = spun
    return ( (sx + pos_x), (sy + pos_y), (sz + pos_z) )  # 3. place

Lesson 4 had one set of angles for its one cube. Now rotate_all() takes the angles as a parameter, and each frame every thing adds its own speeds to its own angles:

def rotate_all(point_3d, angles):
    p = rotate_x(point_3d, angles[0])   # tip
    p = rotate_y(p, angles[1])          # turn
    p = rotate_z(p, angles[2])          # roll
    return p

# in the main loop, every frame:
for thing in things:

Part 6: A floor to stand on 9 MIN

With nothing under them, the shapes seem to float in space and it's hard to judge how far away they are. A floor grid fixes both. It is just lines, at height FLOOR_Y, covering exactly the area the mini-map shows.

FLOOR_Y = -1
GRID_LEFT = -8
GRID_RIGHT = 8
GRID_NEAR = -3
GRID_FAR = 13

def draw_floor():
    for x in range(GRID_LEFT, (GRID_RIGHT + 1)):         # lines running away
        for z in range(GRID_NEAR, GRID_FAR):
            draw_floor_piece( (x, FLOOR_Y, z), (x, FLOOR_Y, (z + 1)) )
    for z in range(GRID_NEAR, (GRID_FAR + 1)):           # lines running across
        for x in range(GRID_LEFT, GRID_RIGHT):
            draw_floor_piece( (x, FLOOR_Y, z), ((x + 1), FLOOR_Y, z) )

def draw_floor_piece(world_start, world_end):
    start = to_camera(world_start)
    end = to_camera(world_end)
    if (start[2] < NEAR) or (end[2] < NEAR):
        return                                           # behind you: skip it
    pygame.draw.line(screen, GRID_COLOUR, project(start), project(end), 1)

Show answer

Q11The floor is drawn first. The mini-map is drawn last. Why the opposite ends?

Show answer

The floor is part of the world, behind everything standing on it, so the painter's rule paints it first. The mini-map isn't in the world at all: it is a panel stuck on your screen, so it must go on top of everything, last.

Wrap up 2 MIN

  • A model is a shape (points and faces). A thing is a model placed in the world with its own position, size, angles, speeds and colour. The world is a list of things.
  • A new shape needs its corners, its faces clockwise from outside, and a pointer for every face. Lesson 3's clock test and average_z work for any number of corners.
  • Each corner goes size → spin → place (to_world()), then camera → NEAR → project, exactly as before.
  • All faces of all things go in one list and one sort. The floor is drawn first, in 1-unit pieces.

Next time: Lesson 6, Matrices

Every corner of every thing now goes through up to five turns a frame: the thing's tip, turn and roll, then your turn and tip undone. Lesson 6 packs each set of turns into one 3 × 3 grid of numbers, a matrix, so a whole chain of turns becomes a single step. It's how real 3D engines do it, and it makes today's code shorter and faster.

# ---- The three turns (from Lesson 2B, unchanged) -----------------------
def rotate_x(point_3d, angle_degrees):
    """TIP one point around the x axis (+y swings toward +z)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = x
    new_y = (y * cos_a) - (z * sin_a)
    new_z = (y * sin_a) + (z * cos_a)
    return (new_x, new_y, new_z)


def rotate_y(point_3d, angle_degrees):
    """TURN one point around the y axis (+x swings toward +z)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = (x * cos_a) - (z * sin_a)
    new_y = y
    new_z = (x * sin_a) + (z * cos_a)
    return (new_x, new_y, new_z)

#  still. Step 2 brings them back, so each thing can spin.)


def to_world(shape_point, thing):
    """NEW: one SHAPE point of a thing -> a WORLD point.

    Just add the thing's position, the same "+ cube_position" as in
    Lesson 4. Now each thing brings its OWN position.

    Worked example (lesson Part 3): the pyramid's tip is SHAPE (0, 1, 0)
    and the pyramid's position is (-2.5, 0, 8):
        ((0 + -2.5), (1 + 0), (0 + 8)) = (-2.5, 1, 8)
    """
    x, y, z = shape_point
    pos_x, pos_y, pos_z = thing["position"]
    return ( (x + pos_x), (y + pos_y), (z + pos_z) )


def to_camera(world_point):
    """One WORLD point -> one CAMERA point (from Lesson 4, unchanged).
    Subtract where you stand, undo your turn, undo your tip."""
    x, y, z = world_point
    moved = ( (x - cam_x), (y - cam_y), (z - cam_z) )
    turned = rotate_y(moved, (-cam_turn))
    tipped = rotate_x(turned, (-cam_tip))
    return tipped


def project(point_3d):
    """One CAMERA point -> one SCREEN point (from Lesson 1).
    Only ever call this with z >= NEAR, so we never divide by 0."""
    x, y, z = point_3d
    screen_x = CENTRE_X + ( (x * FOCAL) / z )
    screen_y = CENTRE_Y - ( (y * FOCAL) / z )
    return (screen_x, screen_y)


def average_z(corners, camera_points):
    """How far away is this face? (from Lesson 3, uses CAMERA points).

    It divides by len(corners), so it works for a triangle (3 corners)
    just as well as for a square (4). Nothing to change!
    """
    total = 0
    for corner_number in corners:
        x, y, z = camera_points[corner_number]
        total = (total + z)
    return (total / len(corners))


def is_facing_you(face_points):
    """The clock test (from Lesson 3, unchanged). It only looks at the
    first 3 corners, so it works for triangles too."""
    a_x, a_y = face_points[0]
    b_x, b_y = face_points[1]
    c_x, c_y = face_points[2]
    arrow_a_x = (b_x - a_x)
    arrow_a_y = (b_y - a_y)
    arrow_b_x = (c_x - a_x)
    arrow_b_y = (c_y - a_y)
    cross = ( (arrow_a_x * arrow_b_y) - (arrow_a_y * arrow_b_x) )
    return (cross > 0)


def dot(arrow_1, arrow_2):
    """The dot product (from Lesson 3)."""
    x1, y1, z1 = arrow_1
    x2, y2, z2 = arrow_2
    return ( (x1 * x2) + (y1 * y2) + (z1 * z2) )


def shade_colour(colour, pointer):
    """Brighter when the face points at the light (from Lesson 3)."""
    brightness = dot(pointer, LIGHT)
    if brightness < 0:
        brightness = 0
    shade = ( AMBIENT + ( (1 - AMBIENT) * brightness ) )
    red, green, blue = colour
    return ( round(red * shade), round(green * shade), round(blue * shade) )


def add_faces_of(thing, faces_to_draw):
    """NEW: work out every face of ONE thing and add the ones we
    should paint to the shared list faces_to_draw.

    This is Lesson 4's face loop, moved into a function so we can run
    it once for EACH thing. Every thing adds to the SAME list, so the
    painter's sort later sees all faces of all things together.
    """
    model = thing["model"]

    # ---- place -> camera, for every corner of this thing ------------
    camera_points = []
    screen_points = []
    for p in model["points"]:
        world = to_world(p, thing)                     # WORLD
        camera = to_camera(world)                      # CAMERA
        camera_points.append(camera)
        if camera[2] >= NEAR:
            screen_points.append(project(camera))      # SCREEN
        else:
            screen_points.append(None)

    for corners, face_colour, pointer in model["faces"]:
        # 0. skip the face if ANY corner is too close or behind you.
        too_close = False
        for corner_number in corners:
            if camera_points[corner_number][2] < NEAR:
                too_close = True
        if too_close:
            continue

        face_points = []
        for corner_number in corners:
            face_points.append(screen_points[corner_number])

        # 1. The clock test (Lesson 3).
        if not is_facing_you(face_points):
            continue

        # 2. How far away is it? (CAMERA z, Lesson 4)
        distance = average_z(corners, camera_points)

        # 3. What colour?
        colour = face_colour
        if one_colour:
            colour = thing["colour"]
        if use_light:
            # NEW: the pointer now comes from the face list, so it
            # works for the pyramid's slopes too (Lesson 3's averaging
            # trick only worked for the cube). The things stand still
            # in step 1, so the pointer needs no turning yet.
            colour = shade_colour(colour, pointer)

        faces_to_draw.append( (distance, face_points, colour) )

    map_x = MAP_CX + (x * MAP_SCALE)
    map_y = MAP_CY - (z * MAP_SCALE)
    return (map_x, map_y)

def rotate_x(point_3d, angle_degrees):
    """TIP one point around the x axis (+y swings toward +z)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = x
    new_y = (y * cos_a) - (z * sin_a)
    new_z = (y * sin_a) + (z * cos_a)
    return (new_x, new_y, new_z)


def rotate_y(point_3d, angle_degrees):
    """TURN one point around the y axis (+x swings toward +z)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = (x * cos_a) - (z * sin_a)
    new_y = y
    new_z = (x * sin_a) + (z * cos_a)
    return (new_x, new_y, new_z)


def rotate_z(point_3d, angle_degrees):
    """ROLL one point around the z axis (+x swings toward +y)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = (x * cos_a) - (y * sin_a)
    new_y = (x * sin_a) + (y * cos_a)
    new_z = z
    return (new_x, new_y, new_z)


def rotate_all(point_3d, angles):
    """Spin one point: tip, then turn, then roll (Lesson 2B's order).

    CHANGED: the angles come IN as a list [tip, turn, roll],
    because every thing now has its OWN angles. Before, there was only
    one cube, so the angles could live in global variables.
    """
    p = rotate_x(point_3d, angles[0])
    p = rotate_y(p, angles[1])
    p = rotate_z(p, angles[2])
    return p


def to_world(shape_point, thing):
    """NEW: one SHAPE point of a thing -> a WORLD point.

    1. size:  multiply by the thing's size (grow or shrink round its
              own centre).
    2. spin:  turn it by the thing's own angles.
    3. place: add the thing's position.

    Worked example (lesson Part 5): the small cube, size 0.5, still,
    at (2, -0.5, 4). Its corner 5 is SHAPE (1, 1, -1):
        1. ((1 * 0.5), (1 * 0.5), (-1 * 0.5)) = (0.5, 0.5, -0.5)
        2. angles 0                           = no change
        3. ((0.5 + 2), (0.5 + -0.5), (-0.5 + 4)) = (2.5, 0, 3.5)
    """
    x, y, z = shape_point
    size = thing["size"]
    sized = ( (x * size), (y * size), (z * size) )         # 1. size
    spun = rotate_all(sized, thing["angles"])               # 2. spin
    pos_x, pos_y, pos_z = thing["position"]
    sx, sy, sz = spun
    return ( (sx + pos_x), (sy + pos_y), (sz + pos_z) )     # 3. place


def to_camera(world_point):
    """One WORLD point -> one CAMERA point (from Lesson 4, unchanged).
    Subtract where you stand, undo your turn, undo your tip."""
    x, y, z = world_point
    moved = ( (x - cam_x), (y - cam_y), (z - cam_z) )
    turned = rotate_y(moved, (-cam_turn))
    tipped = rotate_x(turned, (-cam_tip))
    return tipped


def project(point_3d):
    """One CAMERA point -> one SCREEN point (from Lesson 1).
    Only ever call this with z >= NEAR, so we never divide by 0."""
    x, y, z = point_3d
    screen_x = CENTRE_X + ( (x * FOCAL) / z )
    screen_y = CENTRE_Y - ( (y * FOCAL) / z )
    return (screen_x, screen_y)


def average_z(corners, camera_points):
    """How far away is this face? (from Lesson 3, uses CAMERA points).

    It divides by len(corners), so it works for a triangle (3 corners)
    just as well as for a square (4). Nothing to change!
    """
    total = 0
    for corner_number in corners:
        x, y, z = camera_points[corner_number]
        total = (total + z)
    return (total / len(corners))


def is_facing_you(face_points):
    """The clock test (from Lesson 3, unchanged). It only looks at the
    first 3 corners, so it works for triangles too."""
    a_x, a_y = face_points[0]
    b_x, b_y = face_points[1]
    c_x, c_y = face_points[2]
    arrow_a_x = (b_x - a_x)
    arrow_a_y = (b_y - a_y)
    arrow_b_x = (c_x - a_x)
    arrow_b_y = (c_y - a_y)
    cross = ( (arrow_a_x * arrow_b_y) - (arrow_a_y * arrow_b_x) )
    return (cross > 0)


def dot(arrow_1, arrow_2):
    """The dot product (from Lesson 3)."""
    x1, y1, z1 = arrow_1
    x2, y2, z2 = arrow_2
    return ( (x1 * x2) + (y1 * y2) + (z1 * z2) )


def shade_colour(colour, pointer):
    """Brighter when the face points at the light (from Lesson 3)."""
    brightness = dot(pointer, LIGHT)
    if brightness < 0:
        brightness = 0
    shade = ( AMBIENT + ( (1 - AMBIENT) * brightness ) )
    red, green, blue = colour
    return ( round(red * shade), round(green * shade), round(blue * shade) )


def keep_under_360(angle):
    """Keep an angle between 0 and 360.
    CHANGED: a NEGATIVE speed (the big pyramid) counts DOWN,
    so we also add 360 when it drops below 0."""
    if angle >= 360:
        angle = (angle - 360)
    if angle < 0:
        angle = (angle + 360)
    return angle


def add_faces_of(thing, faces_to_draw):
    """(step 1) work out every face of ONE thing and add the ones we
    should paint to the shared list faces_to_draw.

    This is Lesson 4's face loop, moved into a function so we can run
    it once for EACH thing. Every thing adds to the SAME list, so the
    painter's sort later sees all faces of all things together.
    """
    model = thing["model"]

    # ---- spin -> place -> camera, for every corner of this thing ----
    camera_points = []
    screen_points = []
    for p in model["points"]:
        world = to_world(p, thing)                     # WORLD
        camera = to_camera(world)                      # CAMERA
        camera_points.append(camera)
        if camera[2] >= NEAR:
            screen_points.append(project(camera))      # SCREEN
        else:
            screen_points.append(None)

    for corners, face_colour, pointer in model["faces"]:
        # 0. skip the face if ANY corner is too close or behind you.
        too_close = False
        for corner_number in corners:
            if camera_points[corner_number][2] < NEAR:
                too_close = True
        if too_close:
            continue

        face_points = []
        for corner_number in corners:
            face_points.append(screen_points[corner_number])

        # 1. The clock test (Lesson 3).
        if not is_facing_you(face_points):
            continue

        # 2. How far away is it? (CAMERA z, Lesson 4)
        distance = average_z(corners, camera_points)

        # 3. What colour?
        colour = face_colour
        if one_colour:
            colour = thing["colour"]
        if use_light:
            # NEW: the pointer must spin WITH the thing, so we turn
            # it by the same angles. We do NOT multiply it by the size:
            # a bigger face still points the same way, and the arrow
            # must stay exactly 1 long for the light maths.
            spun_pointer = rotate_all(pointer, thing["angles"])
            colour = shade_colour(colour, spun_pointer)

        faces_to_draw.append( (distance, face_points, colour) )


def to_map(x, z):

    map_x = MAP_CX + (x * MAP_SCALE)
    map_y = MAP_CY - (z * MAP_SCALE)
    return (map_x, map_y)

def rotate_x(point_3d, angle_degrees):
    """TIP one point around the x axis (+y swings toward +z)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = x
    new_y = (y * cos_a) - (z * sin_a)
    new_z = (y * sin_a) + (z * cos_a)
    return (new_x, new_y, new_z)


def rotate_y(point_3d, angle_degrees):
    """TURN one point around the y axis (+x swings toward +z)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = (x * cos_a) - (z * sin_a)
    new_y = y
    new_z = (x * sin_a) + (z * cos_a)
    return (new_x, new_y, new_z)


def rotate_z(point_3d, angle_degrees):
    """ROLL one point around the z axis (+x swings toward +y)."""
    x, y, z = point_3d
    angle_radians = math.radians(angle_degrees)
    cos_a = math.cos(angle_radians)
    sin_a = math.sin(angle_radians)
    new_x = (x * cos_a) - (y * sin_a)
    new_y = (x * sin_a) + (y * cos_a)
    new_z = z
    return (new_x, new_y, new_z)


def rotate_all(point_3d, angles):
    """Spin one point: tip, then turn, then roll (Lesson 2B's order).

    (step 2) CHANGED: the angles come IN as a list [tip, turn, roll],
    because every thing now has its OWN angles. Before, there was only
    one cube, so the angles could live in global variables.
    """
    p = rotate_x(point_3d, angles[0])
    p = rotate_y(p, angles[1])
    p = rotate_z(p, angles[2])
    return p


def to_world(shape_point, thing):
    """(step 2) one SHAPE point of a thing -> a WORLD point.

    1. size:  multiply by the thing's size (grow or shrink round its
              own centre).
    2. spin:  turn it by the thing's own angles.
    3. place: add the thing's position.

    Worked example (lesson Part 5): the small cube, size 0.5, still,
    at (2, -0.5, 4). Its corner 5 is SHAPE (1, 1, -1):
        1. ((1 * 0.5), (1 * 0.5), (-1 * 0.5)) = (0.5, 0.5, -0.5)
        2. angles 0                           = no change
        3. ((0.5 + 2), (0.5 + -0.5), (-0.5 + 4)) = (2.5, 0, 3.5)
    """
    x, y, z = shape_point
    size = thing["size"]
    sized = ( (x * size), (y * size), (z * size) )         # 1. size
    spun = rotate_all(sized, thing["angles"])               # 2. spin
    pos_x, pos_y, pos_z = thing["position"]
    sx, sy, sz = spun
    return ( (sx + pos_x), (sy + pos_y), (sz + pos_z) )     # 3. place


def to_camera(world_point):
    """One WORLD point -> one CAMERA point (from Lesson 4, unchanged).
    Subtract where you stand, undo your turn, undo your tip."""
    x, y, z = world_point
    moved = ( (x - cam_x), (y - cam_y), (z - cam_z) )
    turned = rotate_y(moved, (-cam_turn))
    tipped = rotate_x(turned, (-cam_tip))
    return tipped


def project(point_3d):
    """One CAMERA point -> one SCREEN point (from Lesson 1).
    Only ever call this with z >= NEAR, so we never divide by 0."""
    x, y, z = point_3d
    screen_x = CENTRE_X + ( (x * FOCAL) / z )
    screen_y = CENTRE_Y - ( (y * FOCAL) / z )
    return (screen_x, screen_y)


def average_z(corners, camera_points):
    """How far away is this face? (from Lesson 3, uses CAMERA points).

    It divides by len(corners), so it works for a triangle (3 corners)
    just as well as for a square (4). Nothing to change!
    """
    total = 0
    for corner_number in corners:
        x, y, z = camera_points[corner_number]
        total = (total + z)
    return (total / len(corners))


def is_facing_you(face_points):
    """The clock test (from Lesson 3, unchanged). It only looks at the
    first 3 corners, so it works for triangles too."""
    a_x, a_y = face_points[0]
    b_x, b_y = face_points[1]
    c_x, c_y = face_points[2]
    arrow_a_x = (b_x - a_x)
    arrow_a_y = (b_y - a_y)
    arrow_b_x = (c_x - a_x)
    arrow_b_y = (c_y - a_y)
    cross = ( (arrow_a_x * arrow_b_y) - (arrow_a_y * arrow_b_x) )
    return (cross > 0)


def dot(arrow_1, arrow_2):
    """The dot product (from Lesson 3)."""
    x1, y1, z1 = arrow_1
    x2, y2, z2 = arrow_2
    return ( (x1 * x2) + (y1 * y2) + (z1 * z2) )


def shade_colour(colour, pointer):
    """Brighter when the face points at the light (from Lesson 3)."""
    brightness = dot(pointer, LIGHT)
    if brightness < 0:
        brightness = 0
    shade = ( AMBIENT + ( (1 - AMBIENT) * brightness ) )
    red, green, blue = colour
    return ( round(red * shade), round(green * shade), round(blue * shade) )


def keep_under_360(angle):
    """Keep an angle between 0 and 360.
    (step 2) CHANGED: a NEGATIVE speed (the big pyramid) counts DOWN,
    so we also add 360 when it drops below 0."""
    if angle >= 360:
        angle = (angle - 360)
    if angle < 0:
        angle = (angle + 360)
    return angle


def add_faces_of(thing, faces_to_draw):
    """(step 1) work out every face of ONE thing and add the ones we
    should paint to the shared list faces_to_draw.

    This is Lesson 4's face loop, moved into a function so we can run
    it once for EACH thing. Every thing adds to the SAME list, so the
    painter's sort later sees all faces of all things together.
    """
    model = thing["model"]

    # ---- spin -> place -> camera, for every corner of this thing ----
    camera_points = []
    screen_points = []
    for p in model["points"]:
        world = to_world(p, thing)                     # WORLD
        camera = to_camera(world)                      # CAMERA
        camera_points.append(camera)
        if camera[2] >= NEAR:
            screen_points.append(project(camera))      # SCREEN
        else:
            screen_points.append(None)

    for corners, face_colour, pointer in model["faces"]:
        # 0. skip the face if ANY corner is too close or behind you.
        too_close = False
        for corner_number in corners:
            if camera_points[corner_number][2] < NEAR:
                too_close = True
        if too_close:
            continue

        face_points = []
        for corner_number in corners:
            face_points.append(screen_points[corner_number])

        # 1. The clock test (Lesson 3).
        if not is_facing_you(face_points):
            continue

        # 2. How far away is it? (CAMERA z, Lesson 4)
        distance = average_z(corners, camera_points)

        # 3. What colour?
        colour = face_colour
        if one_colour:
            colour = thing["colour"]
        if use_light:
            # (step 2) the pointer must spin WITH the thing, so we turn
            # it by the same angles. We do NOT multiply it by the size:
            # a bigger face still points the same way, and the arrow
            # must stay exactly 1 long for the light maths.
            spun_pointer = rotate_all(pointer, thing["angles"])
            colour = shade_colour(colour, spun_pointer)

        faces_to_draw.append( (distance, face_points, colour) )


def draw_floor():
    """NEW: draw the floor grid at y = FLOOR_Y, in 1-unit pieces.

    Two sets of lines:
      * lines running AWAY from you (fixed x, z changes)
      * lines running ACROSS        (fixed z, x changes)
    Each line is cut into pieces 1 unit long. A piece is drawn only if
    BOTH its ends are in front of you (CAMERA z >= NEAR). A short piece
    means only a short gap at your feet, not a missing line.
    """
    # Lines running away: x = -8, -7, ... 8.  range() stops BEFORE the
    # end number, so we add 1 to include 8 itself.
    for x in range(GRID_LEFT, (GRID_RIGHT + 1)):
        for z in range(GRID_NEAR, GRID_FAR):
            draw_floor_piece( (x, FLOOR_Y, z), (x, FLOOR_Y, (z + 1)) )
    # Lines running across: z = -3, -2, ... 13.
    for z in range(GRID_NEAR, (GRID_FAR + 1)):
        for x in range(GRID_LEFT, GRID_RIGHT):
            draw_floor_piece( (x, FLOOR_Y, z), ((x + 1), FLOOR_Y, z) )


def draw_floor_piece(world_start, world_end):
    """NEW: one 1-unit piece of floor line, WORLD -> CAMERA -> SCREEN."""
    start = to_camera(world_start)
    end = to_camera(world_end)
    if (start[2] < NEAR) or (end[2] < NEAR):
        return                                   # behind you: skip it
    pygame.draw.line(screen, GRID_COLOUR, project(start), project(end), 1)


def to_map(x, z):
    """A WORLD (x, z) -> a pixel on the mini-map (from Lesson 4)."""
    map_x = MAP_CX + (x * MAP_SCALE)
    map_y = MAP_CY - (z * MAP_SCALE)
    return (map_x, map_y)


def draw_map():
    """Draw the mini-map: every thing's base and you, from above.

    NEW: a loop over ALL things. Corners 0, 1, 2, 3 are the bottom
    corners of BOTH models (that is why the pyramid's base uses the
    cube's numbers), so the same 4 numbers work for every thing.
    """
    box = pygame.Rect(MAP_LEFT, MAP_TOP, MAP_SIZE, MAP_SIZE)
    pygame.draw.rect(screen, MAP_BACK, box)
    screen.set_clip(box)
    for thing in things:
        outline = []
        for corner_number in (0, 1, 2, 3):
            corner = thing["model"]["points"][corner_number]
            x, y, z = to_world(corner, thing)
            outline.append(to_map(x, z))
        pygame.draw.polygon(screen, thing["colour"], outline, 2)
    forward_x, forward_y, forward_z = rotate_y((0, 0, 1), cam_turn)
    you = to_map(cam_x, cam_z)
    nose = to_map( (cam_x + (forward_x * 1.5)), (cam_z + (forward_z * 1.5)) )
    pygame.draw.line(screen, PINK, you, nose, 2)
    pygame.draw.circle(screen, PINK, you, 4)
    screen.set_clip(None)
    pygame.draw.rect(screen, WHITE, box, 1)

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_SPACE:
                spinning = not spinning
            if event.key == pygame.K_l:
                use_light = not use_light
            if event.key == pygame.K_c:
                one_colour = not one_colour
            if event.key == pygame.K_g:
                show_grid = not show_grid
            if event.key == pygame.K_r:          # back to the start
                cam_x = 0
                cam_y = 0
                cam_z = 0
                cam_turn = 0
                cam_tip = 0
                for thing in things:
                    thing["angles"] = [0, 0, 0]

    # ---- Keys you HOLD (from Lesson 4, unchanged) ---------------------
    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT]:
        cam_turn = (cam_turn + TURN_SPEED)
    if keys[pygame.K_RIGHT]:
        cam_turn = (cam_turn - TURN_SPEED)
    if keys[pygame.K_UP]:
        cam_tip = (cam_tip - TURN_SPEED)
    if keys[pygame.K_DOWN]:
        cam_tip = (cam_tip + TURN_SPEED)
    if cam_tip > TIP_LIMIT:
        cam_tip = TIP_LIMIT
    if cam_tip < (-TIP_LIMIT):
        cam_tip = (-TIP_LIMIT)

    forward_x, forward_y, forward_z = rotate_y((0, 0, 1), cam_turn)
    right_x, right_y, right_z = rotate_y((1, 0, 0), cam_turn)
    if keys[pygame.K_w]:
        cam_x = (cam_x + (forward_x * MOVE_SPEED))
        cam_z = (cam_z + (forward_z * MOVE_SPEED))
    if keys[pygame.K_s]:
        cam_x = (cam_x - (forward_x * MOVE_SPEED))
        cam_z = (cam_z - (forward_z * MOVE_SPEED))
    if keys[pygame.K_d]:
        cam_x = (cam_x + (right_x * MOVE_SPEED))
        cam_z = (cam_z + (right_z * MOVE_SPEED))
    if keys[pygame.K_a]:
        cam_x = (cam_x - (right_x * MOVE_SPEED))
        cam_z = (cam_z - (right_z * MOVE_SPEED))
    if keys[pygame.K_e]:
        cam_y = (cam_y + MOVE_SPEED)
    if keys[pygame.K_q]:
        cam_y = (cam_y - MOVE_SPEED)

    # ---- (step 2) every thing spins at its OWN speeds --------------------
    if spinning:
        for thing in things:
            angles = thing["angles"]
            speeds = thing["speeds"]
            angles[0] = keep_under_360( (angles[0] + speeds[0]) )   # tip
            angles[1] = keep_under_360( (angles[1] + speeds[1]) )   # turn
            angles[2] = keep_under_360( (angles[2] + speeds[2]) )   # roll

    screen.fill(BLACK)

    # ---- NEW: the floor first, so every shape is painted on top of it -
    if show_grid:
        draw_floor()

    # ---- (step 1) ONE list for the faces of EVERY thing --------------------
    faces_to_draw = []
    for thing in things:
        add_faces_of(thing, faces_to_draw)

    # ---- The painter's method: furthest first, ALL faces together ----
    faces_to_draw.sort(reverse=True)
    for distance, face_points, colour in faces_to_draw:
        pygame.draw.polygon(screen, colour, face_points)
        pygame.draw.polygon(screen, BLACK, face_points, 2)

    draw_map()

    text = ("you are at (" + str(round(cam_x, 2)) + ", " +
            str(round(cam_y, 2)) + ", " + str(round(cam_z, 2)) + ")")
    text = (text + "   turn " + str(round(cam_turn, 1)) +
            "   tip " + str(round(cam_tip, 1)))
    screen.blit(font.render(text, True, PINK), (20, 20))
    screen.blit(font.render("ARROWS = turn and look,  W A S D = walk,  Q / E = down / up", True, YELLOW), (20, 50))
    screen.blit(font.render("SPACE = pause,  R = reset,  L = light,  C = colours,  G = grid", True, YELLOW), (20, 80))

    pygame.display.flip()
    clock.tick(60)

pygame.quit()
